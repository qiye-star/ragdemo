# 解析降本：本地版面解析 + 大模型整理 + 数字交叉校验（TextIn 兜底）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用一次**零 TextIn 成本**的对比实验，判断"本地词坐标版面解析 + 大模型整理结构 + 数字闭合校验"能否替代 TextIn 处理文字为主的公告与研报；实验达标后按 Phase B 灰度落地（开关默认关、失败整份退回 TextIn、可一键回滚）。

**Architecture:** 新增 `ragdemo/parse/local/` 包：`layout`（pdfplumber 取每页词坐标与文字层）→ `tables`（按坐标在本地还原表格，纯函数）→ `structure`（大模型只整理排版，**不产生数值**）→ `number_closure`（整理后文本里的每个数字必须原样出现在 PDF 文字层，否则该页判失败、退回 TextIn）。实验阶段只产出逐页 markdown 与对比指标，**不接入入库链路**；是否落地由实验报告里的量化门槛决定。

**Tech Stack:** Python 3.11、pdfplumber（MIT）、现有 `HttpClient` + DeepSeek（经出网代理 8086）、pytest、ruff、mypy --strict。

**Spec:** ADR-0008（TextIn 为主解析器，本计划若落地需新增 ADR 修订它）；`docs/05-document-pipeline.md` §3（置信度与 C 档路由）；总计划阶段 3；对话结论（2026-09-30：TextIn 约 0.14 元/页，25 次调用 257 页 34.84 元）。

## Global Constraints

- **每个数字必须可溯源**（CLAUDE.md §0）：大模型只做排版整理，不得产生、修改、换算任何数值；整理后的每个数字必须通过 `closure_violations` 校验，否则该页不采信。
- **计算与生成分离**（§1.2）：任何让模型直接产出数值的 prompt 都是缺陷。
- **数据境内**（§0）：大模型只走 DeepSeek（境内，经 `ragdemo-egress` 反向代理 8086）；不引入境外服务。
- **TDD**（§3）：数值相关函数（数字归一化、闭合校验、对比指标）必须先写失败测试。
- **`ruff` + `mypy --strict`** 必须通过；Python 3.11+，类型注解完整。
- **许可**：**不得引入 PyMuPDF（AGPL-3.0）**；使用 pdfplumber（MIT，底层 pdfminer.six 亦为 MIT）。
- **Prompt 版本化**存 `packages/ragdemo/src/ragdemo/agents/prompts/<agent>/<version>.md`；改 prompt 必须重跑实验（本计划里即重跑 Task 8）。
- **密钥只在环境变量**；不在代码、日志、测试夹具、提交中出现。
- **评测驱动**（§1.4）：实验阶段不改任何在线行为；落地阶段（Phase B）改解析必须跑三套评测并把数字贴进 PR。
- 用户偏好：回答与文档用中文。
- **年报 / 季报（`annual_report` / `quarterly`）永不走本地解析**（含三张报表与分部大表，配置校验直接拒绝）。
- **不批量重解析已入库文档**（会使评测集 `gold_block_ids` 失效）；本地解析只对新文档生效。

```python
# packages/ragdemo/src/ragdemo/parse/local/layout.py
"""本地版面提取：每页的词坐标与文字层。整个本地解析链路里唯一碰 PDF 库的地方。"""

from __future__ import annotations

import io
from dataclasses import dataclass

import pdfplumber


@dataclass(frozen=True)
class Word:
    text: str
    x0: float
    x1: float
    top: float
    bottom: float

    @property
    def mid_y(self) -> float:
        return (self.top + self.bottom) / 2


@dataclass(frozen=True)
class PageLayout:
    page: int  # 从 1 起
    width: float
    height: float
    words: list[Word]
    text: str  # 文字层，按阅读顺序


def extract_pages(pdf_bytes: bytes) -> list[PageLayout]:
    try:
        pdf = pdfplumber.open(io.BytesIO(pdf_bytes))
    except Exception as exc:  # pdfminer 对坏文件抛多种异常，统一成一句能看懂的话
        raise ValueError(f"不是有效的 PDF：{exc}") from exc
    with pdf:
        pages: list[PageLayout] = []
        for i, p in enumerate(pdf.pages, start=1):
            words = [
                Word(str(w["text"]), float(w["x0"]), float(w["x1"]), float(w["top"]), float(w["bottom"]))
                for w in p.extract_words(keep_blank_chars=False)
            ]
            pages.append(
                PageLayout(i, float(p.width), float(p.height), words, p.extract_text() or "")
            )
    return pages
```

```python
# packages/ragdemo/src/ragdemo/parse/local/tables.py
"""按词坐标还原表格（纯函数，不依赖任何 PDF 库）。

表格的单元格对齐信息只存在于坐标里——把页面压平成文字再交给大模型，它只能靠猜来分列，
数字可能被放进错误的列（这种错误"数字都出现过"的闭合校验抓不到）。所以先在本地按坐标
把表格还原好，再交给大模型只做排版。"""

from __future__ import annotations

from collections.abc import Sequence

from ragdemo.parse.local.layout import Word


def cluster_rows(words: Sequence[Word], *, y_tol: float = 3.0) -> list[list[Word]]:
    """按纵向中点聚成行，行内按 x0 升序；行按纵向位置升序。"""
    rows: list[list[Word]] = []
    for w in sorted(words, key=lambda w: (w.mid_y, w.x0)):
        if rows and abs(rows[-1][-1].mid_y - w.mid_y) <= y_tol:
            rows[-1].append(w)
        else:
            rows.append([w])
    return [sorted(r, key=lambda w: w.x0) for r in rows]


def column_edges(rows: Sequence[Sequence[Word]], *, gap: float = 8.0) -> list[tuple[float, float]]:
    """把所有行的词投影到横轴，空隙 >= gap 处切列；返回每列 (左, 右)。"""
    spans = sorted((w.x0, w.x1) for r in rows for w in r)
    cols: list[tuple[float, float]] = []
    for x0, x1 in spans:
        if cols and x0 - cols[-1][1] < gap:
            cols[-1] = (cols[-1][0], max(cols[-1][1], x1))
        else:
            cols.append((x0, x1))
    return cols


def rows_to_grid(
    rows: Sequence[Sequence[Word]], cols: Sequence[tuple[float, float]]
) -> list[list[str]]:
    grid: list[list[str]] = []
    for r in rows:
        cells = [""] * len(cols)
        for w in r:
            idx = next(i for i, (a, b) in enumerate(cols) if w.x0 >= a - 0.5 and w.x1 <= b + 0.5)
            cells[idx] = f"{cells[idx]} {w.text}".strip()
        grid.append(cells)
    return grid


def grid_to_markdown(grid: Sequence[Sequence[str]]) -> str:
    if not grid:
        return ""
    header, *body = grid
    lines = ["| " + " | ".join(header) + " |", "|" + "---|" * len(header)]
    lines += ["| " + " | ".join(r) + " |" for r in body]
    return "\n".join(lines)


def _segments(row: Sequence[Word], gap: float) -> int:
    """一行里被 >= gap 的横向空隙隔开的段数；正文句子里词间空隙很小，只有 1 段。"""
    count = 1
    for a, b in zip(row, row[1:], strict=False):
        if b.x0 - a.x1 >= gap:
            count += 1
    return count


def find_table_regions(
    rows: Sequence[Sequence[Word]], *, gap: float = 8.0, min_rows: int = 3, min_cols: int = 3
) -> list[list[list[Word]]]:
    """表格区域 = 连续的、每行都至少有 2 段的行；区域 >= min_rows 行且列数 >= min_cols 才算。

    必须先在行级别圈出区域、再只对区域算列：整页一起投影会被正文句子桥接，
    把不同列并成一列（混排页——正文加一张表——是最常见的形态）。"""
    regions: list[list[list[Word]]] = []
    run: list[list[Word]] = []
    for row in [*rows, []]:  # 末尾补一个空行，冲刷最后一段
        if row and _segments(row, gap) >= 2:
            run.append(list(row))
            continue
        if len(run) >= min_rows and len(column_edges(run, gap=gap)) >= min_cols:
            regions.append(run)
        run = []
    return regions
```

```python
# packages/ragdemo/src/ragdemo/parse/local/number_closure.py
"""数字抽取与闭合校验：大模型整理后的文本里，每个数字必须原样出现在 PDF 文字层里。

这是"计算与生成分离"在解析环节的落地：模型只排版，不得产生数值。"""

from __future__ import annotations

import re
from collections import Counter

# 带千分位 / 小数 / 百分号 / 括号负数；不含中文数字。
_NUM = re.compile(r"\(?-?\d[\d,]*(?:\.\d+)?\)?%?")


def normalize_number(token: str) -> str:
    """去千分位逗号；括号负数统一成 -x；保留小数位（不做任何数值四舍五入）。"""
    t = token.strip()
    negative = (t.startswith("(") and t.endswith(")")) or t.startswith("(-")
    t = t.strip("()").replace(",", "")
    if t.startswith("-"):
        negative, t = True, t[1:]
    return f"-{t}" if negative else t


def numbers_in(text: str) -> Counter[str]:
    """文本里所有数字的多重集合（归一化后）。年份、页码也算——宁可多校验。"""
    return Counter(normalize_number(m.group()) for m in _NUM.finditer(text))


def closure_violations(structured: str, source: str) -> list[str]:
    """structured 里出现次数多于 source 的数字；空列表表示闭合。按多重集合比较。"""
    src = numbers_in(source)
    out = numbers_in(structured)
    return sorted(n for n, c in out.items() if c > src.get(n, 0))
```

```python
# packages/ragdemo/src/ragdemo/parse/local/structure.py
"""大模型整理一页：只排版，不产生数值。整理结果必须通过数字闭合校验。"""

from __future__ import annotations

from collections.abc import Sequence
from pathlib import Path
from typing import Any

from ragdemo.adapters.http import HttpClient
from ragdemo.parse.describe_llm import Usage, load_prompt
from ragdemo.parse.local.number_closure import closure_violations

CHAT_ENDPOINT = "/chat/completions"
PROMPT_DIR = Path(__file__).resolve().parents[2] / "agents" / "prompts" / "parse_structure"


class ClosureFailed(RuntimeError):
    """整理后的文本含有源文里没有的数字（重试后仍然如此）。"""

    def __init__(self, violations: list[str]) -> None:
        super().__init__(f"数字闭合校验失败：{violations}")
        self.violations = violations


class LlmStructurer:
    def __init__(self, http: HttpClient, *, model: str, prompt_version: str = "v1") -> None:
        self._http = http
        self.model = model
        self._template = load_prompt(prompt_version, PROMPT_DIR)
        self.usage = Usage()

    def structure(self, page_text: str, table_markdowns: Sequence[str]) -> str:
        tables = "\n\n".join(table_markdowns) if table_markdowns else "（本页没有表格）"
        source = page_text + "\n" + "\n".join(table_markdowns)
        prompt = self._template.replace("{page_text}", page_text).replace("{tables}", tables)
        messages = [{"role": "user", "content": prompt}]

        reply = self._chat(messages)
        bad = closure_violations(reply, source)
        if not bad:
            return reply
        messages += [
            {"role": "assistant", "content": reply},
            {
                "role": "user",
                "content": f"你的输出里出现了输入中没有的数字：{', '.join(bad)}。"
                "请只做排版，不要产生任何新数字，重新输出整理后的 markdown。",
            },
        ]
        reply = self._chat(messages)
        bad = closure_violations(reply, source)
        if bad:
            raise ClosureFailed(bad)
        return reply

    def _chat(self, messages: list[dict[str, str]]) -> str:
        raw = self._http.post_json(
            CHAT_ENDPOINT,
            {"model": self.model, "messages": messages, "temperature": 0, "max_tokens": 4000},
        )
        payload: Any = raw.payload
        usage = payload.get("usage") or {}
        self.usage.calls += 1
        self.usage.prompt_tokens += int(usage.get("prompt_tokens") or 0)
        self.usage.completion_tokens += int(usage.get("completion_tokens") or 0)
        return str(payload["choices"][0]["message"]["content"]).strip()
```

```python
# packages/ragdemo/src/ragdemo/parse/local/pipeline.py
"""逐页本地解析：无文字层 → 退回；有表格 → 按坐标还原；整理 → 闭合校验。

实验阶段只产出逐页 markdown 与状态，不构造 NormalizedBlock、不接入入库链路。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass, field
from typing import Literal, Protocol

from ragdemo.parse.confidence import MIN_CHARS_PER_PAGE
from ragdemo.parse.local.layout import PageLayout, extract_pages
from ragdemo.parse.local.structure import ClosureFailed, StructureFailed
from ragdemo.parse.local.tables import (
    cluster_rows,
    column_edges,
    find_table_regions,
    grid_to_markdown,
    rows_to_grid,
)

Status = Literal["ok", "no_text_layer", "closure_failed", "structure_failed"]


class PageStructurer(Protocol):
    def structure(self, page_text: str, table_markdowns: Sequence[str]) -> str: ...


@dataclass(frozen=True)
class PageResult:
    page: int
    status: Status
    markdown: str
    source_text: str
    violations: list[str] = field(default_factory=list)


def _table_markdowns(layout: PageLayout) -> list[str]:
    """先圈出表格区域，再只对区域算列并还原成 markdown。
    （实验阶段的简化：区域内按一张规整网格处理；跨页表、合并单元格、嵌套表头留给 Phase B。）"""
    rows = cluster_rows(layout.words)
    out: list[str] = []
    for region in find_table_regions(rows):
        out.append(grid_to_markdown(rows_to_grid(region, column_edges(region))))
    return out


def parse_pages_local(pdf_bytes: bytes, structurer: PageStructurer) -> list[PageResult]:
    results: list[PageResult] = []
    for layout in extract_pages(pdf_bytes):
        if len(layout.text.strip()) < MIN_CHARS_PER_PAGE and not layout.words:
            results.append(PageResult(layout.page, "no_text_layer", "", layout.text))
            continue
        tables = _table_markdowns(layout)
        try:
            markdown = structurer.structure(layout.text, tables)
        except ClosureFailed as exc:
            results.append(
                PageResult(layout.page, "closure_failed", "", layout.text, exc.violations)
            )
            continue
        except StructureFailed:  # 截断 / 空回复 / 畸形响应 / 丢失数字：这一页不可信
            results.append(PageResult(layout.page, "structure_failed", "", layout.text))
            continue
        results.append(PageResult(layout.page, "ok", markdown, layout.text))
    return results
```

```python
# packages/ragdemo/src/ragdemo/parse/local/compare.py
"""本地解析 vs TextIn 的对比指标（纯函数）。注意：TextIn 的结果不是绝对标准答案，
指标只说明"两路是否一致"；不一致处由人工抽查裁定（实验报告里记录）。"""

from __future__ import annotations

import re
from collections import Counter

from ragdemo.parse.local.number_closure import numbers_in

_WS = re.compile(r"\s+")


def text_coverage(reference: str, candidate: str) -> float:
    ref = Counter(_WS.sub("", reference))
    if not ref:
        return 1.0
    cand = Counter(_WS.sub("", candidate))
    hit = sum(min(c, cand.get(ch, 0)) for ch, c in ref.items())
    return hit / sum(ref.values())


def number_recall_precision(reference: str, candidate: str) -> tuple[float, float]:
    ref, cand = numbers_in(reference), numbers_in(candidate)
    hit = sum(min(c, cand.get(n, 0)) for n, c in ref.items())
    recall = hit / sum(ref.values()) if ref else 1.0
    precision = hit / sum(cand.values()) if cand else 1.0
    return recall, precision


def _table_rows(md: str) -> list[Counter[str]]:
    """每张表（连续的 `|` 行）跳过第一行（表头），其余行含 >= 2 个数字才算数据行。

    表头里的年份（2024 / 2023）是数字，但不是数据；若把它算进去，"数据行全部串行"
    的表仍会因为表头一致而得到非零召回，指标就骗人了。"""
    rows: list[Counter[str]] = []
    header_pending = True
    for line in md.splitlines():
        if not line.strip().startswith("|"):
            header_pending = True  # 遇到非表格行：下一张表从头开始
            continue
        if set(line.replace("|", "").strip()) <= {"-", ":"}:
            continue  # 分隔行 |---|---|
        if header_pending:
            header_pending = False
            continue
        nums = numbers_in(line)
        if sum(nums.values()) >= 2:
            rows.append(nums)
    return rows


def table_row_recall(reference_md: str, candidate_md: str) -> float:
    ref_rows = _table_rows(reference_md)
    if not ref_rows:
        return 1.0
    cand_rows = _table_rows(candidate_md)
    hit = sum(1 for r in ref_rows if any(all(c.get(n, 0) >= k for n, k in r.items()) for c in cand_rows))
    return hit / len(ref_rows)
```

```python
# scripts/parse_compare.py
"""对比实验运行器。读库里已有的 TextIn 缓存（零 TextIn 成本），与本地路径逐文档对比。

用法（需要 .env 里 MODEL_BASE_URL 指向出网代理的 DeepSeek 端口，且 RAGDEMO_DSN 可用）：
    set -a && . ./.env && set +a
    uv run --no-sync python scripts/parse_compare.py docs   # 有 TextIn 真值的已解析文档（当前 22 份）
    uv run --no-sync python scripts/parse_compare.py research <目录>  # 研报：无真值，只测闭合 / 状态

输出：data/experiments/parse-compare-<mode>-<日期>.tsv（data/ 已被 git 忽略）。
"""

from __future__ import annotations

import os
import sys
from datetime import date
from pathlib import Path

import psycopg

from ragdemo.config import load_config
from ragdemo.parse.describer_factory import deepseek_client
from ragdemo.parse.local.compare import number_recall_precision, table_row_recall, text_coverage
from ragdemo.parse.local.pipeline import parse_pages_local
from ragdemo.parse.local.structure import LlmStructurer
from ragdemo_core.blob import LocalBlobStore

OUT_DIR = Path("data/experiments")


def _structurer() -> LlmStructurer:
    cfg = load_config()
    if not cfg.model_base_url:
        raise SystemExit("MODEL_BASE_URL 未设置：实验需要真实模型")
    return LlmStructurer(deepseek_client(cfg.model_base_url), model=cfg.model_name)


def run_docs() -> Path:
    cfg = load_config()
    blob = LocalBlobStore(cfg.blob_root)
    structurer = _structurer()
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    out = OUT_DIR / f"parse-compare-docs-{date.today()}.tsv"
    with psycopg.connect(os.environ["RAGDEMO_DSN"]) as conn, out.open("w", encoding="utf-8") as fh:
        fh.write("doc_id\ttitle\tpages\tok\tclosure_failed\tstructure_failed\tno_text_layer\taccepted\tcoverage\tnum_recall\tnum_precision\ttable_row_recall\n")
        rows = conn.execute(
            "SELECT doc_id, title, raw_ref, parse_md_ref FROM core.document"
            " WHERE parse_engine LIKE 'textin:%%' AND superseded_at IS NULL AND parse_md_ref IS NOT NULL"
            " ORDER BY doc_id"
        ).fetchall()
        for doc_id, title, raw_ref, md_ref in rows:
            try:
                reference = blob.get(str(md_ref)).decode("utf-8")
                pages = parse_pages_local(blob.get(str(raw_ref)), structurer)
            except Exception as exc:  # noqa: BLE001 — 一份文档的传输错误不能中断整批实验
                fh.write(f"{doc_id}\t{title}\tERR:{type(exc).__name__}\t\t\t\t\t\t\t\t\t\n")
                fh.flush()
                continue
            candidate = "\n\n".join(p.markdown for p in pages if p.status == "ok")
            recall, precision = number_recall_precision(reference, candidate)
            n = len(pages)
            counts = {s: sum(1 for p in pages if p.status == s) for s in ("ok", "closure_failed", "structure_failed", "no_text_layer")}
            # accepted = 所有页都 ok。Phase B 是整份文档退回 TextIn，所以"文档接受率"比页级通过率更贴近真实节省。
            accepted = int(n > 0 and counts["ok"] == n)
            fh.write(
                f"{doc_id}\t{title}\t{n}\t{counts['ok']}\t{counts['closure_failed']}\t{counts['structure_failed']}\t{counts['no_text_layer']}\t{accepted}"
                f"\t{text_coverage(reference, candidate):.4f}\t{recall:.4f}\t{precision:.4f}"
                f"\t{table_row_recall(reference, candidate):.4f}\n"
            )
            fh.flush()
    u = structurer.usage
    print(f"{out}\n模型调用 {u.calls} 次，输入 {u.prompt_tokens} / 输出 {u.completion_tokens} tokens")
    return out


def run_research(directory: Path) -> Path:
    structurer = _structurer()
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    out = OUT_DIR / f"parse-compare-research-{date.today()}.tsv"
    with out.open("w", encoding="utf-8") as fh:
        fh.write("file\tpages\tok\tclosure_failed\tstructure_failed\tno_text_layer\taccepted\n")
        for pdf in sorted(directory.glob("*.pdf")):
            try:
                pages = parse_pages_local(pdf.read_bytes(), structurer)
            except Exception as exc:  # noqa: BLE001 — 一份文档的传输错误不能中断整批实验
                fh.write(f"{pdf.name}\tERR:{type(exc).__name__}\t\t\t\t\t\n")
                fh.flush()
                continue
            c = {s: sum(1 for p in pages if p.status == s) for s in ("ok", "closure_failed", "structure_failed", "no_text_layer")}
            accepted = int(len(pages) > 0 and c["ok"] == len(pages))
            fh.write(f"{pdf.name}\t{len(pages)}\t{c['ok']}\t{c['closure_failed']}\t{c['structure_failed']}\t{c['no_text_layer']}\t{accepted}\n")
            fh.flush()
    u = structurer.usage
    print(f"{out}\n模型调用 {u.calls} 次，输入 {u.prompt_tokens} / 输出 {u.completion_tokens} tokens")
    return out


if __name__ == "__main__":
    mode = sys.argv[1] if len(sys.argv) > 1 else "docs"
    if mode == "docs":
        run_docs()
    elif mode == "research":
        run_research(Path(sys.argv[2]))
    else:
        raise SystemExit("用法：parse_compare.py docs | research <目录>")
```

```python
# packages/ragdemo/src/ragdemo/parse/local/blocks.py
"""把逐页整理好的 markdown 转成 NormalizedBlock（与 TextIn 路径 blocks_from_detail 同一套
section_path 语义：标题不含在自己的路径里，层级跳跃时路径保持连续）。"""

from __future__ import annotations

import re
from collections.abc import Sequence

from ragdemo.adapters.announcements import NormalizedBlock

_HEADING = re.compile(r"^(#{1,6})\s+(.*\S)\s*$")


def blocks_from_pages(pages: Sequence[tuple[int, str]]) -> list[NormalizedBlock]:
    blocks: list[NormalizedBlock] = []
    stack: list[str] = []

    def add(block_type: str, content: str, page: int, level: int | None = None) -> None:
        text = content.strip()
        if not text:
            return
        section = " > ".join(stack[:-1] if block_type == "title" else stack)
        blocks.append(
            NormalizedBlock(
                ordinal=len(blocks),
                block_type=block_type,
                section_path=section,
                content=text,
                page=page,
                level=level,
            )
        )

    for page, markdown in pages:
        para: list[str] = []
        table: list[str] = []

        def flush_para(page: int = page, para: list[str] = para) -> None:
            add("paragraph", "\n".join(para), page)
            para.clear()

        def flush_table(page: int = page, table: list[str] = table) -> None:
            add("table", "\n".join(table), page)
            table.clear()

        for line in markdown.splitlines():
            if line.strip().startswith("|"):
                flush_para()
                table.append(line)
                continue
            flush_table()
            heading = _HEADING.match(line.strip())
            if heading:
                flush_para()
                level = len(heading.group(1)) - 1
                text = heading.group(2)
                del stack[level:]
                stack.append(text)
                add("title", text, page, level)
            elif not line.strip():
                flush_para()
            else:
                para.append(line)
        flush_para()
        flush_table()
    return blocks
```

```python
# packages/ragdemo/src/ragdemo/parse/local/parser.py
"""本地版面解析器：逐页 pdfplumber + 大模型整理 + 数字闭合校验。

任何一页不合格（无文字层 / 闭合失败 / 整份不是 PDF / 大模型不可用）都抛 LocalParseFallback，
由调用方整份退回 TextIn——不做"一半本地一半 TextIn"的拼接，保持产物与引擎标识一一对应。
私有材料永不送大模型（与 ADR-0008 后果 1 同一条闸门）。"""

from __future__ import annotations

import hashlib
import json

from ragdemo.parse.local.blocks import blocks_from_pages
from ragdemo.parse.local.pipeline import parse_pages_local
from ragdemo.parse.local.structure import LlmStructurer
from ragdemo.parse.textin import ParseResult, PrivateDocumentEgressBlocked, param_fingerprint
from ragdemo_core.blob import BlobStore

LOCAL_ALGORITHM_VERSION = "v1"


class LocalParseFallback(RuntimeError):
    """本地解析放弃这份文档，调用方应改用 TextIn。"""


class LocalLayoutParser:
    def __init__(
        self,
        structurer: LlmStructurer,
        blob: BlobStore,
        *,
        model: str,
        prompt_version: str = "v1",
    ) -> None:
        self._structurer = structurer
        self._blob = blob
        self._fp = param_fingerprint(
            {"algo": LOCAL_ALGORITHM_VERSION, "prompt": prompt_version, "model": model}
        )
        self.engine = f"local:{LOCAL_ALGORITHM_VERSION}+{self._fp}"

    def parse(self, file_bytes: bytes, *, owner_user: str | None = None) -> ParseResult:
        if owner_user is not None:
            raise PrivateDocumentEgressBlocked(
                "用户私有材料不得送往大模型（与 TextIn 同一条闸门，docs/adr/0008 后果 1）。"
            )
        digest = hashlib.sha256(file_bytes).hexdigest()
        json_key = f"parse/local/{digest}/{self._fp}.json"
        md_key = f"parse/local/{digest}/{self._fp}.md"
        if self._blob.exists(json_key):
            payload = json.loads(self._blob.get(json_key))
            return self._result(payload["pages"], json_key, md_key, from_cache=True, tokens=None)

        usage = self._structurer.usage
        before = (usage.prompt_tokens, usage.completion_tokens)
        try:
            pages = parse_pages_local(file_bytes, self._structurer)
        except ValueError as exc:  # extract_pages：不是有效的 PDF
            raise LocalParseFallback(str(exc)) from exc
        except Exception as exc:  # noqa: BLE001 — 大模型 / 网络任何故障都只是"退回 TextIn"
            raise LocalParseFallback(f"大模型调用失败：{type(exc).__name__}") from exc

        bad = [f"第 {p.page} 页 {p.status}" for p in pages if p.status != "ok"]
        if bad:
            raise LocalParseFallback("；".join(bad))
        page_rows = [{"page": p.page, "markdown": p.markdown, "source_text": p.source_text} for p in pages]
        if not blocks_from_pages([(r["page"], r["markdown"]) for r in page_rows]):  # type: ignore[misc]
            raise LocalParseFallback("整理后没有任何内容块")

        tokens = (usage.prompt_tokens - before[0], usage.completion_tokens - before[1])
        self._blob.put(
            json_key,
            json.dumps({"engine": self.engine, "pages": page_rows}, ensure_ascii=False).encode("utf-8"),
        )
        self._blob.put(md_key, "\n\n".join(r["markdown"] for r in page_rows).encode("utf-8"))
        return self._result(page_rows, json_key, md_key, from_cache=False, tokens=tokens)

    def _result(
        self,
        pages: list[dict[str, object]],
        json_key: str,
        md_key: str,
        *,
        from_cache: bool,
        tokens: tuple[int, int] | None,
    ) -> ParseResult:
        blocks = blocks_from_pages([(int(p["page"]), str(p["markdown"])) for p in pages])  # type: ignore[call-overload]
        return ParseResult(
            blocks=blocks,
            page_count=len(pages),
            engine_version=self.engine,
            markdown="\n\n".join(str(p["markdown"]) for p in pages),
            json_ref=json_key,
            md_ref=md_key,
            warnings=[],
            from_cache=from_cache,
            billable=False,
            llm_tokens=tokens,
        )
```

> 注：上面几处 `# type: ignore` 是因为 `page_rows` 的值类型是 `object`。若 mypy 不要求，删掉；更干净的写法是给页行定义一个 `TypedDict`（`page: int, markdown: str, source_text: str`）——实现者二选一，以 `mypy --strict` 通过为准。

```python
# packages/ragdemo/src/ragdemo/parse/routing.py
"""按文档类型在本地解析与 TextIn 之间路由。

`DocumentParser` 协议不带 doc_type，且测试里有多个自定义假解析器，所以不改协议：
新增可选协议 `DocTypeAwareParser`，`prepare_documents` 用 isinstance 判断，
普通解析器行为完全不变。"""

from __future__ import annotations

from dataclasses import replace
from typing import Protocol, runtime_checkable

from ragdemo.parse.local.parser import LocalLayoutParser, LocalParseFallback
from ragdemo.parse.textin import DocumentParser, ParseResult


@runtime_checkable
class DocTypeAwareParser(Protocol):
    def parse_for(
        self, file_bytes: bytes, *, doc_type: str, owner_user: str | None = None
    ) -> ParseResult: ...


class RoutingParser:
    def __init__(
        self, textin: DocumentParser, local: LocalLayoutParser, *, doc_types: frozenset[str]
    ) -> None:
        self._textin = textin
        self._local = local
        self._doc_types = doc_types

    def parse(self, file_bytes: bytes, *, owner_user: str | None = None) -> ParseResult:
        return self._textin.parse(file_bytes, owner_user=owner_user)

    def parse_for(
        self, file_bytes: bytes, *, doc_type: str, owner_user: str | None = None
    ) -> ParseResult:
        # 私有材料不碰本地路径（本地路径会把原文送给大模型），直接交给 TextIn 的闸门裁决。
        if doc_type in self._doc_types and owner_user is None:
            try:
                return self._local.parse(file_bytes)
            except LocalParseFallback as exc:
                result = self._textin.parse(file_bytes, owner_user=owner_user)
                return replace(result, warnings=[*result.warnings, f"local_fallback: {exc}"])
        return self._textin.parse(file_bytes, owner_user=owner_user)
```

```python
from ragdemo.parse.describer_factory import deepseek_client
from ragdemo.parse.local.structure import LlmStructurer
from ragdemo_core.blob import BlobStore


def with_local_routing(
    textin: DocumentParser, blob: BlobStore, cfg: RagdemoConfig
) -> DocumentParser:
    """开关没开、或没配大模型地址，就原样返回 TextIn 解析器——线上行为完全不变。"""
    if not cfg.parse_local_enabled or not cfg.model_base_url:

    local = LocalLayoutParser(structurer, blob, model=cfg.model_name)
    return RoutingParser(textin, local, doc_types=frozenset(cfg.parse_local_doc_types))
```
