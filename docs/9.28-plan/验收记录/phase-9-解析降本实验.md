## 5. 已知局限

- 多栏正文可能被当成表格；同一段落内两个数字互换，闭合校验检测不到（靠抽查）；表格区域遇到单段行（如"流动资产："）会被截断。
- `max_tokens=4000` 下密集页可能被截断：本次失败原因里没有出现截断类原因，被明确归因于截断的页数为 0。
- 运行器直接读 `core.document`（离线实验脚本，非 asof 视图）。
- 页级副表只记录非 ok 页，ok 页的 markdown 不落盘；抽查清单用的本地 markdown 来自第二次重跑，与首轮 TSV 不是同一批输出。
- LLM 输出非确定性（见 3.2 波动说明），指标有数个百分点的随机性。
- 页眉/页脚口径与 TextIn 不一致，会同时压低数字精确率和文本覆盖率，这部分属于对照基准的差异，而不全是本地解析的错误；但按既定门槛，结论不变。

### 9.2 结论：几乎没有改善，差异落在 LLM 波动范围内

- docs 页失败率三次为 18.3% / 17.6% / 19.8%，波动 ±1–2 个百分点，剥离没有带来可分辨的下降；research 反而 27.8% → 28.7%（+1 页，同属噪声）。**没有指标显著变好；research 失败率、接受文档数、p0 这几项轻微变差（-0.009 p0），分析如下。**
- 疑似装饰字误报页只从 8 降到 6（docs）、6 降到 5（research），仍然剩下：投资评级框 `公司级评` / `持推级维荐评`（民生证券首页评级框，不在顶带、不重复，剥不掉）、`利力能获`（华金证券，多页同样的几个字，非页眉）、表格内竖排行标签（`份及态数状种类股量` 之类，在表格区域内，按设计不剥）。这些在正文区或表格区域，按保守原则不剥，否则可能误删数据。
- 国信 46 页研报里 45 个 `证券研究报告` 页眉、东吴 `东吴证券研究所` / `请务必阅读…` 页脚都已被正确剥离（见 9.3），但这些文档剩余的失败页绝大多数是 S1（丢数字，整张图表/表被压缩）与 S2（表格未原样保留），不是页眉问题，页眉剥离对它们无作用。
- **数字精确率中位数没变（0.9474）的原因（零成本验证，不调模型）：** 把剥离前后的本地文字层直接对 TextIn 真值算数字精确率（`strip_decor` 前后）：549（12 页）0.9171 → 0.9950，551（5 页）0.9394 → 0.9764，说明对 ≥ 4 页的文档剥离确实消掉了 `688041`/年份/月份/页码；但 accepted 文档的绝大多数是 **1–3 页的公告**（552、555、556、559–562 各 2 页），按设计（< 4 页不剥）完全没有被处理，多出来的数字就是首页那一行 `688041`、年份与公告编号（如 `临2023-002` 里的 `002`），这类行每份文档只出现一次，用「重复」无法识别。所以 accepted 文档的精确率中位数由这批短公告决定，一直停在 0.947 左右。这是设计上的限制，不是剥离逻辑的缺陷。
- 文本覆盖率不变（0.952）同理：TextIn 与本地在表格展开、短公告首页头部等的差异不是页眉重复造成的。

### 9.3 剥离审计（零成本，对全部样本直接跑 `strip_decor`）

对 docs 22 份与 research 10 份逐页检查「剥离文字 + 正文文字」的非空白字符多重集合是否等于剥离前文字层：**全部 0 页不一致（无损）**。被剥内容的典型：国信 45 页 `证券研究报告`；东吴 24 页 `东吴证券研究所`、24 页 `请务必阅读正文之后的免责声明部分`、23 页 `公司深度研究`、页码 `N / 25`；华金 `公司快报/集成电路Ⅲ` + `http://www.huajinsc.cn/ N/M 请务必阅读…`；海光各期报告 `…年第X季度报告` 页眉 + `N/12` 页码；东吴有 1 页的旋转文字（共 103 条剥离项里仅 1 条为 `rotated`）。对每份文档出现次数最多的前 8 类剥离项人工过目，未见带有正文数据的情况（更长尾的剥离项未逐条核对）。

### 9.5 `stripped_text` 取舍与误剥防护

重复行按「行文本」比较，只把页码 token（`第 N 页`、`N / M`）归一化；其他数字不同的行（例如每页变化的收盘价行）视为数据，不剥（对设计稿「数字串 → #」的收窄，已有测试）；只看顶 / 底 8% 带内的行，正文区与表格区域内的行永不剥；纯页码行仅限底带，且必须整行匹配页码格式；旋转字符占全页字符超过 50% 时（横向版面）视为正文，不剥。
