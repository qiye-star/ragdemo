## 4. 实测中发现并处理的问题（都有回归测试）

1. **公告标题写法**：浪潮信息写"2025年一季度报告"（无"第"字），且有"…年度报告的专项说明""半年度财务报告"等同日附属公告——匹配规则改为认"报告名 + 允许的后缀"，附属公告不算报告本身。
2. **Wind 股东列名不稳定**：同一期别出现过"三季报前十大股东…""3季末的前十大股东…""3季末股东…"三种写法——按含期别字样的多种写法接受，期别字样对不上仍拒绝。
3. **Wind 分部响应不稳定**：列集合每次不同（有时没有占比列/总收入列、列名嵌公司简称、把"产品"写成"项目"、夹带"计算得到的毛利"派生列，某维度返回空表）——改为按列名**含义**认列，派生列一律不读。没有总收入列的响应必须靠 `fin_fact` 营收对账，两者都没有就拒绝入库。
4. **Wind 占比列会自相矛盾**（实测某地区占比 181%）：只丢占比、保留已对账的收入，并在报告里标出。
5. **CFETS 的 WAF**：`pageSize ≥ 100` 一律 403（与频率无关），固定用 50；口径归一 `100JPY/CNY`÷100、`CNY/KRW` 取倒数。
6. 春节/国庆连调休最长休市 11 天——汇率"漏取"检查阈值按实测放到 12 天，并新增"各币种对交易日集合必须一致"检查（某一对独有的缺口才是真漏取）。

## 5. 已知限制

- 仅 A 股；港股/美股实体的股东、分部、TWD 汇率另立计划。
- 股东只有 Wind 一个来源，靠响应内一致性校验 + 与已解析公告原文交叉核对；原文未解析的期别无法交叉核对。
- 分部某维度 Wind 返回空表时只入库有数据的维度（本次 000977 的地区维度即如此）。
- 全量 A 股尚未执行：`facts holders` 最多调用 Wind 449 次、`facts segments` 最多 225 次（dry run 实测，已排除无披露记录和已入库的期别）。执行前需负责人确认额度。
