# 阶段二：前十大股东 · 主营构成 · 汇率 接入计划

> **给执行者：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行。步骤用 `- [ ]` 勾选。

**目标：** 把 A 股前十大股东、主营构成（分部）、汇率三类结构化数据接进时点数据底座，每一行都能溯源到 `provider_snapshot`，且 `known_at` 不早于现实中最早可获知的时刻。

**架构：** 三张新的双时间轴事实表（`core.shareholder_holding` / `core.segment_revenue` / `core.fx_rate`）+ 各自的 `asof` 视图，沿用 `known_at / superseded_at` 规则。股东与分部由 Wind MCP 取数（Wind 只给"当前值"，不给披露日），`known_at` 用**公告目录 `core.announcement_index` 里该报告期定期报告的最早披露时刻**回填（负责人 2026-09-29 决定：同一期有多份/更正报告时取**第一次披露日**）；后来发现值变了，按"观察到的时刻"追加更正，不改写历史。汇率取中国货币网 CFETS 人民币汇率中间价（免费公开，不消耗 Wind 额度），`known_at` = 当日 09:15（北京时间）。

**技术栈：** Python 3.11、psycopg、Decimal、Wind MCP（`get_stock_equity_holders` / `get_stock_fundamentals`）、中国货币网公开接口、pytest、ruff、mypy --strict。

**依据：** `docs/9.28-plan/2026-09-28-数据底座完善总计划.md` 阶段 2 任务 2.2 / 2.5；`CLAUDE.md` §0、§1.1–1.3、§1.5；`docs/03-point-in-time.md`；`docs/9.28-plan/数据接口契约-v1.md`。

## 全局约束（每个任务都隐含）

- 时点一致：新表必带 `valid_from` / `known_at` / `superseded_at`，登记进 `core.bitemporal_registry`，建 `asof.*` 视图，`superseded_at > known_at` 有 CHECK；应用层只查 `asof`。
- `known_at` = 现实中最早可获知的时刻，**不是入库时间**（`ingested_at` 永不进 `as_of` 过滤）。找不到可信 `known_at` 的行**不入库**，记警告（与 `adapters/wind.py` 现有规则一致）。
- 计算与生成分离：币种换算、占比核对全部 Python `Decimal` 计算；不得让模型产出数值。
- 每个数字可溯源：每行带 `snapshot_id`，指向保留了原始响应的 `provider_snapshot`。
- 供应商可替换：业务代码只经适配器；每个适配器有 Mock 与契约测试（`tests/contracts/`）。
- 数据库变更走 `db/migrations/`；`ruff` + `mypy --strict`；TDD，数值计算与时点逻辑必须有单测。
- 密钥只在环境变量/出网代理层。CFETS 无需凭据，但主机要加进 `infra/egress-proxy/policy.yaml` 白名单。
- **不消耗额度的先做；Wind 调用有额度成本，试点阶段只对 688041.SH、000977.SZ 两家调用，全量调用前需负责人确认。**

## 范围

- 包含：A 股（沪深，`tushare_code` 非空的实体）股东与分部；CFETS 可覆盖币种（USD、EUR、HKD、100JPY、KRW）的汇率；换算函数。
- **不包含（另立计划，需先确认）：** 港股/美股实体的股东与分部（披露日匹配规则要另写英文/繁体标题版）；TWD 汇率（CFETS 不发布，需另选源）；财务事实的币种换算接入（2.5 的同比/TTM 部分已在 `metrics/derived.py`，这里只交付 `fx` 换算函数）。

### Task 2：报告期首次披露时刻匹配（`period_disclosure.py`）

**Interfaces — Produces:**
```python
@dataclass(frozen=True)
class Disclosure:
    known_at: datetime      # 该期定期报告在目录里最早的 known_at
    index_id: int
    title: str

def first_disclosure(conn: psycopg.Connection, entity_id: str, period: str) -> Disclosure | None: ...
def period_end_of(period: str) -> date: ...   # '2025H1'->2025-06-30, '2024FY'->2024-12-31, '2025Q1'->03-31, '2025Q3'->09-30
```

规则（A 股，标题含公司全名前缀，故用 `search` 而非锚定开头）：
- 期别 → 标题正则：`FY`: `{year}年年度报告(摘要)?`；`H1`: `{year}年半年度报告(摘要)?`；`Q1`: `{year}年第一季度报告`；`Q3`: `{year}年第三季度报告`。`{year}` 必须与期别年份一致。
- 排除：标题含 `英文|English|取消|提示性`（与 `parse_policy._NEVER_PARSE` 一致）；**不排除更正/修订**——首次披露取 `min(known_at)`，更正版不可能更早，排除反而会在原版缺失时误丢。
- 只看 `source IN ('cninfo','hkexnews')` 且**含被取代的行**（被取代只表示来源换了，不影响"最早何时可获知"）；`publish_date` 必须落在 `(period_end, period_end + 15 个月]`，挡住往年同名报告。
- 匹配不到返回 `None`，调用方不入库并记警告。

- [ ] **Step 1：失败测试** `tests/ingest/test_period_disclosure.py`（DB 测试，往 `core.announcement_index` 插行）：
  1. 同期有原版（2025-03-28）与更正版（2025-04-30）→ 返回 2025-03-28 那条；
  2. `2024年年度报告` 不匹配 `2025FY`（年份错）；
  3. `2024年半年度报告` 不被 `2024FY` 误匹配（`年度报告` 与 `半年度报告` 的边界）；
  4. 英文版被排除；
  5. 只有被取代的 ifind 行 → `None`（ifind 不在来源白名单）；
  6. 标题含前缀公司全名（`海光信息技术股份有限公司2025年第三季度报告`）能匹配；
  7. 目录里没有 → `None`；`period_end_of` 四种期别各一条。

### Task 3：整批比对写入器（`pit_tables.py`）

**Interfaces — Produces:**
```python
class Outcome(StrEnum):
    INSERTED = "inserted"; UNCHANGED = "unchanged"; REVISED = "revised"

def write_holdings(conn, *, entity_id, period, period_end, rows: Sequence[HoldingRow], known_at: datetime,
                   source_ref: str | None, snapshot_id: int, ingest_run_id: str,
                   observed_at: datetime) -> Outcome
def write_segments(...同形, rows: Sequence[SegmentRow]) -> Outcome
def write_fx(conn, *, rows: Sequence[FxRow], snapshot_id, ingest_run_id, observed_at) -> dict[Outcome, int]
```
语义：
- 该 `(entity, period)` 没有现行行 → 全部插入，`known_at` 用传入的首次披露时刻，`known_at_basis='first_periodic_report'`。
- 有现行行且**整批内容完全相同**（股东：rank/名称/股数/比例；分部：维度/名称/收入/毛利/占比，Decimal 比较）→ `UNCHANGED`，什么都不写。
- 内容不同 → 旧行 `superseded_at = observed_at`，新行 `known_at = observed_at`、`known_at_basis='revision_observed'`（不改写历史；须 `observed_at > 旧行 known_at`，否则抛 `OutOfOrderCorrection`，与 `PointInTimeWriter` 同名异常复用）。
- 汇率按 `(base, quote, rate_date)` 逐条同样处理；`known_at = rate_date 09:15+08` 由适配器给出。

### Task 4：汇率（CFETS 适配器 + 换算）

**Interfaces — Produces:**
```python
# adapters/cfets.py
@dataclass(frozen=True)
class FxRow: base_ccy: str; quote_ccy: str; rate_date: date; rate: Decimal; known_at: datetime
class CfetsAdapter:
    def fetch(self, ctx, *, pair: str, start: date, end: date) -> Iterator[RawResponse]

PAIRS = ("USD/CNY","EUR/CNY","HKD/CNY","100JPY/CNY","CNY/KRW")
```

## 风险与对策

| 风险 | 对策 |
|---|---|
