# 数据接口契约 v1（给 Agent 负责人）

> 状态：**草案，待 Agent 负责人评审定稿**（总计划阶段 1 任务 1.8）。
> 代码：`packages/ragdemo/src/ragdemo/dataapi/contract.py`（类型与 `DataApi` 协议）、
> `mock.py`（内存 Mock）、`sample.py`（样例数据集）。
> 契约测试：`tests/contracts/dataapi_contract.py`——Mock 与将来的真实实现跑同一套。

数据层只交付**只读的数据接口**。Agent、工具外壳层（参数校验、预算、审计日志）、
通用 `compute(expr)`、`write_opinion` 都不在本契约里，由 Agent 侧实现。

---

## 1. 三条对每个接口都成立的规则

1. **强制 `as_of`**。每个接口都有关键字参数 `as_of: datetime`，**必须带时区，没有默认值**。
   只返回在 `as_of` 时刻已经可知、且尚未被取代的数据（`known_at <= as_of` 且
   `superseded_at` 为空或晚于 `as_of`）。回测时物理上看不到未来。
   - `known_at` 是数据在现实中最早可被获知的时刻（公告日、收盘时刻），**不是入库时间**。
   - 盘中的 `as_of` 看不到当天收盘行情；财报在公告日当天 23:59:59 才算已知。
2. **每个数值都带溯源**。
   - 财务事实：`FactCitation` → `[metric_id | source | known_at]`，另附 `snapshot_id`
     （可回放当时的供应商原始响应）。
   - 原文内容：`BlockCitation` → `[block_id | page]`。
   - 派生值（同比等）：`inputs` 里带全部参与计算的原始事实，各自有溯源。
   - 数值一律 `Decimal`，不用 float。
3. **只读、只公开数据**。
   - 用户私有上传材料在任何接口都**不可见**（查不到，不是报错）。
   - 来源不允许展示原文（`can_show_raw = false`）时，能检索到、能拿到元数据与溯源，
     但 `content` / `preview` / `parent_content` 为 `None`。

**错误语义**：查不到 → 返回 `None` 或空列表；参数不合法（naive `as_of`、未知派生类型、
`k <= 0`、`start > end`）→ 抛 `ValueError`。

## 2. 接口一览

| 接口 | 返回 | 说明 |
|---|---|---|
| `resolve_entity(name, *, as_of)` | `list[EntityMatch]` | 全称 / 简称 / 别名 / 证券代码 → 候选实体，按置信度降序；未命中为空列表 |
| `list_entities(*, as_of, node=None)` | `list[EntityInfo]` | 实体清单；`node` 过滤三级环节 |
| `get_metric_definition(metric_id, *, as_of)` | `MetricDefinition \| None` | `as_of` 时生效的那一版口径（口径改版后，早于改版的 `as_of` 仍拿到旧版） |
| `query_fin_fact(entity_id, metric_id, *, as_of, period=None)` | `list[FactValue]` | 已知的财务事实，被更正的取更正后的值，按报告期升序 |
| `query_derived(entity_id, metric_id, kind, *, as_of, period)` | `DerivedValue \| None` | 代码计算的派生值；v1 只有 `kind="yoy"`（累计同比） |
| `get_prices(entity_id, *, start, end, as_of)` | `list[PriceBar]` | 区间内已知的日行情，按交易日升序 |
| `search_blocks(query, *, as_of, entity_ids=(), doc_types=(), k=10)` | `list[BlockHit]` | 原文检索：过滤 → BM25 + 向量 → 融合 → 重排；只返回叶子块 |
| `get_block(block_id, *, as_of)` | `BlockDetail \| None` | 原文块全文 + 所属小节全文（`parent_content`，供生成用；**引用仍用本块 block_id**） |
| `get_document(doc_id, *, as_of)` | `DocumentInfo \| None` | 文档元数据 |
| `get_relations(entity_id, *, as_of, relation_type=None)` | `list[Relation]` | 以该实体为起点或终点的产业链关系 |
| `match_rules(event_type, trigger_node, *, as_of)` | `list[PropagationRule]` | 某环节某类事件适用的传导规则（只返回启用中的） |

各返回类型的字段见 `contract.py`，每个字段都有类型注解。

### 2.1 派生值 `query_derived`

- `yoy`：本期累计值 / 上年同期累计值 − 1。A 股利润表是年初至今累计口径，累计对累计是
  标准算法。
- 算不出来时 `value = None`，原因写在 `note`：上年同期缺失、为 0、为负（亏损转盈利的
  "同比"会误导）、两期单位不一致。**不会编一个数。**
- 本期数据在 `as_of` 时还不可知 → 返回 `None`。

### 2.2 溯源的渲染格式

```text
[revenue_total | tushare | 2024-10-25T23:59:59+08:00]     # FactCitation.render()
[11 | 3]                                                   # BlockCitation.render()
```

Agent 输出里的每个数字都要能落到这两种之一，或显式标注为 `推断`（CLAUDE.md §0）。

## 3. 现在就能用：Mock

```python
from datetime import datetime, timedelta, timezone
from ragdemo.dataapi.mock import MockDataApi

api = MockDataApi()                          # 默认装载 sample.SAMPLE
as_of = datetime(2024, 11, 15, tzinfo=timezone(timedelta(hours=8)))

api.resolve_entity("海光", as_of=as_of)       # → [EntityMatch(entity_id='CN.688041', ...)]
api.query_fin_fact("CN.688041", "revenue_total", as_of=as_of)
api.query_derived("CN.688041", "revenue_total", "yoy", as_of=as_of, period="2024Q3")
api.search_blocks("DCU", as_of=as_of, k=5)
```

样例数据是**示意数据**（不是真实财务数字），但覆盖了契约要守的每一种边界：事实被更正、
口径改版、未来才公开的文档、私有上传材料、不可展示原文的来源、停用的传导规则。
Agent 侧的测试可以直接依赖它；换成真实实现时只换构造点，不改调用代码。

Mock 的检索排序只是关键词计数，不代表真实检索质量——检索质量由评测集验收
（总计划阶段 5：recall@10 > 0.80）。

## 5. 已知限制（评审时请确认可以接受）

1. **传导规则还没有版本化**：`match_rules` 接受 `as_of` 以保持接口一致，但规则本身没有
   `known_at`，任何 `as_of` 下都返回当前启用的规则。改规则会影响历史回测，与口径版本化
   （阶段 1.2）同样的问题，计划在阶段 6 前补。
2. **手工录入的实体、关系、口径有乐观偏差**：它们的 `known_at` 取录入约定的生效日，不是
   真实可知时刻（docs/03-point-in-time.md §6.3）。`Relation.citation.source` 以 `manual:`
   开头的就是手工关系，评分时应单独分组。
3. **派生值 v1 只有累计同比**：环比、TTM 需要把累计值拆成单季，阶段 2.5 以**增量**方式
   加入（`DerivedKind` 增加取值，不改已有签名）。
4. **进程内 Python 接口**：v1 不提供 HTTP 接口。若 Agent 必须跨进程调用，需要另立 ADR
   （诊断界面的 ADR-0010 只覆盖内网只读诊断，不是给 Agent 的服务接口）。

## 6. 变更规则

- 契约版本号：`ragdemo.dataapi.contract.CONTRACT_VERSION`（当前 `"1"`）。
- **增量变更**（新增接口、新增可选参数、`DerivedKind` 新增取值、返回类型新增带默认值的
  字段）：升次版本号，不破坏已有调用，提前通知 Agent 负责人。
- **破坏性变更**（改签名、删字段、改语义）：需要双方书面同意，并给出迁移期。
- 每次变更同步更新 `tests/contracts/dataapi_contract.py`——契约以测试为准，文档与测试
  冲突时改文档。
