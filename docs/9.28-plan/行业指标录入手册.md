# 行业指标手工录入手册（第三方行业报告类）

> 面向：负责把 IDC / TrendForce / LightCounting 等行业报告里的数据录成 CSV 的同事。数据会导入 `core.fin_fact`（公司口径）或 `core.industry_metric_point`（行业汇总口径）。

## 一、CSV 格式

先生成表头：`ragdemo metrics manual-template --out 行业指标.csv`，用 Excel / WPS 打开填写（另存为 **CSV UTF-8**）。列：

| 列 | 含义 | 例 |
|---|---|---|
| `metric_id` | 指标 ID，必须是下面清单里的 | `accelerator_card_shipment` |
| `entity_id` | **公司口径**填公司 ID（如 `US.NVDA`）；**行业汇总口径留空** | 留空 |
| `scope` | **行业汇总口径**填范围（`GLOBAL` / `CN` / `US` …）；公司口径留空；与 `entity_id` **恰填其一** | `GLOBAL` |
| `period` | 报告期，如 `2026Q2`、`2026H1`、`2026M07`、`2025FY` | `2026Q2` |
| `period_end` | 报告期末日，`YYYY-MM-DD` | `2026-06-30` |
| `value` | 数值。**单位必须与清单里的单位一致，不要带单位文字、千分位逗号**；比例用 0–1 小数（35% 填 `0.35`） | `1200000` |
| `unit` | 单位，必须与清单一致 | `pcs` |
| `published_on` | **报告的发布日**（不是你录入的日期），`YYYY-MM-DD`。系统据此判断“当时能不能看到这个数” | `2026-08-20` |
| `source` | 报告名称与机构 | `IDC 中国加速计算服务器市场追踪 2026Q2` |
| `source_ref` | 出处：页码 / 图表编号 / 链接 | `p.8 图3` |

## 二、导入与校验

```bash
ragdemo metrics import-manual --file 行业指标.csv        # 只校验，不写库
ragdemo metrics import-manual --file 行业指标.csv --yes  # 校验通过后写入
```

- 校验**一次列出全部问题**，有任何一行不过整批不写，改完再导入。
- 同一指标同一范围同一期重复导入：数值相同自动跳过；数值不同视为**更正**，新 `published_on` 必须**晚于**原来的，旧值保留可追溯。
- 校验会拒绝：指标不存在、推导指标（毛利率等，由代码算）、单位不一致、未来的发布日、报告期末晚于发布日、来源/出处为空、数值不是数字、同文件内重复行。
- 不同机构对同一指标口径差异大（见各指标“来源与注意”）。**同一指标请固定使用同一个来源做趋势**；换来源要另行说明，不要混录。

## 三、可录入的指标清单（`source_type = vendor_api`）

| metric_id | 名称 | 节点 | 频率 | 单位 | 定义 | 来源与注意 |
|---|---|---|---|---|---|---|
| `ai_server_shipment` | AI服务器出货量 | AI服务器 | quarterly | `pcs` | 全球及中国AI服务器季度出货台数 | 来源：IDC/TrendForce服务器报告；位置：AI服务器章节；数据商字段：无标准字段；注意：AI服务器定义门槛不一(是否含推理服务器) |
| `hbm_asp` | HBM合约价格 | HBM | monthly | `USD` | 各世代HBM的季度合约均价 | 来源：第三方研究机构价格报告；位置：存储价格月报；数据商字段：TrendForce/DRAMeXchange合约价；注意：合约价与现货价差异大;长约锁价使价格变化滞后体现 |
| `hbm_bit_shipment` | HBM 位元出货量 | HBM | quarterly | `pcs` | HBM 产品的位元出货量 | - |
| `hbm_dram_capacity_share` | HBM产能占DRAM总产能比重 | HBM | quarterly | `ratio` | HBM晶圆投片占DRAM总投片比例 | 来源：SK海力士/三星/美光法说会；位置：产能规划章节；数据商字段：需第三方测算；注意：HBM单位晶圆产出低于标准DRAM;需换算 |
| `dc_power_queue_time` | 数据中心电力接入排队时长 | IDC | semiannual | `days` | 主要市场新增数据中心并网平均等待时间 | 来源：电网公司公告与行业媒体；位置：并网章节；数据商字段：无标准字段；注意：区域差异极大;需按具体电力市场追踪 |
| `accelerator_card_shipment` | AI加速卡出货量(全球) | 云端训练芯片 | quarterly | `pcs` | 主要厂商AI加速卡年度/季度出货量 | 来源：IDC/TrendForce出货报告；位置：加速器出货章节；数据商字段：无标准字段;第三方估算；注意：各机构口径差异大;需固定单一来源做趋势 |
| `china_ai_chip_domestic_share` | 中国AI芯片国产份额 | 云端训练芯片 | semiannual | `ratio` | 国产芯片占中国AI加速卡出货或收入比重 | 来源：IDC中国AI加速器市场报告；位置：份额章节；数据商字段：无标准字段；注意：出货量口径与收入口径结论可能相反 |
| `enterprise_ssd_shipment` | 企业级 SSD 出货量 | 企业级SSD | quarterly | `pcs` | 数据中心用固态硬盘出货容量 | - |
| `optical_chip_localization_rate` | 光芯片国产化率 | 光器件与光芯片 | semiannual | `ratio` | 国产DFB/EML光芯片在光模块BOM中的占比 | 来源：行业研究与公司交流；位置：供应链章节；数据商字段：无标准字段；注意：高速率光芯片国产化率显著低于低速率 |
| `optical_module_800g_shipment` | 800G 光模块出货量 | 光模块 | quarterly | `pcs` | 800G 及以上速率光模块的出货只数 | - |
| `optical_module_highspeed_shipment` | 高速光模块出货量(800G/1.6T) | 光模块 | quarterly | `pcs` | 主要厂商高速光模块季度出货 | 来源：LightCounting/Omdia报告；位置：光模块出货章节；数据商字段：无标准字段;第三方估算；注意：代际切换期口径混乱;需区分速率 |
| `china_equipment_localization_rate` | 中国晶圆厂设备国产化率 | 晶圆制造设备 | semiannual | `ratio` | 国产设备在新增采购中的金额占比 | 来源：行业研究报告与招标公告；位置：设备招标章节；数据商字段：无标准字段;需第三方测算；注意：招标口径与实际到货口径差异大 |

| `dram_server_spot_price` | 服务器 DRAM 现货价 | 服务器内存 | daily | `USD` | 服务器用 DDR5 颗粒现货均价 | - |
| `liquid_cooling_penetration` | 液冷渗透率 | 液冷散热 | semiannual | `ratio` | 液冷方案在新增AI服务器机柜中的占比 | 来源：IDC/赛迪液冷市场报告；位置：渗透率章节；数据商字段：无标准字段;第三方估算；注意：冷板式与浸没式需分开统计 |
| `compute_rental_price` | 算力租赁报价 | 算力租赁 | monthly | `CNY` | 单卡单月的智能算力租赁报价 | - |
| `abf_substrate_utilization` | ABF 载板稼动率 | 载板 | monthly | `ratio` | ABF 载板产线的稼动率 | - |
| `open_model_derivatives` | 开源模型衍生数量 | 通用大模型 | monthly | `pcs` | 主流开源模型在模型社区的衍生模型与下载数 | 来源：模型社区公开统计；位置：模型主页；数据商字段：Hugging Face API；注意：下载数受刷量影响;衍生模型数更稳健 |

> 清单由库里的 `core.node_metric` 生成；若指标口径调整（走 `metrics import` 的版本追加），以库为准，请重新生成本表。
> 不在清单里的指标（`filing` / `announcement` / `ir_page` 类）走文档抽取，不要手工录；`derived` 类由代码计算。
