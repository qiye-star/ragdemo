## 已知局限 backlog（复核 Task 2 时登记，本轮不修）

- M1：固定的 GB 体系先后顺序（第X章 > 第X节 > 一、…）在非标准嵌套的文档里会把顶层标题压低或丢掉。
- M3：一次编号重置之后，孤立的单个条目仍可能被提升为标题。
- M4：很短的编号正文行 / 两栏"标签—数值"行会被当成标题。
- M5：很短的整行粗体句子会被当成仅粗体标题。
- M6：嵌套层数多时层级在 `MAX_LEVEL` 处塌缩。
- M7：`heading_matches_v2` 的贪心对齐可能抹掉层级证据（指标口径变更须控制者批准，不在调参范围内）。

### 复核修复（逻辑改动 / 新登记常量，均有测试）

- **A1 竖排单字列分桶**：原先按 `round(x0 / VERTICAL_X_TOL)` 分桶，x0 落在奇数整数边界两侧的字被分进不同桶、连续数永远到不了 3。改为：按 x0 排序，相邻 x0 差 > `VERTICAL_X_TOL` 处切簇，每簇按 top 排序再数连续。测试：x0 在 20.9995 / 21.0005 间抖动的"公司研究"。
- **A2 新登记常量**：`VERTICAL_PITCH_EM`（原硬编码 `3 * em`，初值 3.0，允许范围 2.0–5.0）、`VERTICAL_ISOLATION_EM`（原有，初值 2.0，允许范围 1.0–3.0）。竖排单字不再只看汉字：任何单字符词（拉丁字母 / 数字）都进入判定（原先 `REPORT`、`2026` 竖排会被并进正文行）。测试：1.6 em 的栏（常量取 1.0）、36pt 字距的 20pt 字（常量取 5.0）、拉丁与数字竖排、表格内的数字竖排不触发（整页入口先剔除表格行）。边界测试里常量用 `monkeypatch` 固定在范围内，不随调参漂移。
- **A3 逻辑改动：栏间空白带的纵向重叠规则**。原因：空白带左右两侧原本不必在纵向上相遇，"整宽正文 + 3 行收尾短行 + 3 行右对齐落款"会被判多栏。新规则：x 处跨过 x 的整宽行（横幅）不再打断，但左侧行与右侧行必须在纵向上重叠，且重叠区间内两侧各 >= `MIN_SIDE_ROWS` 行；重叠区间按行的纵向范围（top..bottom）算，不按行中点（两栏基线错位半行时按中点会各丢一行，既有测试 `test_two_columns_with_offset_baselines_are_handed_back` 守着）；重叠区间内横幅行占比 > `MAX_BANNER_SHARE`（新常量，0.5，未进调参空间）则不算空白带。"标签 — 值"两段式行同时算左右两侧各一行：`MIN_SIDE_ROWS` 行即成栏（保守，由上层降级），`MIN_SIDE_ROWS - 1` 行不成栏，有测试。
- A4：typeset 模块 docstring 去掉过时描述；转换后的测试改为断言 `reason == REASON_GUTTER`；补边界测试（2 对 3 行、14 对 15pt、区间上下沿、表格内数字竖排的反例）。
- 记录但不修（carry）：表格吸收等基线的列（图表 / 表格页由 T4 负责）；某页被退回后其余页标题层级移位（设计如此）；混排字号页的 `min_width` 以文档正文字号为准（以后再调）。
