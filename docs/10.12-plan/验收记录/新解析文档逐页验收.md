# 新解析文档逐页验收（只读测量）

日期：2026-10-13。零外部调用、零付费、不写库、不改代码。数据来源：开发库只读 SELECT、`data/blob` 里已缓存的 TextIn JSON 与原 PDF、`data/experiments/backfill-after-288p.json`。

## 1. 先说结论

- 开发库里现行的 TextIn 文档共 72 份（516 页）：此前已审计 31 份（A）、海光信息季报 3 份（B，581-583）、新解析 38 份（C，584-621）。
- **跨页表格的 P5 风险属实。** 按真实路由口径（页型由分类器给出，表块数按『表格块所在页』计），16 份文档、53 页因为『表格续页没有表块』在 P5 失败，其中 16 份文档被整份判为 rejected（A 组 8 份、B 组 3 份、C 组 5 份）。
- 只把『表块数』改成『本页有 TextIn 表格片段』之后，rejected 降到 0 份；其余文档只受 P3 数字核对影响（改后仍有 28 份 textin_unverified，见第 3 节）。建议的改法见第 8 节，本次没有改代码。
- 53 页 P5 失败**全部**是跨页表格的续页（续页有表格单元格，但库里的表块只记首页）；没有一页是分类器把普通页误判成表格页。
- 开发库已应用迁移 034（`core.parse_page_route`、`core.parse_doc_acceptance` 已建），但两张表都是 0 行；这批文档的 `doc_block.parse_source` 全是 NULL。也就是说它们是走旧路径入库（分级开关关闭），**没有写任何台账**。下面的结论是用缓存数据现算出来的。

## 2. 口径

- 页型：`page_kinds()`（`multicolumn_first=False`，与 TieredParser 一致）。
- 数字核对 P3：沿用 T8 口径（`unexpanded_text` + 对比较副本做 `heal_spacing`）。
- 表块数 P5：取库里 `core.doc_block` 现行 table 块按 `page` 计数（与解析时 `blocks_by_page` 同义，块页码即表格首页）。
- 文档结论：`build_ledger` + `verdict_for_document`，页 reasons 带 `L0 未启用` 标记（与真实路径一致）。
- 『改后 P5』= 表块数 + 本页的跨页续表数（由 TextIn 单元格自带的 page_id 数出）。这只是测量用的假设口径，代码没动。

## 8. 建议的代码改动（本次未改）

**问题**：`TieredParser._routed`（`packages/ragdemo/src/ragdemo/parse/tiered/parser.py` 约第 289 行）用 `tp.blocks_by_page[page]` 里 `block_type == 'table'` 的个数当 `table_blocks`；整份回退路径（约第 437 行）用 `Counter(b.page for b in marked if b.block_type == 'table')`。一张跨页表只有一个块，页码是首页，续页因此得 0，P5（`parse/acceptance.py::_p5`：表格页须有 table 块）判失败，文档被 rejected。

**建议**：两处都改成 `table_blocks = max(起始于本页的 table 块数, store.item_types['table'] if store else 0)`。`PageStore.item_types['table']`（`parse/textin_audit.py::split_detail_by_page`）按单元格自带的 page_id 给每个页各记一次，续页自然为 1。P5 的本意（分类器说是表格页、TextIn 却没识别出表格）仍然保留：没有任何表格单元格的页仍是 0。不要改 `_p5` 本身，也不要改库里块的页码（块页码＝首页是 `table_html`、溯源等下游的约定）。

**测试**：在 `tests/parse/tiered/test_parser.py` 补三例：(1) 页型为 table 的续页，TextIn detail 里该页只有跨页表的单元格、表块只在首页 → 该页 P5 通过，文档不为 rejected；(2) 页型为 table 但该页没有任何表格单元格 → 仍 P5 失败、文档 rejected；(3) 整份回退路径的同样断言。改完后按本报告口径复核：72 份应为 0 份因 P5 rejected（『改后 P5』栏已测得）。

**另需知晓**：改后仍有 28 份文档是 textin_unverified（P3：图片 OCR 数字、邻页归属等），与跨页表格无关，属 W2 已记录的已知问题；它们不会因此被拒收，但也不能标为 accepted。
