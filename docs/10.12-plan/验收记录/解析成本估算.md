- 可用场景只有 (a) 全部送 TextIn、(b) 扣除跳页规则的**实测**节省。

## 1000 页规划（`--budget-pages 1000`）

优先级默认：first，然后 none（新到旧），然后 second；整份文档装入、不拆；默认越过放不下的大文档继续装更靠后的小文档（`--strict-order` 则遇到第一份放不下的就停）。

- 装入 **98 份 / 1000 页 / 135.60 元**，预算恰好用完（余 0 页）。
  - first 6 份全部装入，共 38 页（5.15 元）。其中 doc 8 是 EDGAR 8-K（.htm，非 PDF），页数 12 为经验估算，实际若非 PDF 可能无法按页送 TextIn，需要在 `--yes` 前确认。
  - none 92 份 / 962 页，按公告日新到旧，自 2026-10-09 起至 2025-12-10 止；其中最大一份是 doc 319（2026-04-08，116 页）。
  - second（年报 / 半年报全文，10 份 / 1876 页）一份都装不下，全部留在剩余里。
- 严格顺序下是 96 份 / 996 页 / 135.06 元（在第一份放不下的文档处停，余 4 页）；默认模式多装 2 份 2 页文档填满。
- **剩余积压：380 份 / 5411 页 / 733.73 元**（none 370 份 / 3535 页，second 10 份 / 1876 页）。全部 478 份解析完 = 869.33 元。
- 完整逐份清单（doc_id、公告日、页数、累计页、累计元）运行命令即得，输出为确定性（同日按 doc_id 升序）。

## 逐页台账

开发库未应用迁移 034（`core.parse_page_route` 不存在），`--month` 的台账汇总（启用前后每页成本、L0 页未溯源数字率）本次跳过并如实提示；库迁移后同一命令会输出（方法见计划 T12：缓存命中的 L3 页按计费页算）。

## 不确定性

1. **单价**：0.1356 元/页是 257 页的实测估算，待发票复核；单价 ±10% 对应全积压 782.40 ~ 956.26 元，1000 页对应 122.04 ~ 149.16 元。月度花费的权威仍是 `provider_snapshot`。
2. **页数**：pypdf 实测，但 TextIn 实际计费页可能与 pypdf 页数略有差异（页拆分、失败重试、缓存命中不计费），未量化；1 份文档（EDGAR 8-K）页数为估算。
3. **节省**：场景 b 无实测值，不估；c1 / c2 是计划表既有份额（0.3579 / 0.564）机械套到积压上，L0 当前关闭，只是"如果有一个通过验证的 L0"的量级。
4. 本命令的 first / none / second 档位来自标题规则 `parse_tier`（既有口径），档位误判会改变优先级顺序但不改变总页数。
5. 1000 页额度是否已到账**待用户确认**；规划只是估算，不触发任何解析。
