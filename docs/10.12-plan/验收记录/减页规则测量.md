## 补充探测的事先口径（运行前追加，之后不改）

- **墨迹像素：** 用 pypdfium2 以 100 dpi 渲染页面，灰度 < 180 的像素占整页比例记为墨迹比。`blank_page` 命中页的墨迹比 > 0.5% 视为"疑似有内容"，逐页渲染成图目检；确认有实质内容的，`blank_page` 标 `not enabled`（只能否决，不放宽门槛）。
- **无文字层有绘制对象的页：** 文字层字符数 = 0 且存在 image / curve / rect / line 的页，按"含哪类对象"分组计数；其中被 `blank_page` 命中的（即只有 rect/line 或无对象）单列，并全部渲染测墨迹比。
- **D3 口径：** 标题含"摘要"的积压文档，若同实体存在标题去掉"摘要"后相同的另一份文档（任意状态），记为"摘要与全文并存"。
- **D4 口径：** 积压公告中文字层字符数为 0 的页占全部页的 100% 的文档。
- **D5 口径：** `tier_for_document(...) == NONE`，按 `force_whole_document_l3` 分定期 / 非定期。

## 补充探测（按事先登记口径）

1. **无文字层页的绘制对象分布：** 全语料文字层字符数 = 0 的页共 724 页，**全部含图片或曲线**（723 页含 image，1 页含 curve）；无文字层且只有 rect/line 或无对象的页 = **0**。这 724 页**没有一页被 `blank_page` 命中**（规则排除了 image 与 curve），其中 723 页墨迹比 > 0.5%（渲染确有内容），因此矢量描边文字 / 扫描页被误判空白的风险在本语料中**没有出现**。注意：这是"本语料无此类页"的结论，不是"规则对该类页永远安全"的证明（仅 rect/line 绘制的页 `blank_page` 不排除）。
2. **`blank_page` 命中页的真实内容：** 命中 43 页（积压 42 + 验证 1），渲染成功 43，**文字层字符数 = 0 的命中页为 0**——命中的全是有少量文字的稀疏页，没有一页是真空白。墨迹比 > 0.5% 的 3 页（P:125:1、P:283:1、P:423:1）目检为**章程封面页**（公司名、"章程"、中文数字日期）。其余 40 页（墨迹比 0.02%–0.34%）渲染成拼图目检：为**落款页**（公司或董事会名称加日期，日期多为阿拉伯数字，被 `_DATE` 剥离后不计数字）、"特此公告。"、"单位：万元"页眉、"备查文件"条目、独立董事署名行等。**这些页携带可检索的文字与日期，不是空白。**
3. **按事先登记的否决口径：`blank_page` 标 `not enabled`。** 即使 G-S1 / G-S2 与上述无关，这条规则的命中集合里没有真正空白的页，名字与实际不符，强制执行会丢掉落款日期、单位说明、封面标题。
