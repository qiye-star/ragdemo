## 6. 页型普查（可复现脚本）

日期：2026-10-13。命令（只读，不调付费接口；约 3 分钟，4 进程）：

```
set -a && . ./.env && set +a && uv run --no-sync python scripts/parse_probe.py census
```

输出 `data/experiments/parse-census-<日期>.tsv`（gitignored；只有文档键 + 各页型页数，无正文）与打印汇总。实现：`ragdemo.parse.tiered.census`
（`classify_pages` / `summarize` / `is_periodic_report` / `force_whole_document_l3`）。

**范围**：库内全部现行（`superseded_at IS NULL`）有 PDF 的公告类文档 511 份（688041 与 000977 都含；已解析与未解析都含，edgar `.htm` 除外）+ `docs/rawdata/**/research/` 的 91 份研报。
共 602 份；超过 250 页跳过 0 份；pdfplumber 读取失败 1 份（doc_id 352，与第 5 节一致）。

**口径**：普查**代理**，不是 L0 v2 的 `classify_page`——无装饰剥离、无图表检测，故不产出 `chart_unresolved`。顺序按裁决 U-D3：
无文字层 → 财务报表页（`is_financial_statement_page`）→ 表格（`find_table_regions` 或疑似表格行：行内 ≥ 2em 空隙切出 ≥ 2 段且 ≥ 2 个数字，连续 ≥ 2 行；
常量与 L0 v2 计划同值，`tablelike_run` 落地前先在 census.py 近似）→ 多栏（`detect_columns` 或非水平文字）→ 纯文字。
分组：按库内标题识别定期报告（`doc_type` 为 annual_report / quarterly，或标题命中年报 / 半年报 / 季报，摘要也算，见 U-D6）为「定期报告」，其余为「非定期公告」。

| 组 | 文档 | 页 | 无文字层 | 财务报表页 | 表格 | 多栏 | 纯文字 |
|---|---|---|---|---|---|---|---|
| 非定期公告 | 480 | 4348 | 793（18.2%） | 40（0.9%） | 616（14.2%） | 446（10.3%） | 2453（56.4%） |
| 定期报告 | 30 | 2195 | 1（0.0%） | 558（25.4%） | 823（37.5%） | 144（6.6%） | 669（30.5%） |
| 研报 | 91 | 596 | 7（1.2%） | 90（15.1%） | 276（46.3%） | 55（9.2%） | 168（28.2%） |
| 路由范围（非定期公告 + 研报） | 571 | 4944 | 800（16.2%） | 130（2.6%） | 892（18.0%） | 501（10.1%） | 2621（53.0%） |

路由计划 T7 输入（路由范围）：`scan_share` = 0.1618；`statement_share`（财务报表页 / 有文字层页）= 0.0314。

**发现**
- 定期报告识别：库内 30 份被识别为定期报告（其中 19 份是摘要 / 季报，11 份是整份年报 / 半年报 / 半年度财务报告）。盘点第 3 节"> 200 页未分类"的 3 份（219 / 231 / 213 页，doc_id 145 / 325 / 413）全部找到，均为 `doc_type=announcement` 的年度报告；半年报 166–174 页的（doc_id 77 / 299 / 376，另有 124–157 页的 211 / 210 / 462）也全部找到。另有 196、197 页的年报（doc_id 259、487）。
  也就是说 U-D6 所指的漏判确实存在，且 doc_type 无法发现它们；仅靠 `doc_type` 会让这 11 份约 1900 页按页路由。
- 无文字层页高度集中：路由范围 800 页里 510 页来自 4 份整份扫描的文档（doc_id 242 / 366 / 422 / 498，115–152 页，100% 无文字层）。若按文档计，有文字层的文档几乎都没有扫描页；L2 / OCR 的规模取决于这 4 份。
- 与风险评估 §3.1 的 307 份（仅 688041、按文件名）普查相比：无文字层 15.9% → 18.2%，纯文字 57.1% → 56.4%，表格（坐标 + 疑似）15.0% → 14.2%，多栏 10.6% → 10.3%，财务报表页 1.3% → 0.9%；定期报告的财务报表页 23.1% → 25.4%。总体一致，差别来自加入 000977 与全部现行文档。

**用途与局限**：这是描述性的积压页数统计，**不是调参输入**——没有任何常量依据它选取；留出集文档包含在这个全体普查里，因此它也不能当作任何留出集结果使用。
纯文字页数是代理（无装饰剥离、无图表检测），方向不确定：图表页本可进 L0，但图表碎片也会把页推成多栏 / 表格。
