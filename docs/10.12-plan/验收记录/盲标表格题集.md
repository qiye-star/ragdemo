# 盲标表格题集（2026-10-14）

## 1. 为什么要这套题

现有 100 道自动题（`auto:`）里的 29 道表格题，是模型看着“表格描述 + 正文”写出来的。新的重排输入（`rerank_rich_input`）正好把表格描述喂给重排模型，所以 `table/auto` 上 R@10 0.62 → 0.79、MRR 0.27 → 0.69 的涨幅有一部分是“自己出题自己考”（见 `重排输入改造评测.md` §5、`表格评测基线.md`）。计划原定由人来写 50 道表格题（U2），用户改为**由模型出题、独立复核**。这套题就是 U2 的替代品，但**不是人工题**，作者如实记为 `blindmodel:tbl-v1`。

## 2. 怎么做的

**出题（第一遍）。** 只看表格原文：`core.doc_table.grid` 的单元格（行、列、页码、文字），并逐个数值核对源 PDF 文字层。**没有读任何表格描述（`content_desc`）**。按分析师的说法提问，不照抄表格标签：例如“研发上一共投入了多少钱”“7 到 9 月这一季”“资本开支（购建长期资产付出的现金）”“分红和支付利息一共花了多少现金”。每题记录答案单元格 `[block_id | page | r行c列]`、行标签、列标签、数值、单位。已被自动题当作出题源的表格块不选作出题源（与计划 T3 的“两套题互相独立”一致）。

**复核（第二遍）。** 另起一个独立的模型会话，只拿到 62 道题的文字，**看不到第一遍的答案和 gold 块**，也不许读表格描述。它从库里和源 PDF 重新找答案，列出所有能回答该题的现行块（包括同一数字出现在后一期报告的“上年同期”列、利润表、业绩快报正文、律师法律意见书段落等），并标出含糊、标签泄漏、错误来源、无法回答等问题。

**合并规则。** 只保留两遍答案一致的题；复核标出问题的题，改写后再交复核方确认，不通过就删除。

## 6. 怎么用

```bash
# C1（免费）
uv run --no-sync ragdemo eval run --models mock --no-rerank --w-vec 0 --author-prefix blindmodel: --label tbl-blind-C1
# C2（付费，需批准；重排输入开关前后各一次才能检验循环论证问题）
uv run --no-sync ragdemo eval run --models siliconflow --rerank --vector-backend pg --author-prefix blindmodel: --label tbl-blind-C2-off
uv run --no-sync ragdemo eval run --models siliconflow --rerank --vector-backend pg --rerank-rich-input --author-prefix blindmodel: --label tbl-blind-C2-rich
```

`--author-prefix blindmodel:` 用 `author LIKE 'blindmodel:%'` 选题，正好选中这 62 条，不会混进 `auto:` 题。

## 7. 需要注意的地方

1. **不是人工题。** 出题和复核都是模型，只是两次独立会话。两遍用的是同一类模型，可能犯同样的错（例如对“单季”和“累计”的理解一致地偏），独立性比人工 + 模型弱。
2. **分组名会显示成 `table/human`。** `evals/grouping.py` 把凡是不以 `auto:` 开头的作者都归为 `human`，所以这套题在 `eval run` 的分组输出和 `table-gate` 里叫 `table/human`（n=62）。计划写死的 `table/human` 门槛是按 n=50 定的（允许降 2 题）。要不要给 `blindmodel` 单开一个分组、门槛怎么定，需要负责人决定；本次没有改分组代码。
3. **不带 `--author-prefix` 的 `eval run` 现在会跑 162 题**（100 道 auto + 62 道盲标），总体指标与以前的运行不可比。以前的基线都带了 `--author-prefix auto:`，不受影响。
4. **公司集中。** 语料里有表的只有海光、浪潮和一份英伟达 8-K，海光占 74%。三大报表题各 4 道，样本少；按计划 n<10 的子类只报告、不判门槛。
5. **数据本身的一个异常，照原样保留。** B44：2024 年报摘要里李金阳期末持股是 65,742,946 股，而 2024 年三季报、2025 年三季报、2026 年一季报都是 65,732,946 股。两遍都核对了 PDF，年报摘要确实印的是 65,742,946，所以题目按原文给答案。
6. **口径相近的数字不算 gold。** B09 问浪潮 2024 年一季度营业收入的**调整后**数字，2024 年报分季度表里的 1,760,657.48 万元是调整前口径，不算答案；B21 问快报口径，年报审定数 1,437,688.95 万元不算。
