# 解析分级路由（L0 本地文字层 → L1 自托管引擎 → L2 双引擎一致 → L3 TextIn，按页降级）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行本计划。步骤用复选框（`- [ ]`）跟踪；每个任务结束必须有独立可测的产物并单独提交。

**Goal:** 把文档解析从"整份文档要么本地、要么 TextIn"改为**逐页四级路由**：文字层完好的页走 L0（pdfplumber + 大模型排版 + 闭合校验，已实现），L0 不合格的页走 L1（自托管开源引擎，结果对 PDF 文字层做溯源校验），无文字层的扫描页走 L2（两个独立引擎数字多重集完全一致才采用），其余（财务报表页、校验失败页、L2 不一致页）走 L3（TextIn）。目标是在**不放松"每个数字可溯源"**的前提下，把研报与公告的单页解析成本从约 0.14 元降到 ≤ 0.05 元。

**Architecture:** 新增 `packages/ragdemo/src/ragdemo/parse/tiered/` 包。`route.route_page` 对每一页独立决策（L0 复用 `parse/local` 的 `parse_page_local`，L1/L2 经统一的 `PageEngine` 协议调用跑在本地 docker 的引擎薄壳，L3 把需要 TextIn 的页按连续段切成子 PDF 交给现有 `TextInParser`）；`blocks.assemble_blocks` 把各级产物按页拼成 `NormalizedBlock` 并统一重建 `section_path`；`parser.TieredParser` 实现现有 `DocumentParser` 协议并新增 `parse_for(doc_type=...)`，由 `prepare_documents` 按文档类型调用；逐页路由决策写旁路 JSON（对象存储）与新表 `core.parse_page_route`（迁移 028），支撑审计、各级占比统计、月度费用与告警。全部开关默认关闭，关闭时线上行为与今天逐字节一致。

**Tech Stack:** Python 3.11、pdfplumber（已用）、pypdf（已用，切单页/子 PDF）、pypdfium2（渲染页图，仅 L2 视觉接口用）、PaddleOCR 3.x（PP-StructureV3，容器内）、MinerU（容器内，许可核查通过才用）、Docling（容器内，仅对照）、通义千问视觉版（经出网代理，仅作 L2 的一路）、现有 `HttpClient` / `TextInParser` / `ops.alerts.raise_alert`、ParadeDB 迁移、pytest、ruff、mypy --strict。

**Spec:**
- `CLAUDE.md` §0（每个数字可溯源、数据境内）、§1.2（计算与生成分离）、§1.4（评测驱动）、§1.5（供应商可替换）、§3（TDD、契约测试、密钥、迁移）。
- `docs/adr/0008-textin-xparse-document-parsing.md`（TextIn 为主解析器；本计划落地时新增 ADR-0015 修订其适用范围，年报/季报条款不变）。
- `docs/adr/0014-research-reports-internal-retrieval-only.md`（研报不展示原文、不得对外分发——决定了研报不送视觉大模型）。
- `docs/9.28-plan/2026-09-30-解析降本计划.md`（Phase A 已落地：`parse/local/` 全部模块与 `scripts/parse_compare.py`；Task 8 未执行；Phase B 由本计划重写）。

## Global Constraints

- **每个数字必须可溯源（CLAUDE.md §0）——任何一级都不得放松。** 有文字层的页：L0 走已有的数字闭合 + 字符闭合 + 表格原样检查；L1 走 `verify_against_text_layer`（数字双向闭合、关键字双向闭合、双向文字覆盖率）。无文字层的页：没有原文可对照，只能用 L2 的 `verify_dual`（两路数字多重集完全相等、关键字多重集相等、表格行互相完全召回）替代；做不到就走 L3。**单一引擎在无文字层页上的输出永远不采用。**
- **计算与生成分离（§1.2）：** 大模型（L0 的 DeepSeek、L2 的视觉接口）只排版/转写，不产生数值；它们的输出与其他数字一样必须过校验。视觉大模型**不得单独采用**（会编造数字），只能作为 L2 的一路。
- **数据境内（§0）：** 原始文档只允许发往：本机 docker 内的自托管引擎（引擎容器所在网络 `internal: true`，运行期无外网）、DeepSeek（已在用，经出网代理 8086）、TextIn（已在用，经 8081）、通义千问视觉版（新增，境内，经出网代理 8087，**仅公告**）。境外 SaaS（LlamaParse、Reducto、Extend、Mistral Document AI、Mathpix）**一律排除**，不写适配器、不进白名单。
- **研报（`research_report`）不送视觉大模型。** ADR-0014 规定研报"不得对外分发"；TextIn 是 ADR-0014 决定 5 已接受的处理方，视觉接口不是。研报的扫描页只能用两个**自托管**引擎做 L2，否则走 L3。
- **用户私有材料（`owner_user` 非空）不进入分级路由**，原样交给 TextIn 的私有闸门裁决（ADR-0008 后果 1），本计划不改这条闸门。
- **年报 / 季报（`annual_report` / `quarterly`）整份永远走 L3。** 配置校验直接拒绝把它们放进 `PARSE_TIERED_DOC_TYPES`。推翻条件：实测证明开源引擎在中文财报跨页合并表上不输 TextIn，并新增 ADR 推翻 ADR-0008 的对应条款——本计划**不做**这件事。对其他文档类型，识别为财务报表的页（`is_financial_statement_page`）也强制 L3。
- **供应商可替换（§1.5）：** 业务包（`packages/`）不得 import 任何引擎 SDK（paddleocr / mineru / docling / dashscope）。引擎 SDK 只出现在 `infra/parse-engines/<engine>/server.py`（容器内薄壳）。每个适配器有 Mock 实现与 `tests/contracts/` 契约测试。
- **密钥只在环境变量 / 出网代理层：** 视觉接口密钥 `VISION_MODEL_API_KEY` 只出现在 `egress-proxy` 容器环境与 `.env`，由 `infra/egress-proxy/policy.yaml` 注入；业务进程只知道回环地址。自托管引擎无密钥。
- **TDD（§3）：** 校验、路由、费用估算、块转换、配置校验全部先写失败测试。数值相关函数（费用、占比、指标、门槛）没有例外。
- **评测驱动（§1.4）：** 改解析层（T15 打开开关）前后必须跑 `eval_retrieval` 并把数字贴进 PR；GO/NO-GO 门槛在 T7 里**事先写死**，不得事后调整。`eval_extraction` 与观点评分目前**没有运行器**（`db/migrations/005_opinions_evals_audit.sql` 只有表），PR 中如实写"N/A：无运行器"，见"开放问题"。
- **数据库变更只走 `db/migrations/`：** 当前最新迁移是 `027_research_source_registry.sql`，本计划新增 `028_parse_page_route.sql`。
- **不批量重解析已入库文档**（会使评测集 `gold_block_ids` 失效）；分级路由只对新文档生效。改引擎版本 / 校验阈值会改变 `tiered:` 引擎指纹，同样只影响之后的新文档。
- **`ruff` + `mypy --strict` 必须通过**；Python 3.11+，类型注解完整。底层包 `ragdemo-core` 不得 import 业务层（本计划只改业务层）。
- **许可：** 不引入 PyMuPDF（AGPL-3.0）。引擎许可在 T1 核查；出现 AGPL / GPL / 非商用条款的组件不得进入生产路由，除非负责人书面裁决（见 T6）。
- **时点（§1.1）：** `core.parse_page_route.routed_at` 是运维时间（解析实际发生时刻），只用于费用与告警汇总，**永远不进入 `as_of` 过滤**；这张表不登记 `core.bitemporal_registry`（与 `core.parse_tier_policy` 同理，见迁移 015 的注释）。
- 用户偏好：文档与回答用中文。

```python
"""前置探测的纯逻辑（解析分级路由计划 T1）：扫描页占比统计与"L2 是否推迟"的判定。

门槛事先写死在这里，不得在看到数据后调整：两个比例任一达到门槛就建 L2（双引擎一致），
否则推迟——扫描页直接走 L3（TextIn），L1 只做有文字层页的版面与表格。"""

from __future__ import annotations

from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from typing import Literal

SCAN_PAGE_RATIO_MIN = 0.02  # 无可用文字层的页 / 总页数
SCAN_DOC_RATIO_MIN = 0.05  # 含 >= 1 个无可用文字层页的文档 / 总文档数


@dataclass(frozen=True)
class ScanSummary:
    docs: int
    pages: int
    no_text_pages: int
    cid_pages: int
    docs_with_no_text: int

    @property
    def page_ratio(self) -> float:
        return self.no_text_pages / self.pages if self.pages else 0.0

    @property
    def doc_ratio(self) -> float:
        return self.docs_with_no_text / self.docs if self.docs else 0.0


def summarize_scan(reasons_by_doc: Mapping[str, Sequence[str | None]]) -> ScanSummary:
    """reasons_by_doc：文档 → 逐页 `needs_handback` 的结果（None = 文字层可用）。"""
    pages = sum(len(r) for r in reasons_by_doc.values())
    bad = [x for r in reasons_by_doc.values() for x in r if x is not None]
    cid = sum(1 for x in bad if "cid" in x)
    docs_bad = sum(1 for r in reasons_by_doc.values() if any(x is not None for x in r))
    return ScanSummary(len(reasons_by_doc), pages, len(bad), cid, docs_bad)


def l2_decision(s: ScanSummary) -> Literal["build_l2", "defer_l2"]:
    if s.page_ratio >= SCAN_PAGE_RATIO_MIN or s.doc_ratio >= SCAN_DOC_RATIO_MIN:
        return "build_l2"
    return "defer_l2"
```

```python
    print("docker:", _run(["docker", "info", "--format", "{{.ServerVersion}} cpus={{.NCPU}} mem={{.MemTotal}}"]))

    """named：(文档名, 分组键, PDF 字节)。分组键是 doc_type（scan-db）或 "rawdata"（scan）。"""

            fh.write(f"{name}\t{group}\t{len(reasons)}\t{len(bad)}\t{sum(1 for r in bad if 'cid' in r)}\n")

    print(f"门槛：页占比 >= {SCAN_PAGE_RATIO_MIN} 或文档占比 >= {SCAN_DOC_RATIO_MIN} 则建 L2")

        s = summarize_scan(docs)
        print(f"[{group}] docs={s.docs} pages={s.pages} no_text={s.no_text_pages} cid={s.cid_pages}"
              f" page_ratio={s.page_ratio:.4f} doc_ratio={s.doc_ratio:.4f}")
```

```python
"""逐页路由记录。不依赖 parse 包内任何模块（textin.py 会导入它，避免循环）。"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any, Literal, cast

Tier = Literal["L0", "L1", "L2", "L3"]
TIERS: tuple[Tier, ...] = ("L0", "L1", "L2", "L3")


@dataclass(frozen=True)
class PageRoute:
    page: int  # 原文档页码，从 1 起
    tier: Tier  # 最终采用的层级
    engine: str  # local_llm:<模型+prompt> / <引擎>:<版本> / <主>:<版本>+<副>:<版本> / textin
    text_layer: bool  # 这一页是否有可用文字层
    reasons: tuple[str, ...] = ()  # 逐级降级原因，按尝试顺序
    elapsed_ms: int = 0  # 路由耗时（不含 L3 的 TextIn 调用）
    local_engine_calls: int = 0  # 自托管引擎调用次数（费用按页摊销用）
    llm_tokens: tuple[int, int] = (0, 0)  # L0 大模型 (输入, 输出)，含失败的尝试
    vision_tokens: tuple[int, int] = (0, 0)  # L2 视觉接口 (输入, 输出)
    textin_billed: bool = False  # 这一页这次是否真的向 TextIn 计费（缓存命中为 False）

    def __post_init__(self) -> None:
        if self.page < 1:
            raise ValueError(f"页码必须从 1 起，收到 {self.page}")
        if self.tier not in TIERS:
            raise ValueError(f"未知层级 {self.tier!r}")
        if self.elapsed_ms < 0:
            raise ValueError(f"耗时不能为负：{self.elapsed_ms}")


def route_to_dict(r: PageRoute) -> dict[str, object]:
    return {
        "page": r.page,
        "tier": r.tier,
        "engine": r.engine,
        "text_layer": r.text_layer,
        "reasons": list(r.reasons),
        "elapsed_ms": r.elapsed_ms,
        "local_engine_calls": r.local_engine_calls,
        "llm_tokens": list(r.llm_tokens),
        "vision_tokens": list(r.vision_tokens),
        "textin_billed": r.textin_billed,
    }


def route_from_dict(d: Mapping[str, Any]) -> PageRoute:
    llm = d.get("llm_tokens") or [0, 0]
    vision = d.get("vision_tokens") or [0, 0]
    return PageRoute(
        page=int(d["page"]),
        tier=cast(Tier, str(d["tier"])),
        engine=str(d["engine"]),
        text_layer=bool(d["text_layer"]),
        reasons=tuple(str(x) for x in d.get("reasons") or []),
        elapsed_ms=int(d.get("elapsed_ms") or 0),
        local_engine_calls=int(d.get("local_engine_calls") or 0),
        llm_tokens=(int(llm[0]), int(llm[1])),
        vision_tokens=(int(vision[0]), int(vision[1])),
        textin_billed=bool(d.get("textin_billed")),
    )
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/engines.py
"""页级解析引擎的统一接口（CLAUDE.md §1.5：业务代码不 import 任何引擎 SDK）。

引擎只回答"这一页转写成什么 markdown"；采不采用由 verify.py 的校验决定。"""

from __future__ import annotations

import re
import time
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Final, Protocol, runtime_checkable

from ragdemo.parse.local.layout import extract_pages

VISION_ENGINE_NAME: Final = "qwen_vl"

_MD_IMAGE = re.compile(r"!\[[^\]]*\]\([^)]*\)")
_HTML_IMG = re.compile(r"<img\b[^>]*>", re.IGNORECASE)


class EngineError(RuntimeError):
    """这一页这个引擎给不出可用结果（坏文件、空输出、截断、内容过滤）。路由器据此降级。"""


class EngineUnavailable(EngineError):
    """引擎服务不可达 / 超时 / 5xx。与 EngineError 一样降级，另计入告警。"""


@dataclass(frozen=True)
class EngineOutput:
    markdown: str
    elapsed_ms: int
    prompt_tokens: int = 0
    completion_tokens: int = 0


@runtime_checkable
class PageEngine(Protocol):
    name: str
    version: str

    def parse_page(self, page_pdf: bytes, *, page_no: int) -> EngineOutput: ...


def strip_images(markdown: str) -> str:
    """引擎输出里的图片引用（文件名常带坐标数字）不是正文；进校验前必须去掉，
    否则会被当成"凭空出现的数字"，造成误拒。"""
    return _HTML_IMG.sub("", _MD_IMAGE.sub("", markdown))


class MockPageEngine:
    """离线测试用：默认回显单页 PDF 的文字层；可按页指定回复、失败或整体不可达。"""

    def __init__(
        self,
        name: str = "mock",
        version: str = "1",
        *,
        replies: Mapping[int, str] | None = None,
        fail_pages: frozenset[int] = frozenset(),
        unavailable: bool = False,
        tokens: tuple[int, int] = (0, 0),
    ) -> None:
        self.name = name
        self.version = version
        self._replies = dict(replies or {})
        self._fail_pages = fail_pages
        self._unavailable = unavailable
        self._tokens = tokens
        self.calls: list[int] = []

    def parse_page(self, page_pdf: bytes, *, page_no: int) -> EngineOutput:
        t0 = time.perf_counter()
        if self._unavailable:
            raise EngineUnavailable(f"{self.name} 不可达（mock）")
        if page_no in self._fail_pages:
            raise EngineError(f"{self.name} 第 {page_no} 页失败（mock）")
        if page_no in self._replies:
            text = self._replies[page_no]
        else:
            try:
                layouts = extract_pages(page_pdf)
            except ValueError as exc:
                raise EngineError(str(exc)) from exc
            if len(layouts) != 1:
                raise EngineError(f"期望单页 PDF，收到 {len(layouts)} 页")
            text = layouts[0].text
        self.calls.append(page_no)
        elapsed = int((time.perf_counter() - t0) * 1000)
        return EngineOutput(strip_images(text), elapsed, self._tokens[0], self._tokens[1])
```

```python
"""切单页 / 子 PDF（pypdf，BSD-3-Clause）。引擎按页调用，TextIn 按连续段调用。"""

from __future__ import annotations

import io
from collections.abc import Sequence

from pypdf import PdfReader, PdfWriter


def _reader(pdf_bytes: bytes) -> PdfReader:
    try:
        reader = PdfReader(io.BytesIO(pdf_bytes))
        _ = len(reader.pages)
    except Exception as exc:  # noqa: BLE001 — pypdf 对坏文件抛多种异常，统一成一句能看懂的话
        raise ValueError(f"不是有效的 PDF：{exc}") from exc
    return reader


def sub_pdf(pdf_bytes: bytes, pages: Sequence[int]) -> bytes:
    reader = _reader(pdf_bytes)
    total = len(reader.pages)
    if not pages:
        raise ValueError("页码列表为空")
    bad = [p for p in pages if not 1 <= p <= total]
    if bad:
        raise ValueError(f"页码越界：{bad}（共 {total} 页）")
    writer = PdfWriter()
    for p in pages:
        writer.add_page(reader.pages[p - 1])
    buf = io.BytesIO()
    writer.write(buf)
    return buf.getvalue()


def single_page_pdf(pdf_bytes: bytes, page_no: int) -> bytes:
    return sub_pdf(pdf_bytes, [page_no])
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/verify.py
"""分级路由的溯源校验（CLAUDE.md §0：每个数字可溯源）。

- 有文字层的页：引擎输出必须与 PDF 文字层数字双向闭合、关键字双向闭合、文字双向覆盖。
  （L0 另有自己更严的字符闭合与表格原样检查，在 parse/local/structure.py。）
- 无文字层的页：没有原文可对照，用两个独立引擎互相对照替代——数字多重集完全相等、
  关键字多重集相等、表格行互相完全召回。阈值写死在这里并进入引擎指纹。"""

from __future__ import annotations

from collections import Counter
from dataclasses import dataclass
from typing import Final

from ragdemo.parse.local.compare import plain_text_from_markdown, table_row_recall, text_coverage
from ragdemo.parse.local.number_closure import closure_violations, numbers_in

VERIFY_VERSION: Final = "v1"
TEXT_LAYER_MIN_COVERAGE = 0.97
DUAL_MIN_COVERAGE = 0.90
# 单位、百分号、方向词、中文数字：OCR 认错这些字，数字全对也会把意思改反。
CRITICAL_CHARS: frozenset[str] = frozenset("亿万千百十元%‰增减升降涨跌负亏盈零〇一二三四五六七八九两")


@dataclass(frozen=True)
class Verdict:
    ok: bool
    reasons: tuple[str, ...] = ()


def _content(text: str) -> str:
    return "".join(ch for ch in text if ch.isalnum())


def _critical(text: str) -> Counter[str]:
    return Counter(ch for ch in text if ch in CRITICAL_CHARS)


def critical_char_violations(structured: str, source: str) -> list[str]:
    src, out = _critical(source), _critical(structured)
    return sorted(ch for ch, c in out.items() if c > src.get(ch, 0))


def verify_against_text_layer(candidate_md: str, page_text: str) -> Verdict:
    plain = plain_text_from_markdown(candidate_md)
    if not _content(plain):
        return Verdict(False, ("引擎输出为空",))
    reasons: list[str] = []
    invented = closure_violations(plain, page_text)
    lost = closure_violations(page_text, plain)
    if invented:
        reasons.append(f"凭空数字：{invented}")
    if lost:
        reasons.append(f"丢失数字：{lost}")
    added = critical_char_violations(plain, page_text)
    missing = critical_char_violations(page_text, plain)
    if added:
        reasons.append(f"关键字新增：{''.join(added)}")
    if missing:
        reasons.append(f"关键字丢失：{''.join(missing)}")
    fwd = text_coverage(_content(page_text), _content(plain))
    back = text_coverage(_content(plain), _content(page_text))
    if fwd < TEXT_LAYER_MIN_COVERAGE:
        reasons.append(f"文字覆盖率 {fwd:.4f} < {TEXT_LAYER_MIN_COVERAGE}")
    if back < TEXT_LAYER_MIN_COVERAGE:
        reasons.append(f"反向覆盖率 {back:.4f} < {TEXT_LAYER_MIN_COVERAGE}（多出了原文没有的文字）")
    return Verdict(not reasons, tuple(reasons))


def verify_dual(primary_md: str, secondary_md: str) -> Verdict:
    a, b = plain_text_from_markdown(primary_md), plain_text_from_markdown(secondary_md)
    if not _content(a) or not _content(b):
        return Verdict(False, ("至少一路输出为空",))
    reasons: list[str] = []
    na, nb = numbers_in(a), numbers_in(b)
    if na != nb:
        reasons.append(
            f"数字不一致：仅主引擎 {sorted((na - nb).elements())}；仅副引擎 {sorted((nb - na).elements())}"
        )
    if _critical(a) != _critical(b):
        reasons.append("关键字（单位/方向/中文数字）不一致")
    ra, rb = table_row_recall(primary_md, secondary_md), table_row_recall(secondary_md, primary_md)
    if ra < 1.0 or rb < 1.0:
        reasons.append(f"表格行不一致：{ra:.4f}/{rb:.4f}")
    agree = min(text_coverage(_content(a), _content(b)), text_coverage(_content(b), _content(a)))
    if agree < DUAL_MIN_COVERAGE:
        reasons.append(f"文字一致度 {agree:.4f} < {DUAL_MIN_COVERAGE}")
    return Verdict(not reasons, tuple(reasons))
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/http_engine.py
"""自托管解析引擎（PaddleOCR / MinerU / Docling）的 HTTP 适配器。

引擎本体跑在本地 docker（infra/parse-engines/<name>），容器里只有我们自己的薄壳暴露统一 JSON
协议；业务代码不 import 任何引擎 SDK（CLAUDE.md §1.5）。协议：
  GET  /v1/health      -> {"engine", "engine_version", "device"}
  POST /v1/parse-page  {"pdf_base64", "page_no"} -> {"ok": true, "markdown", "elapsed_ms"} | {"ok": false, "error"}
内容层失败返回 200 + ok=false，不与传输层故障混在同一套状态码分类里。"""

from __future__ import annotations

import base64
import time
from typing import Any, Literal

import httpx

from ragdemo.adapters.errors import AdapterError
from ragdemo.adapters.http import HttpClient, ProviderConfig, RetryPolicy, TokenBucket
from ragdemo.parse.tiered.engines import EngineError, EngineOutput, EngineUnavailable, strip_images

EngineName = Literal["paddle", "mineru", "docling"]
HEALTH = "/v1/health"
PARSE = "/v1/parse-page"


class HttpPageEngine:
    def __init__(self, http: HttpClient, *, name: str, version: str) -> None:
        self._http = http
        self.name = name
        self.version = version

    def parse_page(self, page_pdf: bytes, *, page_no: int) -> EngineOutput:
        t0 = time.perf_counter()
        body = {"pdf_base64": base64.b64encode(page_pdf).decode("ascii"), "page_no": page_no}
        try:
            raw = self._http.post_json(PARSE, body)
        except AdapterError as exc:
            raise EngineUnavailable(f"{self.name} 不可达：{exc}") from exc
        payload: Any = raw.payload
        if not isinstance(payload, dict) or payload.get("ok") is not True:
            err = payload.get("error") if isinstance(payload, dict) else "响应不是 JSON 对象"
            raise EngineError(f"{self.name} 第 {page_no} 页失败：{err}")
        markdown = payload.get("markdown")
        if not isinstance(markdown, str):
            raise EngineError(f"{self.name} 第 {page_no} 页响应缺少 markdown")
        elapsed = payload.get("elapsed_ms")
        ms = elapsed if isinstance(elapsed, int) and elapsed >= 0 else int((time.perf_counter() - t0) * 1000)
        return EngineOutput(strip_images(markdown), ms)


def engine_from_url(
    name: EngineName,
    base_url: str,
    *,
    transport: httpx.BaseTransport | None = None,
    retry: RetryPolicy | None = None,
) -> HttpPageEngine:
    cfg = ProviderConfig.load(f"parse_{name}")
    http = HttpClient(
        provider=f"parse_{name}",
        base_url=base_url,
        policy=retry or cfg.retry,
        bucket=TokenBucket(rate_per_minute=cfg.rate_limit_qpm),
        timeout_s=cfg.timeout_s,
        daily_quota=cfg.daily_quota,
        transport=transport,
    )
    try:
        health: Any = http.get_json(HEALTH, {}).payload
    except AdapterError as exc:
        raise EngineUnavailable(f"{name} 健康检查失败：{exc}") from exc
    if not isinstance(health, dict) or health.get("engine") != name or not health.get("engine_version"):
        raise EngineUnavailable(f"{name} 健康检查返回异常：{health!r}")
    return HttpPageEngine(http, name=name, version=str(health["engine_version"]))
```

```python
# infra/parse-engines/common/shim.py
"""解析引擎薄壳：stdlib HTTP 服务，单线程串行（引擎实例不保证线程安全）。

只在容器内网监听；不记录请求体（文档内容）。引擎 SDK 只在各引擎的 server.py 里 import。"""

from __future__ import annotations

import base64
import json
import tempfile
import time
import traceback
from collections.abc import Callable
from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path

ParseFn = Callable[[Path], str]  # 单页 PDF 路径 -> markdown


def serve(engine: str, version: str, device: str, parse_fn: ParseFn, port: int = 8000) -> None:
    class Handler(BaseHTTPRequestHandler):
        def _send(self, status: int, body: dict[str, object]) -> None:
            data = json.dumps(body, ensure_ascii=False).encode("utf-8")
            self.send_response(status)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def do_GET(self) -> None:  # noqa: N802 — BaseHTTPRequestHandler 约定的方法名
            if self.path != "/v1/health":
                self._send(404, {"error": "not found"})
                return
            self._send(200, {"engine": engine, "engine_version": version, "device": device})

        def do_POST(self) -> None:  # noqa: N802
            if self.path != "/v1/parse-page":
                self._send(404, {"error": "not found"})
                return
            try:
                length = int(self.headers.get("Content-Length") or 0)
                request = json.loads(self.rfile.read(length))
                raw = base64.b64decode(request["pdf_base64"], validate=True)
            except Exception as exc:  # noqa: BLE001
                self._send(200, {"ok": False, "error": f"请求格式错误：{type(exc).__name__}"})
                return
            if not raw.startswith(b"%PDF"):
                self._send(200, {"ok": False, "error": "不是有效的 PDF"})
                return
            t0 = time.perf_counter()
            with tempfile.TemporaryDirectory() as d:
                path = Path(d) / "page.pdf"
                path.write_bytes(raw)
                try:
                    markdown = parse_fn(path)
                except Exception as exc:  # noqa: BLE001
                    traceback.print_exc()
                    self._send(200, {"ok": False, "error": f"引擎异常：{type(exc).__name__}"})
                    return
            self._send(200, {"ok": True, "markdown": markdown, "elapsed_ms": int((time.perf_counter() - t0) * 1000)})

        def log_message(self, format: str, *args: object) -> None:  # noqa: A002
            return  # 不写访问日志：路径固定，正文不得落日志

    HTTPServer(("0.0.0.0", port), Handler).serve_forever()  # noqa: S104 — 只在 internal 网络内可达
```

```python
API 以 T1 记录的 paddleocr 版本为准（3.x：PPStructureV3().predict(input=...)，结果对象的

from importlib.metadata import version
from pathlib import Path

from paddleocr import PPStructureV3
from shim import serve

DEVICE = os.environ.get("PARSE_DEVICE", "cpu")
PIPELINE = PPStructureV3(device=DEVICE, markdown_ignore_labels=[])


def parse(path: Path) -> str:
    parts = [res.markdown["markdown_texts"] for res in PIPELINE.predict(input=str(path))]
    return "\n\n".join(parts)


if __name__ == "__main__":
    serve("paddle", version("paddleocr"), DEVICE, parse)
```

```python
"""30 页难样本基准（纯函数）：样本清单、TextIn 参考、逐样本打分、汇总、门槛与混合成本。

TextIn 不是绝对标准答案：指标只说明"与 TextIn 是否一致"，不一致处由人工抽查裁定。
门槛在计划里事先写死（GATES），执行时不得修改。"""

from __future__ import annotations

import csv
import math
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from pathlib import Path
from types import MappingProxyType
from typing import Any, Final, Literal, cast, get_args

from ragdemo.parse.local.compare import (
    number_recall_precision,
    plain_text_from_markdown,
    table_row_recall,
    text_coverage,
)
from ragdemo.parse.local.report import sanitize
from ragdemo.parse.textin import table_markdown
from ragdemo.parse.tiered.engines import EngineError, PageEngine
from ragdemo.parse.tiered.pdfpages import single_page_pdf
from ragdemo.parse.tiered.verify import Verdict, verify_against_text_layer

Category = Literal["scan", "cross_page_table", "merged_cell_table", "l0_failed", "financial_statement"]
BENCH_SIZE: Final = 30
MAX_TEXTIN_SPEND_PAGES: Final = 40  # 无缓存样本需要现调 TextIn 的页数上限（约 5.6 元）
TABLE_CATEGORIES: Final = frozenset({"cross_page_table", "merged_cell_table"})

GATES: Final[Mapping[str, float]] = MappingProxyType(
    {
        "num_recall_min": 0.98,
        "num_precision_min": 0.99,
        "table_row_recall_min": 0.90,
        "latency_mean_max_s": 15.0,
        "latency_p95_max_s": 30.0,
        "fail_vs_textin_factor": 1.5,
        "l1_pass_rate_min": 0.70,
        "l2_consistency_min": 0.60,
        "blended_cost_max_cny": 0.05,
    }
)


@dataclass(frozen=True)
class BenchCase:
    pdf: Path
    page: int
    span: int  # 跨页表样本为 2：引擎逐页解析后拼接，与 TextIn 合并后的表按行比较
    category: Category
    textin_json_ref: str | None  # 整份文档的 TextIn 缓存 JSON（blob 键）；空 = 需要现调


def load_bench_cases(path: Path) -> list[BenchCase]:
    cases: list[BenchCase] = []
    with path.open(encoding="utf-8", newline="") as fh:
        for i, row in enumerate(csv.DictReader(fh, delimiter="\t"), start=2):
            page, span, cat = int(row["page"]), int(row["span"]), row["category"]
            if page < 1 or span < 1 or cat not in get_args(Category):
                raise ValueError(f"第 {i} 行无效：page={page} span={span} category={cat!r}")
            ref = (row.get("textin_json_ref") or "").strip() or None
            cases.append(BenchCase(Path(row["pdf"]), page, span, cast(Category, cat), ref))
    return cases


def textin_page_reference(payload: Mapping[str, Any], page: int) -> str:
    """这一页在 TextIn 结果里的全部内容（含页眉页脚——引擎也会输出它们，排除会冤枉精确率）。"""
    detail = (payload.get("result") or {}).get("detail") or []
    ids = [int(d["page_id"]) for d in detail if d.get("page_id") is not None]
    offset = 1 if ids and min(ids) == 0 else 0  # 与 textin._page_offset 同一规则
    parts: list[str] = []
    for item in detail:
        if item.get("page_id") is None or int(item["page_id"]) + offset != page:
            continue
        if str(item.get("type")) == "table":
            parts.append(table_markdown(item.get("cells") or []))
        else:
            parts.append(str(item.get("text", "")).strip())
    return "\n\n".join(p for p in parts if p)


@dataclass(frozen=True)
class EngineRun:
    case: BenchCase
    engine: str
    markdown: str | None
    error: str | None
    elapsed_ms: int


def run_engine(engine: PageEngine, case: BenchCase, pdf_bytes: bytes) -> EngineRun:
    parts: list[str] = []
    elapsed = 0
    for p in range(case.page, case.page + case.span):
        try:
            out = engine.parse_page(single_page_pdf(pdf_bytes, p), page_no=p)
        except EngineError as exc:
            return EngineRun(case, engine.name, None, f"{type(exc).__name__}: {exc}", elapsed)
        parts.append(out.markdown)
        elapsed += out.elapsed_ms
    markdown = "\n\n".join(parts)
    if not markdown.strip():
        return EngineRun(case, engine.name, None, "空输出", elapsed)
    return EngineRun(case, engine.name, markdown, None, elapsed)


@dataclass(frozen=True)
class CaseScore:
    num_recall: float
    num_precision: float
    table_row_recall: float
    coverage: float
    text_layer_verdict: Verdict | None  # 无文字层样本为 None


def score_run(run: EngineRun, reference: str, page_text: str | None) -> CaseScore | None:
    if run.markdown is None:
        return None
    ref_plain, plain = plain_text_from_markdown(reference), plain_text_from_markdown(run.markdown)
    recall, precision = number_recall_precision(ref_plain, plain)
    return CaseScore(
        num_recall=recall,
        num_precision=precision,
        table_row_recall=table_row_recall(reference, run.markdown),
        coverage=text_coverage(ref_plain, plain),
        text_layer_verdict=verify_against_text_layer(run.markdown, page_text) if page_text is not None else None,
    )


@dataclass(frozen=True)
class EngineSummary:
    engine: str
    cases: int
    failures: int
    num_recall: float
    num_precision: float
    table_row_recall: float
    latency_mean_s: float
    latency_p95_s: float
    l1_pass_rate: float | None


def _mean(xs: Sequence[float]) -> float:
    return sum(xs) / len(xs) if xs else 0.0


def _p95(xs: Sequence[float]) -> float:
    """最近秩法（与 evals/runner.py::_percentile 同一定义）。"""
    if not xs:
        return 0.0
    ordered = sorted(xs)
    return ordered[max(0, math.ceil(0.95 * len(ordered)) - 1)]


def summarize_engine(runs: Sequence[EngineRun], scores: Sequence[CaseScore | None]) -> EngineSummary:
    ok: list[tuple[EngineRun, CaseScore]] = [(r, s) for r, s in zip(runs, scores, strict=True) if s is not None]
    latencies = [r.elapsed_ms / r.case.span / 1000 for r, _ in ok]
    l0_total = sum(1 for r in runs if r.case.category == "l0_failed")
    l0_pass = 0
    for r, s in ok:
        if r.case.category == "l0_failed" and s.text_layer_verdict is not None and s.text_layer_verdict.ok:
            l0_pass += 1
    return EngineSummary(
        engine=runs[0].engine if runs else "",
        cases=len(runs),
        failures=sum(1 for s in scores if s is None),
        num_recall=_mean([s.num_recall for _, s in ok]),
        num_precision=_mean([s.num_precision for _, s in ok]),
        table_row_recall=_mean([s.table_row_recall for r, s in ok if r.case.category in TABLE_CATEGORIES]),
        latency_mean_s=_mean(latencies),
        latency_p95_s=_p95(latencies),
        l1_pass_rate=l0_pass / l0_total if l0_total else None,
    )


@dataclass(frozen=True)
class GateResult:
    name: str
    value: float
    threshold: float
    passed: bool


def allowed_failures(textin_failures: int) -> int:
    return max(math.ceil(GATES["fail_vs_textin_factor"] * textin_failures), 1)


def l1_gates(s: EngineSummary, *, textin_failures: int) -> list[GateResult]:
    g = GATES
    allowed = allowed_failures(textin_failures)
    l1 = s.l1_pass_rate if s.l1_pass_rate is not None else 0.0
    return [
        GateResult("数字召回", s.num_recall, g["num_recall_min"], s.num_recall >= g["num_recall_min"]),
        GateResult("数字精确率", s.num_precision, g["num_precision_min"], s.num_precision >= g["num_precision_min"]),
        GateResult("表格行召回", s.table_row_recall, g["table_row_recall_min"], s.table_row_recall >= g["table_row_recall_min"]),
        GateResult("单页耗时均值（秒）", s.latency_mean_s, g["latency_mean_max_s"], s.latency_mean_s <= g["latency_mean_max_s"]),
        GateResult("单页耗时 p95（秒）", s.latency_p95_s, g["latency_p95_max_s"], s.latency_p95_s <= g["latency_p95_max_s"]),
        GateResult("失败样本数", float(s.failures), float(allowed), s.failures <= allowed),
        GateResult("L0 失败页的 L1 校验通过率", l1, g["l1_pass_rate_min"], l1 >= g["l1_pass_rate_min"]),
    ]


@dataclass(frozen=True)
class CostInputs:
    scan_share: float  # 无可用文字层页占比（T1）
    statement_share: float  # 有文字层页中财务报表页占比（本任务 statements 模式）
    l0_pass: float  # L0 页级通过率 p0（T2）
    l1_pass: float  # L0 失败页的 L1 通过率（本任务）
    l2_consistency: float  # 扫描页双引擎一致率（T10；未建 L2 时填 0）
    c_l0: float  # L0 每页大模型成本（T2）
    c_local: float  # 自托管引擎每页摊销成本（PARSE_LOCAL_ENGINE_COST_PER_PAGE_CNY）
    c_l2_pair: float  # L2 一页两路的成本（两个自托管 = 2×c_local；含视觉接口时加其每页 token 成本）
    c_textin: float  # TextIn 每页单价
    l0_enabled: bool
    l1_enabled: bool
    l2_enabled: bool


def blended_cost_per_page(x: CostInputs) -> float:
    """每页期望成本，含失败尝试的沉没成本（L0 失败后 L1 再失败的页，三笔都要付）。"""
    p0 = x.l0_pass if x.l0_enabled else 0.0
    c0 = x.c_l0 if x.l0_enabled else 0.0
    after_l0 = (x.c_local + (1 - x.l1_pass) * x.c_textin) if x.l1_enabled else x.c_textin
    text_non_statement = (1 - x.scan_share) * (1 - x.statement_share)
    scan = (x.c_l2_pair + (1 - x.l2_consistency) * x.c_textin) if x.l2_enabled else x.c_textin
    return (
        (1 - x.scan_share) * x.statement_share * x.c_textin
        + text_non_statement * (c0 + (1 - p0) * after_l0)
        + x.scan_share * scan
    )


BENCH_HEADER: Final = (
    "pdf\tpage\tspan\tcategory\tengine\tstatus\telapsed_ms\tnum_recall\tnum_precision"
    "\ttable_row_recall\tcoverage\ttext_layer_ok\treasons"
)


def bench_row(run: EngineRun, score: CaseScore | None) -> str:
    c = run.case
    head = [sanitize(c.pdf), str(c.page), str(c.span), c.category, run.engine]
    if score is None:
        return "\t".join([*head, sanitize(f"ERR:{run.error}"), str(run.elapsed_ms), "", "", "", "", "", ""])
    v = score.text_layer_verdict
    return "\t".join(
        [
            *head, "ok", str(run.elapsed_ms),
            f"{score.num_recall:.4f}", f"{score.num_precision:.4f}",
            f"{score.table_row_recall:.4f}", f"{score.coverage:.4f}",
            "" if v is None else str(int(v.ok)), sanitize("；".join(v.reasons) if v else ""),
        ]
    )
```

```python
    engines: dict[str, PageEngine] = {}

def _reference(case: BenchCase, pdf_bytes: bytes, blob: LocalBlobStore, textin: TextInParser | None) -> str:
    pages = range(case.page, case.page + case.span)
    if case.textin_json_ref:
        payload = json.loads(blob.get(case.textin_json_ref))
        return "\n\n".join(textin_page_reference(payload, p) for p in pages)
    assert textin is not None
    result = textin.parse(sub_pdf(pdf_bytes, list(pages)))
    assert result.json_ref is not None
    payload = json.loads(blob.get(result.json_ref))
    return "\n\n".join(textin_page_reference(payload, i) for i in range(1, case.span + 1))


def run_bench(cases_path: Path, engine_names: list[str], *, allow_textin_spend: bool) -> Path:
    cfg = load_config()
    blob = LocalBlobStore(cfg.blob_root)
    cases = load_bench_cases(cases_path)
    if len(cases) != BENCH_SIZE:
        print(f"警告：样本 {len(cases)} 条，计划要求 {BENCH_SIZE} 条")
    spend = sum(c.span for c in cases if not c.textin_json_ref)
    if spend and not allow_textin_spend:
        raise SystemExit(f"{spend} 页没有 TextIn 缓存；确认花费（约 {spend * 0.14:.2f} 元）后加 --allow-textin-spend")
    if spend > MAX_TEXTIN_SPEND_PAGES:
        raise SystemExit(f"需要现调 TextIn {spend} 页，超过上限 {MAX_TEXTIN_SPEND_PAGES}")
    textin = TextInParser(cfg.require_textin_base_url(), blob) if spend else None
    engines = _bench_engines(engine_names)
    runs: dict[str, list[EngineRun]] = {n: [] for n in engines}
    scores: dict[str, list[CaseScore | None]] = {n: [] for n in engines}
    textin_failures = 0
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    out = OUT_DIR / f"parse-bench-{date.today()}.tsv"
    with out.open("w", encoding="utf-8") as fh:
        fh.write(BENCH_HEADER + "\n")
        for case in cases:
            pdf_bytes = case.pdf.read_bytes()
            try:
                reference = _reference(case, pdf_bytes, blob, textin)
            except Exception as exc:  # noqa: BLE001 — TextIn 失败计入 TextIn 失败数，不中断基准
                print(f"TextIn 参考失败 {case.pdf}#{case.page}: {type(exc).__name__}")
                reference = ""
            if not reference.strip():
                textin_failures += 1
            layouts = extract_pages(sub_pdf(pdf_bytes, list(range(case.page, case.page + case.span))))
            has_text = all(needs_handback(lay.text) is None for lay in layouts)
            page_text = "\n".join(lay.text for lay in layouts) if has_text else None
            for name, engine in engines.items():
                run = run_engine(engine, case, pdf_bytes)
                score = score_run(run, reference, page_text)
                runs[name].append(run)
                scores[name].append(score)
                fh.write(bench_row(run, score) + "\n")
                fh.flush()
    print(f"{out}\nTextIn 失败样本数 {textin_failures}")
    for name in engines:
        s = summarize_engine(runs[name], scores[name])
        print(f"\n## {name}: {s}")
        for g in l1_gates(s, textin_failures=textin_failures):
            print(f"| {g.name} | {g.value:.4f} | {g.threshold} | {'通过' if g.passed else '未通过'} |")
    return out
```

```python
    def parse(self, file_bytes: bytes, *, owner_user: str | None = None) -> ParseResult:
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/blocks.py
"""逐页 markdown（L0/L1/L2 产物）→ NormalizedBlock；整份文档按页拼接并统一重建 section_path。

TextIn（L3）的块由 blocks_from_detail 产生；各级块在 assemble_blocks 里按页序合并、重新编号，
按标题层级重建 section_path（与 blocks_from_detail 同一规则：标题不含在自己的路径里，
层级跳跃时路径保持连续）。HTML 表格展开合并单元格为重复值，与 textin.table_markdown 一致；
原始 HTML 保留在 table_html。"""

from __future__ import annotations

import html
import re
from collections.abc import Sequence
from dataclasses import replace
from html.parser import HTMLParser

from ragdemo.adapters.announcements import NormalizedBlock

_HEADING = re.compile(r"^(#{1,6})\s+(.*\S)\s*$")
_TABLE = re.compile(r"<table\b.*?</table>", re.DOTALL | re.IGNORECASE)
_TAG = re.compile(r"<[^>]*>")
_SLOT = re.compile(r"^\x00TABLE(\d+)\x00$")


def _span(value: str | None) -> int:
    try:
        return max(1, int(value or 1))
    except ValueError:
        return 1


class _TableGrid(HTMLParser):
    def __init__(self) -> None:
        super().__init__()
        self.rows: list[list[tuple[str, int, int]]] = []
        self._cell: list[str] | None = None
        self._spans = (1, 1)

    def handle_starttag(self, tag: str, attrs: list[tuple[str, str | None]]) -> None:
        if tag == "tr":
            self.rows.append([])
        elif tag in ("td", "th"):
            a = dict(attrs)
            self._spans = (_span(a.get("rowspan")), _span(a.get("colspan")))
            self._cell = []
            if not self.rows:
                self.rows.append([])
        elif tag == "br" and self._cell is not None:
            self._cell.append(" ")

    def handle_endtag(self, tag: str) -> None:
        if tag in ("td", "th") and self._cell is not None:
            self.rows[-1].append((" ".join("".join(self._cell).split()), *self._spans))
            self._cell = None

    def handle_data(self, data: str) -> None:
        if self._cell is not None:
            self._cell.append(data)


def html_table_to_markdown(table_html: str) -> str:
    parser = _TableGrid()
    parser.feed(table_html)
    parser.close()
    grid: dict[tuple[int, int], str] = {}
    for r, row in enumerate(parser.rows):
        c = 0
        for text, row_span, col_span in row:
            while (r, c) in grid:
                c += 1
            for dr in range(row_span):
                for dc in range(col_span):
                    grid[(r + dr, c + dc)] = text.replace("|", r"\|")
            c += col_span
    if not grid:
        return ""
    n_rows = max(r for r, _ in grid) + 1
    n_cols = max(c for _, c in grid) + 1
    rows = [[grid.get((r, c), "") for c in range(n_cols)] for r in range(n_rows)]
    lines = ["| " + " | ".join(rows[0]) + " |", "|" + "---|" * n_cols]
    lines += ["| " + " | ".join(row) + " |" for row in rows[1:]]
    return "\n".join(lines)


def _strip_tags(line: str) -> str:
    return " ".join(html.unescape(_TAG.sub(" ", line)).split())


def blocks_from_markdown_page(page: int, markdown: str) -> list[NormalizedBlock]:
    tables: list[str] = []

    def stash(m: re.Match[str]) -> str:
        tables.append(m.group(0))
        return f"\n\x00TABLE{len(tables) - 1}\x00\n"

    text = _TABLE.sub(stash, markdown)
    out: list[NormalizedBlock] = []
    para: list[str] = []
    pipe: list[str] = []

    def add(block_type: str, content: str, *, level: int | None = None, table_html: str | None = None) -> None:
        if content.strip():
            out.append(
                NormalizedBlock(
                    ordinal=len(out), block_type=block_type, section_path="", content=content.strip(),
                    page=page, level=level, table_html=table_html,
                )
            )

    def flush_para() -> None:
        add("paragraph", "\n".join(s for s in (_strip_tags(x) for x in para) if s))
        para.clear()

    def flush_pipe() -> None:
        add("table", "\n".join(pipe))
        pipe.clear()

    for line in text.splitlines():
        s = line.strip()
        slot = _SLOT.match(s)
        if slot:
            flush_para()
            flush_pipe()
            raw = tables[int(slot.group(1))]
            add("table", html_table_to_markdown(raw), table_html=raw)
            continue
        if s.startswith("|"):
            flush_para()
            pipe.append(s)
            continue
        flush_pipe()
        heading = _HEADING.match(s)
        if heading:
            flush_para()
            add("title", _strip_tags(heading.group(2)), level=len(heading.group(1)) - 1)
        elif not s:
            flush_para()
        else:
            para.append(line)
    flush_para()
    flush_pipe()
    return out


def assemble_blocks(pages: Sequence[tuple[int, Sequence[NormalizedBlock]]]) -> list[NormalizedBlock]:
    stack: list[str] = []
    out: list[NormalizedBlock] = []
    for _page, blocks in sorted(pages, key=lambda item: item[0]):
        for b in blocks:
            if b.block_type == "title":
                level = b.level if b.level is not None else 0
                del stack[level:]
                stack.append(b.content)
                section = " > ".join(stack[:-1])
            else:
                section = " > ".join(stack)
            out.append(replace(b, ordinal=len(out), section_path=section))
    return out
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/textin_pages.py
"""L3：把需要 TextIn 的页按连续段切成子 PDF 分别送 TextIn（段内跨页表仍由 apply_merge 合并），
块的页码映射回原文档页码。全部页都要 L3 时直接送整份——与旧路径同一个缓存键，存量缓存可复用。
TextIn 的异常（ParseRetryable / ParseTimeout / ParsePermanent / 私有闸门）原样抛出，由
prepare_documents 按既有规则处理。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass, replace

from ragdemo.adapters.announcements import NormalizedBlock
from ragdemo.parse.textin import DocumentParser
from ragdemo.parse.tiered.pdfpages import sub_pdf


def contiguous_runs(pages: Sequence[int]) -> list[list[int]]:
    runs: list[list[int]] = []
    for p in sorted(set(pages)):
        if runs and p == runs[-1][-1] + 1:
            runs[-1].append(p)
        else:
            runs.append([p])
    return runs


@dataclass(frozen=True)
class TextInPages:
    blocks_by_page: dict[int, list[NormalizedBlock]]
    billed: frozenset[int]  # 这次真的向 TextIn 计费的原文档页码
    json_refs: list[str]
    warnings: list[str]

    @property
    def billed_pages(self) -> int:
        return len(self.billed)


def parse_pages_with_textin(
    textin: DocumentParser, pdf_bytes: bytes, pages: Sequence[int], *, total_pages: int
) -> TextInPages:
    wanted = sorted(set(pages))
    if not wanted:
        return TextInPages({}, frozenset(), [], [])
    whole = wanted == list(range(1, total_pages + 1))
    runs = [wanted] if whole else contiguous_runs(wanted)
    by_page: dict[int, list[NormalizedBlock]] = {}
    billed: set[int] = set()
    refs: list[str] = []
    warnings: list[str] = []
    for run in runs:
        result = textin.parse(pdf_bytes if whole else sub_pdf(pdf_bytes, run), owner_user=None)
        if not result.from_cache:
            billed.update(run)
        if result.json_ref:
            refs.append(result.json_ref)
        warnings.extend(result.warnings)
        for b in result.blocks:
            local = b.page if b.page is not None else 1
            if not 1 <= local <= len(run):
                raise ValueError(f"TextIn 块页码 {b.page} 超出子文档 1..{len(run)}")
            original = run[local - 1]
            by_page.setdefault(original, []).append(replace(b, page=original))
    return TextInPages(by_page, frozenset(billed), refs, warnings)
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/route.py
"""单页四级路由（解析分级路由计划）。

有文字层：财务报表页 → L3；否则 L0（本地文字层 + 大模型排版 + 闭合校验）→ L1（自托管引擎 +
文字层溯源校验）→ L3。无文字层：L2（两路独立引擎一致，T10 落地）→ L3。
任何一级失败都只降级，不抛异常；降级原因逐条记进 PageRoute.reasons。"""

from __future__ import annotations

import time
from collections.abc import Callable
from dataclasses import dataclass
from typing import Protocol

from ragdemo.adapters.errors import AdapterError
from ragdemo.parse.describe_llm import Usage
from ragdemo.parse.local.layout import PageLayout
from ragdemo.parse.local.pipeline import PageResult, PageStructurer, needs_handback, parse_page_local
from ragdemo.parse.tiered.classify import is_financial_statement_page
from ragdemo.parse.tiered.engines import EngineError, EngineUnavailable, PageEngine
from ragdemo.parse.tiered.types import PageRoute, Tier
from ragdemo.parse.tiered.verify import verify_against_text_layer

L2_SUPPORTED = False  # T10 落地双引擎分支后改为 True；factory 据此拒绝提前打开 L2


class CountingStructurer(PageStructurer, Protocol):
    usage: Usage


@dataclass(frozen=True)
class RouteContext:
    structurer: CountingStructurer | None  # None = L0 关闭
    primary: PageEngine | None  # None = L1 关闭
    secondary: PageEngine | None = None  # None = L2 关闭
    l0_tag: str = "off"  # L0 的模型 + prompt 版本，进引擎标识与指纹


@dataclass(frozen=True)
class PageOutcome:
    route: PageRoute
    markdown: str | None  # None = 交给 L3


def route_page(
    layout: PageLayout,
    page_pdf: Callable[[], bytes],
    ctx: RouteContext,
    *,
    clock: Callable[[], float] = time.perf_counter,
) -> PageOutcome:
    t0 = clock()
    reasons: list[str] = []
    llm = (0, 0)
    vision = (0, 0)
    local_calls = 0
    handback = needs_handback(layout.text)
    text_ok = handback is None

    def done(tier: Tier, engine: str, markdown: str | None) -> PageOutcome:
        route = PageRoute(
            page=layout.page, tier=tier, engine=engine, text_layer=text_ok, reasons=tuple(reasons),
            elapsed_ms=max(0, int((clock() - t0) * 1000)), local_engine_calls=local_calls,
            llm_tokens=llm, vision_tokens=vision,
        )
        return PageOutcome(route, markdown)

    if handback is not None:
        reasons.append(f"无可用文字层：{handback}")
        return done("L3", "textin", None)  # T10 在这里插入 L2 分支
    if is_financial_statement_page(layout.text):
        reasons.append("财务报表页：强制 L3")
        return done("L3", "textin", None)

    if ctx.structurer is None:
        reasons.append("L0 关闭")
    else:
        usage = ctx.structurer.usage
        before = (usage.prompt_tokens, usage.completion_tokens)
        result: PageResult | None
        try:
            result = parse_page_local(layout, ctx.structurer)
        except AdapterError as exc:  # 大模型限流 / 配额 / 不可达：只是这一页降级
            reasons.append(f"L0 大模型不可达：{type(exc).__name__}")
            result = None
        llm = (usage.prompt_tokens - before[0], usage.completion_tokens - before[1])
        if result is not None:
            if result.status == "ok":
                return done("L0", f"local_llm:{ctx.l0_tag}", result.markdown)
            reasons.append(f"L0 {result.status}：{result.reason}")

    if ctx.primary is None:
        reasons.append("L1 关闭")
        return done("L3", "textin", None)
    local_calls += 1
    try:
        out = ctx.primary.parse_page(page_pdf(), page_no=layout.page)
    except EngineUnavailable as exc:
        reasons.append(f"L1 {ctx.primary.name} 不可达：{exc}")
        return done("L3", "textin", None)
    except EngineError as exc:
        reasons.append(f"L1 {ctx.primary.name} 失败：{exc}")
        return done("L3", "textin", None)
    verdict = verify_against_text_layer(out.markdown, layout.text)
    if verdict.ok:
        return done("L1", f"{ctx.primary.name}:{ctx.primary.version}", out.markdown)
    reasons.append(f"L1 校验失败：{'；'.join(verdict.reasons)}")
    return done("L3", "textin", None)
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/parser.py
"""逐页四级路由解析器：实现 DocumentParser（parse 等价于 TextIn）与 DocTypeAwareParser。

- 只对 doc_types 内的公开文档生效；私有材料原样交给 TextIn 的闸门（ADR-0008 后果 1）。
- 旁路文件 parse/tiered/<sha256>/<指纹>.json 在调用 TextIn **之前**写入：TextIn 临时失败时
  prepare_documents 不写行、下次重跑，届时直接读旁路文件，不重复 L0/L1 的工作与花费。
- 引擎标识 tiered:<算法版本>+<指纹>；指纹含 L0 模型与 prompt、L1/L2 引擎名与版本、校验版本、
  TextIn 参数指纹——任何一项变化只影响之后的新文档（不批量重解析）。"""

from __future__ import annotations

import hashlib
import json
from collections import Counter
from dataclasses import replace
from typing import Final

from ragdemo.adapters.announcements import NormalizedBlock
from ragdemo.parse.local.layout import extract_pages
from ragdemo.parse.textin import DocumentParser, ParseResult, param_fingerprint
from ragdemo.parse.tiered.blocks import assemble_blocks, blocks_from_markdown_page
from ragdemo.parse.tiered.pdfpages import single_page_pdf
from ragdemo.parse.tiered.route import RouteContext, route_page
from ragdemo.parse.tiered.textin_pages import TextInPages, parse_pages_with_textin
from ragdemo.parse.tiered.types import TIERS, PageRoute, route_from_dict, route_to_dict
from ragdemo.parse.tiered.verify import VERIFY_VERSION
from ragdemo_core.blob import BlobStore

TIERED_ALGORITHM_VERSION: Final = "v1"


def _engine_tag(engine: object | None) -> str:
    if engine is None:
        return "off"
    return f"{getattr(engine, 'name')}:{getattr(engine, 'version')}"


class TieredParser:
    def __init__(
        self,
        textin: DocumentParser,
        blob: BlobStore,
        *,
        context: RouteContext,
        doc_types: frozenset[str],
        textin_fp: str,
    ) -> None:
        self._textin = textin
        self._blob = blob
        self._ctx = context
        self._doc_types = doc_types
        self._fp = param_fingerprint(
            {
                "algo": TIERED_ALGORITHM_VERSION,
                "verify": VERIFY_VERSION,
                "l0": context.l0_tag if context.structurer is not None else "off",
                "l1": _engine_tag(context.primary),
                "l2": _engine_tag(context.secondary),
                "textin": textin_fp,
            }
        )
        self.engine = f"tiered:{TIERED_ALGORITHM_VERSION}+{self._fp}"

    def parse(self, file_bytes: bytes, *, owner_user: str | None = None) -> ParseResult:
        return self._textin.parse(file_bytes, owner_user=owner_user)

    def parse_for(self, file_bytes: bytes, *, doc_type: str, owner_user: str | None = None) -> ParseResult:
        if doc_type not in self._doc_types or owner_user is not None:
            return self._textin.parse(file_bytes, owner_user=owner_user)
        digest = hashlib.sha256(file_bytes).hexdigest()
        json_key = f"parse/tiered/{digest}/{self._fp}.json"
        md_key = f"parse/tiered/{digest}/{self._fp}.md"

        if self._blob.exists(json_key):
            cached = json.loads(self._blob.get(json_key))
            routes = [route_from_dict(r) for r in cached["routes"]]
            markdowns = {int(k): str(v) for k, v in cached["markdown"].items()}
            return self._finish(file_bytes, routes, markdowns, json_key, md_key, sidecar_hit=True)

        try:
            layouts = extract_pages(file_bytes)
        except ValueError as exc:
            result = self._textin.parse(file_bytes)
            return replace(result, warnings=[*result.warnings, f"tiered_fallback: {exc}"])
        if not layouts:
            result = self._textin.parse(file_bytes)
            return replace(result, warnings=[*result.warnings, "tiered_fallback: PDF 没有页"])

        ctx = self._context_for(doc_type)
        outcomes = [
            route_page(lay, lambda p=lay.page: single_page_pdf(file_bytes, p), ctx) for lay in layouts
        ]
        routes = [o.route for o in outcomes]
        markdowns = {o.route.page: o.markdown for o in outcomes if o.markdown is not None}
        payload = {
            "engine": self.engine,
            "routes": [route_to_dict(r) for r in routes],
            "markdown": {str(k): v for k, v in markdowns.items()},
        }
        self._blob.put(json_key, json.dumps(payload, ensure_ascii=False).encode("utf-8"))
        return self._finish(file_bytes, routes, markdowns, json_key, md_key, sidecar_hit=False)

    def _context_for(self, doc_type: str) -> RouteContext:
        return self._ctx  # T10 在这里加视觉接口的文档范围限制

    def _finish(
        self,
        file_bytes: bytes,
        routes: list[PageRoute],
        markdowns: dict[int, str],
        json_key: str,
        md_key: str,
        *,
        sidecar_hit: bool,
    ) -> ParseResult:
        l3 = parse_pages_with_textin(
            self._textin, file_bytes, [r.page for r in routes if r.tier == "L3"], total_pages=len(routes)
        )
        routes = [replace(r, textin_billed=r.page in l3.billed) for r in routes]
        from_cache = sidecar_hit and not l3.billed
        self._blob.put(md_key, self._audit_markdown(routes, markdowns).encode("utf-8"))
        per_page: list[tuple[int, list[NormalizedBlock]]] = [
            (p, blocks_from_markdown_page(p, md)) for p, md in markdowns.items()
        ]
        per_page += list(l3.blocks_by_page.items())
        counts = Counter(r.tier for r in routes)
        summary = "tiered: " + " ".join(f"{t}={counts.get(t, 0)}" for t in TIERS)
        return ParseResult(
            blocks=assemble_blocks(per_page),
            page_count=len(routes),
            engine_version=self.engine,
            markdown="\n\n".join(markdowns[p] for p in sorted(markdowns)),
            json_ref=json_key,
            md_ref=md_key,
            warnings=[summary, *l3.warnings],
            from_cache=from_cache,
            billable_pages=l3.billed_pages,
            page_routes=() if from_cache else tuple(routes),
        )

    @staticmethod
    def _audit_markdown(routes: list[PageRoute], markdowns: dict[int, str]) -> str:
        """人读档案：每页标出层级与引擎；L3 页的正文在 TextIn 自己的产物里。"""
        return "\n\n".join(
            f"<!-- page {r.page} {r.tier} {r.engine} -->\n{markdowns.get(r.page, '')}" for r in routes
        )
```

```python
def dual_consistency(a: Sequence[EngineRun], b: Sequence[EngineRun]) -> float:
    """scan 样本中两路都成功且 verify_dual 通过的占比（失败样本计为不一致）。"""
    pairs = [(x, y) for x, y in zip(a, b, strict=True) if x.case.category == "scan"]
    if not pairs:
        return 0.0
    agree = sum(
        1 for x, y in pairs
        if x.markdown is not None and y.markdown is not None and verify_dual(x.markdown, y.markdown).ok
    )
    return agree / len(pairs)
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/vision_engine.py
"""通义千问视觉版适配器（OpenAI 兼容接口，经出网代理 8087）。

只能作为 L2 的一路：它会编造数字，单独输出永远不采用（route.py 只在 verify_dual 通过时采用
主引擎的输出）。只用于公告（parser.VISION_ALLOWED_DOC_TYPES）。密钥由出网代理注入。"""

from __future__ import annotations

import base64
import io
import time
from pathlib import Path
from typing import Any

import httpx
import pypdfium2 as pdfium

from ragdemo.adapters.errors import AdapterError
from ragdemo.adapters.http import HttpClient, ProviderConfig, TokenBucket
from ragdemo.parse.describe_llm import load_prompt
from ragdemo.parse.tiered.engines import VISION_ENGINE_NAME, EngineError, EngineOutput, EngineUnavailable, strip_images

CHAT_ENDPOINT = "/chat/completions"
PROMPT_DIR = Path(__file__).resolve().parents[2] / "agents" / "prompts" / "parse_vision"
PROVIDER = "qwen_vl"


def render_page_png(page_pdf: bytes, *, dpi: int = 150) -> bytes:
    try:
        pdf = pdfium.PdfDocument(page_pdf)
    except Exception as exc:  # noqa: BLE001 — pdfium 对坏文件抛 PdfiumError
        raise ValueError(f"不是有效的 PDF：{exc}") from exc
    try:
        if len(pdf) != 1:
            raise ValueError(f"期望单页 PDF，收到 {len(pdf)} 页")
        image = pdf[0].render(scale=dpi / 72).to_pil()
        buf = io.BytesIO()
        image.save(buf, format="PNG")
        return buf.getvalue()
    finally:
        pdf.close()


def vision_client(base_url: str, *, transport: httpx.BaseTransport | None = None) -> HttpClient:
    cfg = ProviderConfig.load(PROVIDER)
    return HttpClient(
        provider=PROVIDER, base_url=base_url, policy=cfg.retry,
        bucket=TokenBucket(rate_per_minute=cfg.rate_limit_qpm), timeout_s=cfg.timeout_s,
        daily_quota=cfg.daily_quota, cost_per_call_cents=cfg.cost_per_call_cents, transport=transport,
    )


class VisionPageEngine:
    name = VISION_ENGINE_NAME

    def __init__(
        self, http: HttpClient, *, model: str, prompt_version: str = "v1", dpi: int = 150, max_tokens: int = 4000
    ) -> None:
        self._http = http
        self._model = model
        self._dpi = dpi
        self._max_tokens = max_tokens
        self._prompt = load_prompt(prompt_version, PROMPT_DIR)
        self.version = f"{model}+{prompt_version}"

    def parse_page(self, page_pdf: bytes, *, page_no: int) -> EngineOutput:
        t0 = time.perf_counter()
        try:
            png = render_page_png(page_pdf, dpi=self._dpi)
        except ValueError as exc:
            raise EngineError(str(exc)) from exc
        image_url = "data:image/png;base64," + base64.b64encode(png).decode("ascii")
        body = {
            "model": self._model,
            "temperature": 0,
            "max_tokens": self._max_tokens,
            "messages": [
                {"role": "user", "content": [
                    {"type": "image_url", "image_url": {"url": image_url}},
                    {"type": "text", "text": self._prompt},
                ]}
            ],
        }
        try:
            raw = self._http.post_json(CHAT_ENDPOINT, body)
        except AdapterError as exc:
            raise EngineUnavailable(f"{self.name} 不可达：{type(exc).__name__}") from exc
        payload: Any = raw.payload
        choices = payload.get("choices") if isinstance(payload, dict) else None
        if not isinstance(choices, list) or not choices or not isinstance(choices[0], dict):
            raise EngineError(f"{self.name} 第 {page_no} 页回复缺少 choices")
        choice: dict[str, Any] = choices[0]
        if choice.get("finish_reason") == "length":
            raise EngineError(f"{self.name} 第 {page_no} 页回复被截断")
        message = choice.get("message")
        content = message.get("content") if isinstance(message, dict) else None
        if not isinstance(content, str) or not content.strip():
            raise EngineError(f"{self.name} 第 {page_no} 页回复为空或被过滤")
        usage = payload.get("usage") or {}
        return EngineOutput(
            strip_images(content.strip()),
            int((time.perf_counter() - t0) * 1000),
            int(usage.get("prompt_tokens") or 0),
            int(usage.get("completion_tokens") or 0),
        )
```

```python
"""逐页记账：费用估算、落库、按时间窗汇总、告警（解析分级路由计划 T11）。

单价不写死在代码里：全部来自配置（TierPrices.from_config）；缺单价时记 NULL，报表按当时单价重算，
仍缺则计入"未定价页数"，不编一个数。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import datetime, timedelta
from decimal import Decimal
from typing import TYPE_CHECKING, cast
from zoneinfo import ZoneInfo

import psycopg

from ragdemo.ops.alerts import Alert, raise_alert
from ragdemo.parse.tiered.types import TIERS, PageRoute, Tier

    from ragdemo.config import RagdemoConfig

SHANGHAI = ZoneInfo("Asia/Shanghai")
L3_SHARE_ALERT = 0.40
L3_SHARE_MIN_PAGES = 50
PARSE_SPEND_ALERT_SHARE = Decimal("0.30")  # ADR-0008 推翻条件：解析支出超过总预算 30%
_MTOK = Decimal(1_000_000)


@dataclass(frozen=True)
class TierPrices:
    llm_in_per_mtok: Decimal | None = None
    llm_out_per_mtok: Decimal | None = None
    vision_in_per_mtok: Decimal | None = None
    vision_out_per_mtok: Decimal | None = None
    textin_per_page: Decimal | None = None
    local_engine_per_page: Decimal = Decimal(0)

    @classmethod
    def from_config(cls, cfg: RagdemoConfig) -> TierPrices:
        return cls(
            llm_in_per_mtok=cfg.model_price_in_per_mtok_cny,
            llm_out_per_mtok=cfg.model_price_out_per_mtok_cny,
            vision_in_per_mtok=cfg.vision_price_in_per_mtok_cny,
            vision_out_per_mtok=cfg.vision_price_out_per_mtok_cny,
            textin_per_page=cfg.textin_cost_per_page_cny,
            local_engine_per_page=cfg.parse_local_engine_cost_per_page_cny,
        )


def _tokens_cost(tokens: tuple[int, int], p_in: Decimal | None, p_out: Decimal | None) -> Decimal | None:
    if tokens == (0, 0):
        return Decimal(0)
    if p_in is None or p_out is None:
        return None
    return (Decimal(tokens[0]) * p_in + Decimal(tokens[1]) * p_out) / _MTOK


def estimate_page_cost(route: PageRoute, prices: TierPrices) -> Decimal | None:
    """这一页这一次实际发生的全部花费，含失败的尝试。任一项缺单价返回 None。"""
    parts: list[Decimal | None] = [
        _tokens_cost(route.llm_tokens, prices.llm_in_per_mtok, prices.llm_out_per_mtok),
        _tokens_cost(route.vision_tokens, prices.vision_in_per_mtok, prices.vision_out_per_mtok),
        prices.local_engine_per_page * route.local_engine_calls,
    ]
    if route.textin_billed:
        parts.append(prices.textin_per_page)
    known = [p for p in parts if p is not None]
    if len(known) != len(parts):
        return None
    return sum(known, Decimal(0))


def record_page_routes(
    conn: psycopg.Connection,
    *,
    routes: Sequence[PageRoute],
    routes_ref: str,
    content_hash: str,
    doc_type: str,
    ingest_run_id: str,
    routed_at: datetime,
    prices: TierPrices | None,
) -> int:
    inserted = 0
    for r in routes:
        cost = estimate_page_cost(r, prices) if prices is not None else None
        cur = conn.execute(
            "INSERT INTO core.parse_page_route (routes_ref, content_hash, doc_type, page, tier, engine,"
            " text_layer, reasons, elapsed_ms, local_engine_calls, llm_prompt_tokens,"
            " llm_completion_tokens, vision_prompt_tokens, vision_completion_tokens, textin_billed,"
            " cost_cny, ingest_run_id, routed_at)"
            " VALUES (%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s)"
            " ON CONFLICT (routes_ref, page) DO NOTHING",
            (
                routes_ref, content_hash, doc_type, r.page, r.tier, r.engine, r.text_layer,
                list(r.reasons), r.elapsed_ms, r.local_engine_calls, r.llm_tokens[0], r.llm_tokens[1],
                r.vision_tokens[0], r.vision_tokens[1], r.textin_billed, cost, ingest_run_id, routed_at,
            ),
        )
        inserted += cur.rowcount
    return inserted


@dataclass(frozen=True)
class TierRow:
    tier: Tier
    pages: int
    cost_cny: Decimal
    pages_unpriced: int


def tier_summary(conn: psycopg.Connection, *, start: datetime, end: datetime, prices: TierPrices) -> list[TierRow]:
    rows = conn.execute(
        "SELECT page, tier, engine, text_layer, local_engine_calls, llm_prompt_tokens,"
        " llm_completion_tokens, vision_prompt_tokens, vision_completion_tokens, textin_billed, cost_cny"
        "  FROM core.parse_page_route WHERE routed_at >= %s AND routed_at < %s",
        (start, end),
    ).fetchall()
    pages = {t: 0 for t in TIERS}
    cost = {t: Decimal(0) for t in TIERS}
    unpriced = {t: 0 for t in TIERS}
    for page, tier, engine, text_layer, calls, li, lo, vi, vo, billed, stored in rows:
        t = cast(Tier, tier)
        pages[t] += 1
        value = stored
        if value is None:
            value = estimate_page_cost(
                PageRoute(page=int(page), tier=t, engine=str(engine), text_layer=bool(text_layer),
                          local_engine_calls=int(calls), llm_tokens=(int(li), int(lo)),
                          vision_tokens=(int(vi), int(vo)), textin_billed=bool(billed)),
                prices,
            )
        if value is None:
            unpriced[t] += 1
        else:
            cost[t] += Decimal(value)
    return [TierRow(t, pages[t], cost[t], unpriced[t]) for t in TIERS]


def format_tier_summary(rows: Sequence[TierRow]) -> str:
    lines = ["| 层级 | 页数 | 估算费用（元） | 未定价页数 |", "|---|---|---|---|"]
    lines += [f"| {r.tier} | {r.pages} | {r.cost_cny:.4f} | {r.pages_unpriced} |" for r in rows]
    total_pages = sum(r.pages for r in rows)
    total_cost = sum((r.cost_cny for r in rows), Decimal(0))
    total_unpriced = sum(r.pages_unpriced for r in rows)
    lines.append(f"| 合计 | {total_pages} | {total_cost:.4f} | {total_unpriced} |")
    return "\n".join(lines)


def evaluate_tier_alerts(
    day_rows: Sequence[TierRow],
    *,
    engine_unavailable_pages: int,
    month_cost_cny: Decimal,
    monthly_budget_cny: Decimal,
) -> list[Alert]:
    alerts: list[Alert] = []
    total = sum(r.pages for r in day_rows)
    l3 = sum(r.pages for r in day_rows if r.tier == "L3")
    if total >= L3_SHARE_MIN_PAGES and l3 / total > L3_SHARE_ALERT:
        alerts.append(Alert("parse_tiered", "warning", "parse_tiered:l3_share",
                            f"近 24 小时 L3 占比 {l3 / total:.0%} 超过 {L3_SHARE_ALERT:.0%}",
                            f"L3 {l3} 页 / 共 {total} 页；检查引擎健康与校验失败原因"))
    if engine_unavailable_pages > 0:
        alerts.append(Alert("parse_tiered", "warning", "parse_tiered:engine_unavailable",
                            f"近 24 小时有 {engine_unavailable_pages} 页因引擎不可达降级",
                            "docker compose ps 查看 parse-* 容器；降级页已走 TextIn"))
    threshold = monthly_budget_cny * PARSE_SPEND_ALERT_SHARE
    if month_cost_cny >= threshold:
        severity = "critical" if month_cost_cny >= monthly_budget_cny else "warning"
        alerts.append(Alert("parse_tiered", severity, "parse_tiered:budget",
                            f"本月解析估算花费 {month_cost_cny:.2f} 元，已达总预算的 {month_cost_cny / monthly_budget_cny:.0%}",
                            "ADR-0008 推翻条件：解析支出超过总预算 30%"))
    return alerts


def collect_tier_alerts(
    conn: psycopg.Connection, *, now: datetime, prices: TierPrices, monthly_budget_cny: Decimal
) -> list[Alert]:
    day = tier_summary(conn, start=now - timedelta(hours=24), end=now, prices=prices)
    month_start = now.astimezone(SHANGHAI).replace(day=1, hour=0, minute=0, second=0, microsecond=0)
    month = tier_summary(conn, start=month_start, end=now, prices=prices)
    row = conn.execute(
        "SELECT count(*) FROM core.parse_page_route WHERE routed_at >= %s AND routed_at < %s"
        " AND array_to_string(reasons, ' ') LIKE %s",
        (now - timedelta(hours=24), now, "%不可达%"),
    ).fetchone()
    legacy = conn.execute(
        "SELECT coalesce(sum(cost_cents), 0) / 100 FROM core.provider_snapshot"
        " WHERE provider = 'textin' AND fetched_at >= %s AND fetched_at < %s",
        (month_start, now),
    ).fetchone()
    month_cost = sum((r.cost_cny for r in month), Decimal(0)) + Decimal(legacy[0] if legacy else 0)
    return evaluate_tier_alerts(
        day,
        engine_unavailable_pages=int(row[0]) if row else 0,
        month_cost_cny=month_cost,
        monthly_budget_cny=monthly_budget_cny,
    )


def emit_tier_alerts(
    conn: psycopg.Connection, *, now: datetime, prices: TierPrices, monthly_budget_cny: Decimal
) -> list[dict[str, str]]:
    alerts = collect_tier_alerts(conn, now=now, prices=prices, monthly_budget_cny=monthly_budget_cny)
    return [raise_alert(conn, a, now=now) for a in alerts]
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/factory.py
"""按配置组装 TieredParser；开关没开或没有任何低成本层级可用时原样返回 TextIn——线上行为不变。"""

from __future__ import annotations

import json
import logging
from collections.abc import Callable

from ragdemo.config import ConfigError, RagdemoConfig
from ragdemo.ops.alerts import Alert, raise_alert
from ragdemo.parse.describer_factory import deepseek_client
from ragdemo.parse.local.structure import LlmStructurer
from ragdemo.parse.textin import DocumentParser, TextInParser
from ragdemo.parse.tiered.engines import VISION_ENGINE_NAME, EngineUnavailable, PageEngine
from ragdemo.parse.tiered.http_engine import engine_from_url
from ragdemo.parse.tiered.parser import TieredParser
from ragdemo.parse.tiered.route import L2_SUPPORTED, RouteContext
from ragdemo_core.blob import BlobStore

logger = logging.getLogger("ragdemo.parse.tiered")
L0_PROMPT_VERSION = "v1"  # 与 LlmStructurer 默认 prompt_version 一致；改 prompt 必须重跑 T2


def _default_engine_factory(cfg: RagdemoConfig) -> Callable[[str, str], PageEngine]:
    def make(name: str, url: str) -> PageEngine:
        if name == VISION_ENGINE_NAME:
            from ragdemo.parse.tiered.vision_engine import VisionPageEngine, vision_client

            assert cfg.vision_model_name is not None  # load_config 已校验
            return VisionPageEngine(vision_client(url), model=cfg.vision_model_name)
        return engine_from_url(name, url)  # type: ignore[arg-type]

    return make


def _engine_url(name: str, cfg: RagdemoConfig) -> str:
    url = {"paddle": cfg.parse_paddle_base_url, "mineru": cfg.parse_mineru_base_url,
           VISION_ENGINE_NAME: cfg.vision_model_base_url}[name]
    assert url is not None  # load_config 已校验
    return url


def _try_engine(name: str, cfg: RagdemoConfig, make: Callable[[str, str], PageEngine]) -> PageEngine | None:
    try:
        return make(name, _engine_url(name, cfg))
    except EngineUnavailable as exc:
        logger.warning(json.dumps({"event": "parse_engine_unavailable", "engine": name, "error": str(exc)}, ensure_ascii=False))
        raise_alert(None, Alert("parse_tiered", "warning", "parse_tiered:engine_unavailable",
                                f"解析引擎 {name} 启动时不可达，本次运行该层级关闭", str(exc)))
        return None


def with_tiered_routing(
    textin: TextInParser,
    blob: BlobStore,
    cfg: RagdemoConfig,
    *,
    engine_factory: Callable[[str, str], PageEngine] | None = None,
) -> DocumentParser:
    if not cfg.parse_tiered_enabled:
        return textin
    if cfg.parse_l2_enabled and not L2_SUPPORTED:
        raise ConfigError("PARSE_L2_ENABLED=true 但 L2 分支尚未落地（解析分级路由计划 T10）")
    make = engine_factory or _default_engine_factory(cfg)
    structurer = None
    if cfg.parse_tier_l0_enabled:
        if not cfg.model_base_url:
            raise ConfigError("PARSE_TIER_L0_ENABLED=true 需要 MODEL_BASE_URL")
        structurer = LlmStructurer(deepseek_client(cfg.model_base_url), model=cfg.model_name)
    primary = _try_engine(cfg.parse_l1_engine, cfg, make) if cfg.parse_l1_engine else None
    secondary = None
    if cfg.parse_l2_enabled and primary is not None and cfg.parse_l2_second_engine:
        secondary = _try_engine(cfg.parse_l2_second_engine, cfg, make)
    if structurer is None and primary is None:
        return textin  # 没有任何可用的低成本层级：整份走 TextIn
    ctx = RouteContext(
        structurer=structurer,
        primary=primary,
        secondary=secondary,
        l0_tag=f"{cfg.model_name}+{L0_PROMPT_VERSION}" if structurer is not None else "off",
    )
    return TieredParser(
        textin, blob, context=ctx, doc_types=frozenset(cfg.parse_tiered_doc_types), textin_fp=textin.param_fp
    )
```

## 已知局限（写进 ADR-0015"后果"）

1. **多栏正文被当成表格。** L0 的坐标还原会把三栏版面误判为表格区域；自托管引擎的版面分析也可能把并排栏目切错。校验只保证数字与关键字不增不减，不保证阅读顺序。
2. **数字多重集校验对排列不敏感。** 同一页内两个数字互换位置（或互换到相邻单元格）不会被 `closure_violations` / `verify_dual` 的数字比较发现；L2 的表格行互召回能抓"跨行互换"，抓不到"同行跨列互换"。靠 T7/T15 的人工抽查兜底。
3. **引擎组合上限。** 同一时刻只允许 1 个 L1 主引擎 + 1 个 L2 副引擎；不做 N 路投票。两个引擎犯同一个错（例如同一模糊字形都认成同一个错字）时 L2 会放行——这是双引擎一致方案的理论上限。
4. **不同引擎表格的 HTML 与 markdown 归一化差异。** 合并单元格展开成重复值会使块内容里的数字出现次数多于原表（与 TextIn 路径同一表示，ADR-0008）；校验在块转换**之前**对引擎原始输出做；`&nbsp;`、全角数字、千分位、公式（`$...$`）里的数字由 `numbers_in` 的归一化规则决定，个别引擎的特殊转义可能造成误拒（多花钱，不会误收）。
5. **页眉页脚与页码。** 引擎丢掉页码会被判"丢失数字"→ 降级 L3（误拒）。薄壳已配置输出页眉页脚，仍可能有个别版本忽略。
6. **跨页表只在 L3 连续段内合并。** L0/L1/L2 页上的跨页表被拆成两页各自的表格块；检索时可能两半分别命中。
7. **section_path 由标题层级统一重建。** 不同引擎的标题层级判断不同，混合文档的章节路径可能比纯 TextIn 浅或深一层。
8. **文字层乱码但非 `(cid:` 形态**（错误的 ToUnicode 映射）识别不出，会被当成有文字层，L1 校验以错误文字层为准可能误拒或误收；属 Phase A 已知限制的延续。
9. **财务报表页识别是关键词 + 数字密度启发式。** 漏判的报表页会进入 L0/L1（仍受校验约束）；年报/季报整份 L3 不依赖它。
10. **TextIn 不是标准答案。** 基准指标只表示"与 TextIn 一致"，分歧靠人工裁定。
11. **`elapsed_ms` 不含 L3 的 TextIn 调用时间**；单页耗时门槛只衡量自托管引擎。
12. **私有材料不走分级路由**——私有材料本可以完全本地解析，留给 P4。
