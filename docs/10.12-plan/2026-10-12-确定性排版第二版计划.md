## Global Constraints

- **溯源保证不变（CLAUDE.md §0）。** L0 输出的每个内容字符都来自（剥离装饰后的）PDF 文字层。v2 只允许做三件事：在行首加 `#`、在**同一行内**按大空隙把"编号标题 + 行尾数值"拆成两行（只插入换行，不增删字符）、合并段落时决定行间空格。每个 L0 接受页仍走现有双向数字闭合 + 双向字符闭合（`pipeline._self_check`），**一条都不放松、不加豁免**。
- **图表碎片不做闭合豁免。** v1 的唯一误报是 `( 4 %` 与 `)` 被分到两处，输出读成 `4%`、原文是 `(4%)`——财务口径里括号即负数，这不是"仅空白差异"，豁免它就等于允许改号。处理方式是**页型降级**（T4），闭合校验的定义不变（有测试证明它照样拦截）。
- **计算与生成分离（§1.2）：** L0 全程无模型；所有指标、门槛、成本由本计划的纯函数计算并有单测。
- **防过拟合（硬规则）：** 样本按文档拆成调参集与留出集（固定种子 `20261012`，清单 `docs/10.12-plan/l0v2/split.tsv` 入库）。调参集用来改规则与阈值；**留出集只在 T6 跑一次**（`docs/10.12-plan/l0v2/holdout-run.lock` 由脚本写入并提交，第二次运行直接拒绝），**不得据留出集结果再改规则、阈值或指标口径**。门槛与指标口径在本文写死（见"门槛"一节），执行中不得修改。可调常量及其允许范围事先登记（见"调参空间登记"），超出范围或新增规则必须写进调参记录并补测试。
- **不写库、不花钱：** T1–T6 只读 `core.document` 与对象存储里已有的 TextIn 缓存（离线实验脚本，与 `scripts/parse_compare.py` 同一例外），不写任何表；不调用任何模型、不现调 TextIn。迁移：本计划**不新增迁移**（GO 后的逐页记账沿用分级路由计划的 `028_parse_page_route.sql`）。
- **研报原文不入 git：** `docs/rawdata/**/*.pdf` 已被 `docs/rawdata/.gitignore` 忽略。测试要用真实版面时，提交的是**脱敏版面夹具**（`tests/fixtures/layouts/*.json`：只保留词坐标、字号、粗体，文字逐字替换为占位符——汉字→`字`、ASCII 字母→`x`、数字→`8`，标点保留），另配"本机有原文件才跑"的真实文件测试（`pytest.skip`）。人工判定表里含研报文字的（标题判定、阅读顺序抽查）放在被 git 忽略的 `data/experiments/l0v2/`，只把计数写进报告。
- **TDD（§3）：** 先写失败测试、看到失败、最小实现、看到通过、提交。数值与时点逻辑无例外。**不得修改既有测试的断言来迁就新实现**；若既有测试与本计划的规则冲突，停下来报告（BLOCKED），由控制者裁决。

## 检索是否依赖标题层级（读代码的结论，决定标题门槛的严格程度）

读到的事实（均已核对路径）：

1. **切块**（`parse/chunker.py`）：`chunk_document` 跳过 `title` 块（"标题不单独成块，它以 section_path 的形式进入每个块"）；段落叶子的内容是 `f"{section_path}\n{text}"`（`_with_section_prefix`）；表格叶子**不加**前缀；`_merge_short_paragraphs` 只在"同 `section_path`、同页"的相邻短段落之间合并（`leaf_min_chars=200`、`leaf_max_chars=400`，`parse/config.py`）。
2. **父块**（`parse/tree.py` `build_tree`）：按 `section_path` 为每个小节建一个父块；`retrieval/expand.py` 命中叶子后用 `_SQL_PARENT_CONTENT` 把父块及其全部叶子拼成证据——小节越大，证据越长。
3. **检索信号**：BM25 在 `retrieval/lexical.py` 里对 `content` 检索（`WHERE content ||| %(query)s`），`content` 已含 section_path 前缀；嵌入输入 `embed/base.py` 的 `embedding_input` 再拼一次 `doc_title`、`section_path`、`content_desc`、`content`。
4. **表格描述**：`parse/describe.py` 用 `section_path` 最后一段做表格描述的上下文（`table_describe` prompt 的 `{section_path}`）。
5. **评测**：`eval_retrieval` 按 `gold_block_ids` 计 recall@10（`evals/runner.py`）；`evals/generate.py` 合成题目时用 `_body` 去掉前缀再取正文；`gold` 是块 ID，标题层级不直接参与打分。`quality/checks.py` 用 `section_path` 判定相邻短块。
6. 分级路由计划 T8 的 `assemble_blocks` 按 markdown 的 `#` 级数重建 `section_path`（`#` → level 0），所以 L0 的标题与层级**直接决定**入库块的 `section_path`。

结论（标题对切块与检索评测的实际影响）：

- **误标（把正文句标成标题）伤害最大且隐蔽**：那句话会进入其后所有段落叶子的前缀，直到出现同级或更高级标题——BM25 与嵌入都被污染；同时切断短段合并，产生更多几十字的碎块；父块被切碎，证据上下文残缺。recall@10 会下降，但闭合校验完全看不见。→ **精确率必须严**。
- **漏标**主要影响两件事：块前缀少了章节名（BM25 / 嵌入少一个弱信号）；同页短段落可能跨章节合并（受 400 字上限约束）；父块变大（极端情况整份文档一个父块）→ 证据上下文膨胀、生成成本上升。对 recall@10 的影响小于误标。→ **召回可以放宽**，而且 v1 已估计"编号样式"规则的召回上界约 0.80（TextIn 会把整句话标成 `###`，规则无法复现）。
- **层级错**改变前缀的深浅与父块边界，影响介于两者之间；TextIn 的绝对级数本身也不稳定（同类标题在不同文档里是 `###` 或 `####`），所以按**相对层级**（相邻两个匹配标题之间"更深 / 同级 / 更浅"是否一致）评估。
- 据此的门槛：标题精确率 ≥ 0.85（公告，对 TextIn，自动）且研报人工判定精确率 ≥ 0.85；召回 ≥ 0.60；相对层级一致率 ≥ 0.85。GO 后用 T8 的"块结构指标"（空 section_path 叶子占比、父块长度 p95）监控漏标带来的证据膨胀，并用分组 recall@10 检验净效果。

### 指标口径（事先写死）

- **页型**：每页一个 `PageKind`，按顺序判定、先中先得：`no_text_layer`（`needs_handback` 或剥离前文字层含 `(cid:`）→ `financial_statement`（`is_financial_statement_page`）→ `multicolumn`（旋转文字残留、竖排单字列、整页纵向空白带）→ `table`（`find_table_regions` 有区域）→ `chart_fragments`（图表碎片行 ≥ 3）→ `table`（连续 ≥ 2 行"疑似表格行"）→ `plain_text`。只有 `plain_text` 进入排版与自检；**L0 接受** = `plain_text` 且自检通过（`status == "ok"`）。
- **"含表格"的判定**：坐标表格区域（`find_table_regions`：连续 ≥ 3 行、每行 ≥ 2 段、≥ 3 列），或连续 ≥ 2 行"疑似表格行"（行内按 ≥ 2 字宽的空隙切成 ≥ 2 段，且行内 ≥ 2 个数字）。后者专门兜住 v1 漏识的"主要会计数据"类小表（v1 有 118 / 205 条 TextIn 数据行流进了段落）。
- **数字召回（新口径，G3）**：只在 docs 组 `doc_type = announcement` 的 **L0 接受页**上算；参考 = 同一页的 TextIn 结果（由 `parse_json_ref` 的 `detail[]` 经 `blocks_from_detail` 重建，**不含** TextIn 标注的页眉页脚 `content == 1`，即"TextIn 会入库的内容"）；候选 = 该页 L0 markdown；按页累加的 micro 召回。每个缺失数字归入四类之一：`decor_stripped`（在本页被剥离的装饰文字里）、`not_in_text_layer`（数字串在本页文字层里根本不存在——TextIn 从图片里 OCR 出来的）、`tokenization`（数字串在文字层里，但分词不同，如跨词或与相邻字符连写）、`unexplained`（文字层里有这个数字、L0 输出却少了——构造上不可能，出现即 bug）。v1 的口径（整份文档、只算 accepted 文档、参考是整份 TextIn markdown）在 T4 诊断里复现并解释，不再作门槛。
- **标题（G6）**：docs 组 announcement 的 L0 接受页；参考 = 同页 TextIn 标题（`#` 级数 = `outline_level + 1`）。匹配用"只留字母数字"的规范化文本按多重集合匹配；**两条相邻同级候选标题拼起来恰好等于某条参考标题、而各自都匹配不上时合并为一条**（TextIn 常把两行的公告题目合成一行，v1 有 10 个错配属于此类）。层级用相对层级一致率：按文档顺序贪心对齐匹配上的标题，相邻两对的级差符号（+ / 0 / −）相同即一致。
- **多栏漏检（G4）**：人工标注为 `multi` 的页里，被 L0 **接受**的比例（这才是安全意义上的漏检：没被拦下、进了 L0）。**多栏误检（G5）**：人工标注为 `single` 的页里被判 `multicolumn` 的比例（只影响成本）。
- **表格泄漏（G8）**：L0 接受页中，同页 TextIn 参考含 ≥ 1 条表格数据行（`compare` 的表格行口径：每表跳过首行、行内 ≥ 2 个数字）的页占比。
- **对文字层精确率（G2）**：独立审计（不经过 `_self_check`）：每个 L0 接受页的内容字符（`isalnum`）多重集合 == 剥离后文字层词的内容字符多重集合，且输出数字多重集合 ⊆ 剥离后 `layout.text` 的数字多重集合。
- **覆盖率（G10）**：L0 接受页 / 有文字层页（`kind != no_text_layer`），分 announcement 与 research。
- **耗时（G12）**：每份文档"版面提取 + `parse_layouts_l0`"总耗时 / 页数，取全部页的 p95（开发机）。

### 门槛（现在写死，T6 执行时不得修改）

| 编号 | 页型 / 集合 | 指标 | 门槛 |
|---|---|---|---|
| G1 | 纯文字页（docs + research） | `plain_text` 页里自检失败（`closure_failed`）的页数 | = 0 |
| G2 | L0 接受页（docs + research） | 独立审计不一致页数（对文字层精确率 = 1.0） | = 0 |
| G3 | L0 接受页（announcement） | 数字召回（新口径，micro） | ≥ 0.99 |
| G3b | L0 接受页（announcement） | `unexplained` 缺失数字个数 | = 0 |
| G4 | 人工标注页（留出集） | 多栏漏检率（需标注为 `multi` 的页 ≥ 30） | ≤ 0.05 |
| G5 | 人工标注页（留出集） | 多栏误检率 | ≤ 0.15 |
| G6a / G6b / G6c | L0 接受页（announcement） | 标题召回 / 精确率 / 相对层级一致率 | ≥ 0.60 / ≥ 0.85 / ≥ 0.85 |
| G7 | L0 接受页（research，人工） | 标题精确率（随机抽 min(100, 全部) 个，判定数 ≥ min(60, 全部)；标题总数 < 30 时不适用） | ≥ 0.85 |
| G8 | L0 接受页（announcement） | 表格泄漏页占比 | ≤ 0.05 |
| G9 | L0 接受页（人工抽查 announcement 15 + research 15，不足则全部） | 阅读顺序错误（不同文字流交错）页数 | = 0 |
| G10a / G10b | 有文字层页 | L0 覆盖率 announcement / research | ≥ 0.30 / ≥ 0.15 |
| G11 | 有文字层页（announcement） | 判为 `multicolumn` 的页占比 | ≤ 0.10 |
| G12 | 全部页 | 每页耗时 p95 | ≤ 1.0 s |

取值依据：G1 / G2 / G3b 是溯源硬线，只能是 0。G3 沿用 v1 门槛 0.99，但换成"只看 L0 接受页、参考不含 TextIn 页眉页脚"的口径（v1 的 0.9855 由 8 份表格密集的摘要类文档拉低，这些页在 v2 里不进 L0，详见 T4）。G4 ≤ 0.05：多栏页一旦被接受就是静默的阅读顺序错误，闭合抓不到，必须低；最少 30 个正例才有意义（v1 灵敏度测试显示研报首页几乎都是侧栏，留出集约 41 份研报首页足够）。G5 ≤ 0.15：误检只多花钱。G6 见上一节。G8 ≤ 0.05：L0 页理论上不含表格，泄漏即"表格行流进段落"。G9 = 0：阅读顺序是闭合校验唯一看不见的维度，只能人工。G10：低于该覆盖率时每页节省不足 0.04 元（公告）/ 0.02 元（研报），不值得多一级路由的运维复杂度（TextIn 实测 34.84 元 / 257 页 = 0.1356 元 / 页）。G11 ≤ 0.10：公告几乎全是单栏，v1 为 3.8%，超过 10% 说明检测器误报主导。G12：v1 实测 0.13–0.16 s / 页，整页扫描后给 1 s 余量。

**GO** = 留出集上 G1–G12 全部通过（不适用的 G7 计为通过）。**NO-GO** = 任一未过；留出集已"用掉"，后续若做 v3 必须另取新留出样本（开放问题 3）。调参集上门槛未全过时**不跑留出集**，直接以调参集结果报 NO-GO（留出集保持未用）。

"""L0 第二版的评估样本：按文档拆分调参集 / 留出集（固定种子），以及脱敏版面夹具。

拆分是防过拟合的根：调参集用来改规则，留出集只在最后跑一次。拆分清单入库，之后不得重生成。
研报原文不入 git（ADR-0014），测试用的真实版面只保留几何信息，文字逐字替换为占位符。"""

from __future__ import annotations

import random
import re
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Final, Literal, cast

from ragdemo.parse.local.layout import PageLayout, Word

SPLIT_SEED: Final = 20261012
Group = Literal["docs", "research"]
SampleSet = Literal["tune", "holdout"]
SPLIT_HEADER: Final = "group\tkey\tstratum\tset\tforced"

# v1 报告 §7 展示过、或被本计划用作测试夹具的文档：已经被看过，只能进调参集。
FORCED_TUNE: Final[frozenset[str]] = frozenset(

        "AP202408191639328385",  # 太平洋 2024-08-19：首页竖排"公司研究"
        "AP202604151821234936",  # 山西 2026-04-15：首页行情侧栏

        "AP202310201602162496",  # 开源 2023-10-20：v1 §7 样例
    }
)

_AP = re.compile(r"_(AP\d+)\.pdf$")


def research_key(filename: str) -> str:
    m = _AP.search(filename)
    if m is None:
        raise ValueError(f"研报文件名里没有 AP 编号：{filename}")
    return m.group(1)


def broker_of(filename: str) -> str:
    parts = filename.split("_")
    if len(parts) < 3:
        raise ValueError(f"研报文件名不是 日期_券商_标题_AP编号 格式：{filename}")
    return parts[1]


@dataclass(frozen=True)
class SampleDoc:
    group: Group
    key: str  # docs：doc_id；research：AP 编号
    stratum: str  # docs：doc_type；research：券商


@dataclass(frozen=True)
class SplitRow:
    doc: SampleDoc
    sample_set: SampleSet
    forced: bool = False


def split_samples(
    docs: Sequence[SampleDoc], *, forced_tune: frozenset[str], seed: int = SPLIT_SEED
) -> list[SplitRow]:
    """强制项进调参集；其余按（组, 分层）分桶，每桶 ⌊n/2⌋ 份进留出集，余下进调参集。"""
    rng = random.Random(seed)
    out: list[SplitRow] = []
    buckets: dict[tuple[str, str], list[SampleDoc]] = {}
    for d in sorted(docs, key=lambda d: (d.group, d.stratum, d.key)):
        if d.key in forced_tune:
            out.append(SplitRow(d, "tune", True))
        else:
            buckets.setdefault((d.group, d.stratum), []).append(d)
    for bucket in sorted(buckets):
        shuffled = list(buckets[bucket])
        rng.shuffle(shuffled)
        n_hold = len(shuffled) // 2
        out.extend(SplitRow(d, "holdout" if i < n_hold else "tune") for i, d in enumerate(shuffled))
    return sorted(out, key=lambda r: (r.doc.group, r.doc.key))


def write_split(rows: Sequence[SplitRow], path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    lines = [SPLIT_HEADER]
    lines += [
        f"{r.doc.group}\t{r.doc.key}\t{r.doc.stratum}\t{r.sample_set}\t{int(r.forced)}" for r in rows
    ]
    path.write_text("\n".join(lines) + "\n", encoding="utf-8")


def read_split(path: Path) -> list[SplitRow]:
    lines = path.read_text(encoding="utf-8").splitlines()
    if not lines or lines[0] != SPLIT_HEADER:
        raise ValueError(f"{path} 不是拆分清单（表头应为 {SPLIT_HEADER!r}）")
    rows: list[SplitRow] = []
    for line in lines[1:]:
        if not line.strip():
            continue
        group, key, stratum, sample_set, forced = line.split("\t")
        if group not in ("docs", "research") or sample_set not in ("tune", "holdout"):
            raise ValueError(f"拆分清单行非法：{line!r}")
        rows.append(
            SplitRow(
                SampleDoc(cast(Group, group), key, stratum), cast(SampleSet, sample_set), forced == "1"
            )
        )
    return rows


def mask_text(text: str) -> str:
    """逐字替换（长度不变）：汉字 → 字，ASCII 字母 → x，数字 → 8；标点与空白原样保留。"""
    out: list[str] = []
    for ch in text:
        if "0" <= ch <= "9" or "０" <= ch <= "９":
            out.append("8")
        elif "一" <= ch <= "鿿" or "㐀" <= ch <= "䶿":
            out.append("字")
        elif ch.isascii() and ch.isalpha():
            out.append("x")
        else:
            out.append(ch)
    return "".join(out)


def layout_to_fixture(layout: PageLayout) -> dict[str, Any]:
    return {
        "page": layout.page,
        "width": round(layout.width, 2),
        "height": round(layout.height, 2),
        "text": mask_text(layout.text),
        "words": [
            [mask_text(w.text), round(w.x0, 2), round(w.x1, 2), round(w.top, 2),
             round(w.bottom, 2), w.upright, round(w.size, 2), w.bold]
            for w in layout.words
        ],
    }


def layout_from_fixture(d: Mapping[str, Any]) -> PageLayout:
    words = [
        Word(str(t), float(x0), float(x1), float(top), float(bottom), bool(up), float(size), bool(bold))
        for t, x0, x1, top, bottom, up, size, bold in d["words"]
    ]
    return PageLayout(int(d["page"]), float(d["width"]), float(d["height"]), words, str(d["text"]))

def split_segments(row: Sequence[Word], gap: float) -> list[list[Word]]:
    """把一行（已按 x0 升序）在 >= gap 的横向空隙处切成段。"""
    segs: list[list[Word]] = []
    for w in row:
        if segs and w.x0 - segs[-1][-1].x1 < gap:
            segs[-1].append(w)
        else:
            segs.append([w])
    return segs

# packages/ragdemo/src/ragdemo/parse/local/headings.py
"""编号标题规则（纯函数）：识别中文公告 / 研报的章节编号，校验同一文档内编号的连续性，按编号体系定级。

只判断"哪一行是标题、第几级"；加 `#` 由 typeset 完成，任何字符都不增删。
连续性校验是精确率的主要保障："3.5亿元……"这类以数字开头的正文行即使长得像 `1.1`，
也会因为前面没有 `3.4`（或不是该层的第 1 个）而被剔除。"""

from __future__ import annotations

import re
from collections import Counter
from collections.abc import Sequence
from dataclasses import dataclass
from typing import Final, Literal

NumberingSystem = Literal[
    "chapter", "section", "cn", "cn_paren", "arabic", "decimal2", "decimal3", "arabic_paren", "keyword"
]
# 层级先后（GB/T 9704 惯例：第X章 > 第X节 > 一、 > （一） > 1. > 1.1 > 1.1.1 > （1））。
SYSTEM_ORDER: Final[tuple[NumberingSystem, ...]] = (
    "chapter", "section", "cn", "cn_paren", "arabic", "decimal2", "decimal3", "arabic_paren"
)
MIN_SYSTEM_HEADINGS = 2  # 一个编号体系在全文至少保留这么多个，才算"成体系"
MAX_LEVEL = 6
UNIT_AFTER_NUMBER: Final = "亿万千百元%％倍个家人台年月日"

_CN = "一二三四五六七八九十零〇"
_PATTERNS: Final[tuple[tuple[NumberingSystem, re.Pattern[str]], ...]] = (
    ("chapter", re.compile(rf"^第([{_CN}]+)章")),
    ("section", re.compile(rf"^第([{_CN}]+)节")),
    ("cn", re.compile(rf"^([{_CN}]{{1,3}})[、．.](?=\S)")),
    ("cn_paren", re.compile(rf"^[（(]([{_CN}]{{1,3}})[）)](?=\S)")),
    ("decimal3", re.compile(r"^(\d{1,2})\.(\d{1,2})\.(\d{1,2})(?![\d.])\s*(?=\S)")),
    ("decimal2", re.compile(r"^(\d{1,2})\.(\d{1,2})(?![\d.])\s*(?=\S)")),
    ("arabic", re.compile(r"^(\d{1,2})[、．.](?!\d)\s*(?=\S)")),
    ("arabic_paren", re.compile(r"^[（(](\d{1,2})[）)]\s*(?=\S)")),
)
_KEYWORD = re.compile(
    r"^(?:(?:特别提示|重要提示|重要内容提示|释义|目录|备查文件目录|备查文件|风险提示)[：:]?"
    r"|附件[一二三四五六七八九十\d]{0,3}(?:[：:].{0,30})?)$"
)
_CN_DIGITS: Final = {"零": 0, "〇": 0, "一": 1, "二": 2, "三": 3, "四": 4, "五": 5, "六": 6, "七": 7, "八": 8, "九": 9}


@dataclass(frozen=True)
class Numbering:
    system: NumberingSystem
    ordinal: int  # keyword 为 0
    scope: tuple[int, ...] = ()  # 小数编号的前缀（1.2.3 → (1, 2)），其余为空


def cn_numeral(s: str) -> int | None:
    """一 … 九十九。不支持"百"（章节号不会这么大）。"""
    if not s:
        return None
    if "十" in s:
        tens_s, _, ones_s = s.partition("十")
        tens = _CN_DIGITS.get(tens_s) if tens_s else 1
        ones = _CN_DIGITS.get(ones_s) if ones_s else 0
        if tens is None or ones is None:
            return None
        return tens * 10 + ones
    return _CN_DIGITS.get(s) if len(s) == 1 else None


def numbering_of(text: str) -> Numbering | None:
    s = text.strip()
    if _KEYWORD.match(s):
        return Numbering("keyword", 0)
    for system, pat in _PATTERNS:
        m = pat.match(s)
        if m is None:
            continue
        rest = s[m.end():].lstrip()
        if system in ("decimal2", "decimal3", "arabic") and rest[:1] and rest[0] in UNIT_AFTER_NUMBER:
            return None  # "3.5亿元""1.5倍"：带单位的数值，不是编号
        groups = m.groups()
        if system in ("chapter", "section", "cn", "cn_paren"):
            n = cn_numeral(groups[0])
            return None if n is None else Numbering(system, n)
        nums = tuple(int(g) for g in groups)
        return Numbering(system, nums[-1], nums[:-1])
    return None


@dataclass(frozen=True)
class Candidate:
    index: int  # 调用方的行序号（文档顺序）
    numbering: Numbering


def keep_consistent(cands: Sequence[Candidate]) -> frozenset[int]:
    """按文档顺序保留编号连续的候选：同一体系同一前缀内，第一个必须是 1，之后必须 +1；
    出现更高一级的标题时，所有更低级体系的计数清零。最后剔除不足 MIN_SYSTEM_HEADINGS 个的体系。"""
    kept: list[Candidate] = []
    last: dict[tuple[NumberingSystem, tuple[int, ...]], int] = {}
    for c in cands:
        n = c.numbering
        if n.system == "keyword":
            kept.append(c)
            continue
        key = (n.system, n.scope)
        prev = last.get(key)
        if not ((prev is None and n.ordinal == 1) or (prev is not None and n.ordinal == prev + 1)):
            continue
        rank = SYSTEM_ORDER.index(n.system)
        for k in [k for k in last if SYSTEM_ORDER.index(k[0]) > rank]:
            del last[k]
        last[key] = n.ordinal
        kept.append(c)
    per_system = Counter(c.numbering.system for c in kept)
    return frozenset(
        c.index
        for c in kept
        if c.numbering.system == "keyword" or per_system[c.numbering.system] >= MIN_SYSTEM_HEADINGS
    )


def assign_levels(systems: Sequence[NumberingSystem], *, base: int) -> dict[NumberingSystem, int]:
    """base = 字号标题已用掉的级数。文档里出现的编号体系按 SYSTEM_ORDER 依次占 base+1、base+2……；
    关键词标题（释义、重要内容提示……）与最高一级编号同级。"""
    present = sorted({s for s in systems if s != "keyword"}, key=SYSTEM_ORDER.index)
    levels: dict[NumberingSystem, int] = {s: min(base + 1 + i, MAX_LEVEL) for i, s in enumerate(present)}
    levels["keyword"] = min(base + 1, MAX_LEVEL)
    return levels

def _gaps(items: Sequence[_Item], i: int) -> tuple[float | None, float | None]:
    line = items[i]
    assert isinstance(line, _Line)
    above = below = None
    if i > 0:
        prev = items[i - 1]
        above = line.mid - (prev.mid if isinstance(prev, _Line) else prev.last_mid)
    if i + 1 < len(items):
        nxt = items[i + 1]
        below = (nxt.mid if isinstance(nxt, _Line) else nxt.first_mid) - line.mid
    return above, below


def _right_margin(items: Sequence[_Item]) -> float:
    xs = sorted(it.x1 for it in items if isinstance(it, _Line))
    return xs[int(0.9 * (len(xs) - 1))] if xs else 0.0


def _numbered(
    items: Sequence[_Item], i: int, body_size: float, pitch: float, right: float
) -> Numbering | None:
    line = items[i]
    assert isinstance(line, _Line)
    head = line.head_text.strip()
    n = numbering_of(head)
    if n is None or len(head) > NUMBERED_HEADING_MAX_CHARS:
        return None
    if n.system != "keyword" and head[-1] in SENTENCE_END:
        return None
    size = line.size or body_size or 10.0
    if not line.rest_text and line.head_x1 >= right - SHORT_LINE_FACTOR * size:
        return None  # 一直写到版心右缘：折行的正文段落，不是标题
    if not NUMBERED_NEEDS_SIGNAL:
        return n
    above, below = _gaps(items, i)
    signal = (
        line.bold
        or (body_size > 0 and line.size >= HEADING_EMPHASIS_RATIO * body_size)
        or (above is not None and above > HEADING_GAP_FACTOR * pitch)
        or (below is not None and below > HEADING_GAP_FACTOR * pitch)
    )
    return n if signal else None


def _bold_heading(items: Sequence[_Item], i: int, body_size: float, pitch: float) -> bool:
    line = items[i]
    assert isinstance(line, _Line)
    text = line.text.strip()
    if not (
        line.bold
        and len(text) <= BOLD_HEADING_MAX_CHARS
        and text[-1] not in SENTENCE_END
        and any(ch.isalpha() for ch in text)
        and (body_size == 0 or line.size <= HEADING_SIZE_RATIO * body_size)
    ):
        return False
    for j in (i - 1, i + 1):  # 相邻行也是整行粗体：强调段落，不是标题
        if 0 <= j < len(items):
            nb = items[j]
            if isinstance(nb, _Line) and nb.bold:
                return False
    above, below = _gaps(items, i)
    gaps = [g for g in (above, below) if g is not None]
    return bool(gaps) and all(g > BOLD_HEADING_GAP_FACTOR * pitch for g in gaps)

        if c.index in kept:
            ln = flat[c.index]
            ln.heading_level = levels[c.numbering.system]
            ln.split = bool(ln.rest_text)
            deepest = max(deepest, ln.heading_level)
    if total == 0 or bold > BOLD_DOC_MAX_SHARE * total:
        return
    bold_level = min(max(MIN_BOLD_LEVEL, deepest + 1), MAX_LEVEL)
    for pi in live:
        for i, it in enumerate(pi.items):
            if isinstance(it, _Line) and not it.heading_level and _bold_heading(pi.items, i, body, pitch):
                it.heading_level = bold_level

def _merge_split_titles(cand: list[tuple[str, int]], ref_keys: Counter[str]) -> list[tuple[str, int]]:
    out: list[tuple[str, int]] = []
    i = 0
    while i < len(cand):
        if i + 1 < len(cand):
            (a, la), (b, lb) = cand[i], cand[i + 1]
            if la == lb and a not in ref_keys and b not in ref_keys and (a + b) in ref_keys:
                out.append((a + b, la))
                i += 2
                continue
        out.append(cand[i])
        i += 1
    return out


def _aligned_pairs(cand: list[tuple[str, int]], ref: list[tuple[str, int]]) -> list[tuple[int, int]]:
    pairs: list[tuple[int, int]] = []
    j = 0
    for i, (key, _) in enumerate(cand):
        for jj in range(j, len(ref)):
            if ref[jj][0] == key:
                pairs.append((i, jj))
                j = jj + 1
                break
    return pairs


def _sign(x: int) -> int:
    return (x > 0) - (x < 0)


def heading_matches_v2(candidate_md: str, reference_md: str) -> HeadingMatchV2:
    ref = _headings(reference_md)
    ref_keys = Counter(k for k, _ in ref)
    cand = _merge_split_titles(_headings(candidate_md), ref_keys)
    cand_keys = Counter(k for k, _ in cand)
    matched = sum(min(c, ref_keys.get(k, 0)) for k, c in cand_keys.items())
    agree = total = 0
    for (i1, j1), (i2, j2) in itertools.pairwise(_aligned_pairs(cand, ref)):
        total += 1
        agree += int(_sign(cand[i2][1] - cand[i1][1]) == _sign(ref[j2][1] - ref[j1][1]))
    return HeadingMatchV2(matched, len(cand), len(ref), agree, total)

"""整页多栏 / 侧栏检测（纯函数）。

v1 只看"同一行里的空隙"：侧栏行与正文行很少落在同一行（纵向错开几个点就被聚成两行），
所以研报首页的评级框 / 行情框几乎全部漏检，产出"字符一个不少、顺序错乱"的 ok 页。
这里对页面横向逐点扫描：某个 x 在一段连续的行里都没有被任何词跨过，且这段行里 x 左右两侧
各有 >= MIN_SIDE_ROWS 行文字、空白带足够宽、并落在页面中部区域，就是栏间空白带。
另查"竖排单字列"（研报左侧的"公 司 研 究"）。检出即判多栏，由上层降级，不在本地猜阅读顺序。"""

from __future__ import annotations

import itertools
import unicodedata
from collections.abc import Sequence
from dataclasses import dataclass

from ragdemo.parse.local.layout import PageLayout, Word
from ragdemo.parse.local.tables import cluster_rows, find_table_regions

GUTTER_ZONE = (0.15, 0.85)  # 空白带左缘 >= 页宽 * 下限、右缘 <= 页宽 * 上限（排除页边的右对齐日期 / 页码）
MIN_GUTTER_EM = 1.5  # 空白带宽度 >= 此值 * 正文字号
MIN_SIDE_ROWS = 3  # 空白带两侧各至少这么多行
X_STEP = 2.0  # 横向扫描步长（pt）
VERTICAL_MIN_CHARS = 3  # 竖排单字列：同一 x 上至少连续这么多个孤立单字
VERTICAL_X_TOL = 2.0
VERTICAL_ISOLATION_EM = 2.0  # 单字与同行其他词的距离 >= 此值 * 字号 才算"孤立"
REASON_GUTTER = "多栏版面：纵向空白带"
REASON_VERTICAL = "多栏版面：竖排单字"


@dataclass(frozen=True)
class Gutter:
    x: float
    left: float  # 左侧文字的最右端
    right: float  # 右侧文字的最左端
    top: float
    bottom: float
    left_rows: int
    right_rows: int


@dataclass(frozen=True)
class ColumnVerdict:
    multicolumn: bool
    reason: str = ""
    gutter: Gutter | None = None


def _wide(ch: str) -> bool:
    return unicodedata.east_asian_width(ch) in ("W", "F")


def _judge(run: Sequence[Sequence[Word]], x: float, min_width: float, lo: float, hi: float) -> Gutter | None:
    left_rows = [r for r in run if any(w.x1 <= x for w in r)]
    right_rows = [r for r in run if any(w.x0 >= x for w in r)]
    if len(left_rows) < MIN_SIDE_ROWS or len(right_rows) < MIN_SIDE_ROWS:
        return None
    left = max(w.x1 for r in left_rows for w in r if w.x1 <= x)
    right = min(w.x0 for r in right_rows for w in r if w.x0 >= x)
    if right - left < min_width or left < lo or right > hi:
        return None
    return Gutter(
        x, left, right,
        min(w.top for r in run for w in r), max(w.bottom for r in run for w in r),
        len(left_rows), len(right_rows),
    )


def _gutter_at(rows: Sequence[Sequence[Word]], x: float, min_width: float, lo: float, hi: float) -> Gutter | None:
    run: list[Sequence[Word]] = []
    for row in rows:
        if any(w.x0 < x < w.x1 for w in row):  # 这一行有词跨过 x：空白带在此中断
            g = _judge(run, x, min_width, lo, hi)
            if g is not None:
                return g
            run = []
        else:
            run.append(row)
    return _judge(run, x, min_width, lo, hi)


def _vertical_stack(rows: Sequence[Sequence[Word]], body_size: float) -> bool:
    em = body_size or 10.0
    singles: list[Word] = []
    for r in rows:
        for k, w in enumerate(r):
            if len(w.text) != 1 or not _wide(w.text):
                continue
            left_gap = w.x0 - r[k - 1].x1 if k > 0 else float("inf")
            right_gap = r[k + 1].x0 - w.x1 if k + 1 < len(r) else float("inf")
            if min(left_gap, right_gap) >= VERTICAL_ISOLATION_EM * em:
                singles.append(w)
    singles.sort(key=lambda w: (round(w.x0 / VERTICAL_X_TOL), w.top))
    run = 1
    for a, b in itertools.pairwise(singles):
        if abs(a.x0 - b.x0) <= VERTICAL_X_TOL and 0 < b.top - a.top <= 3 * em:
            run += 1
            if run >= VERTICAL_MIN_CHARS:
                return True
        else:
            run = 1
    return False


def detect_columns(rows: Sequence[Sequence[Word]], width: float, body_size: float) -> ColumnVerdict:
    """rows：非表格区域的行（按纵向位置升序，行内按 x0 升序）。只看直立词。"""
    upright = [[w for w in r if w.upright] for r in rows]
    upright = [r for r in upright if r]
    if _vertical_stack(upright, body_size):
        return ColumnVerdict(True, REASON_VERTICAL)
    lo, hi = GUTTER_ZONE[0] * width, GUTTER_ZONE[1] * width
    min_width = MIN_GUTTER_EM * (body_size or 10.0)
    x = lo
    while x <= hi:
        g = _gutter_at(upright, x, min_width, lo, hi)
        if g is not None:
            return ColumnVerdict(True, REASON_GUTTER, g)
        x += X_STEP
    return ColumnVerdict(False)


def page_columns(layout: PageLayout, body_size: float) -> ColumnVerdict:
    rows = cluster_rows([w for w in layout.words if w.upright])
    in_table = {id(w) for reg in find_table_regions(rows) for r in reg for w in r}
    return detect_columns([r for r in rows if id(r[0]) not in in_table], layout.width, body_size)

# packages/ragdemo/src/ragdemo/parse/local/chart.py
"""图表碎片页识别（纯函数）。

矢量图表的坐标轴刻度、数据标签会以零散短词出现在文字层里：阅读顺序没有意义，数字分词还对其周围的
空白很敏感——v1 唯一一例 closure_failed 就是 "( 4 %" 与 ")" 被排到两处，输出读成 4%、原文是 (4%)。
检出即整页降级（L1 / L3）；闭合校验不做任何豁免。"""

from __future__ import annotations

from collections.abc import Sequence

from ragdemo.parse.local.layout import Word
from ragdemo.parse.local.tables import split_segments

FRAGMENT_MAX_CHARS = 6
FRAGMENT_NUMERIC_SHARE = 0.5
FRAGMENT_SEGMENT_GAP = 8.0
CHART_MIN_FRAGMENT_ROWS = 3
_NUMERICISH = frozenset("0123456789.%-+()（）,，％−")


def _compact(text: str) -> str:
    return "".join(text.split())


def is_fragment_row(row: Sequence[Word]) -> bool:
    """整行很短且以数字类字符为主（"40%" "( 4 %" ")"），或一行里 >= 3 段短词且过半含数字（刻度行）。"""
    text = _compact("".join(w.text for w in row))
    if not text:
        return False
    if len(text) <= FRAGMENT_MAX_CHARS and sum(ch in _NUMERICISH for ch in text) >= FRAGMENT_NUMERIC_SHARE * len(text):
        return True
    segs = [_compact("".join(w.text for w in s)) for s in split_segments(row, FRAGMENT_SEGMENT_GAP)]
    if len(segs) < 3:
        return False
    return all(len(s) <= FRAGMENT_MAX_CHARS for s in segs) and 2 * sum(
        any(ch.isdigit() for ch in s) for s in segs
    ) >= len(segs)


def chart_fragment_rows(rows: Sequence[Sequence[Word]]) -> int:
    return sum(1 for r in rows if is_fragment_row(r))


def has_chart_fragments(rows: Sequence[Sequence[Word]]) -> bool:
    return chart_fragment_rows(rows) >= CHART_MIN_FRAGMENT_ROWS

```python
# packages/ragdemo/src/ragdemo/parse/local/recall_diag.py
"""数字召回的缺失归因（纯函数）：参考（TextIn）里有、候选（L0）里没有的数字，各自为什么没有。

- decor_stripped：在被剥离的装饰文字（页眉页脚 / 页码 / 旋转字）里；
- unexplained：文字层里还有富余（没被输出用掉）的同一个数字，输出却少了——构造上不可能，出现即 bug；
- not_in_text_layer：数字串在文字层里根本不存在（TextIn 从图片里 OCR 的）；
- tokenization：数字串在文字层里，但分词不同（跨词、与相邻字符连写等），逐个列入 examples 供人工复核。"""

from __future__ import annotations

import re
from collections import Counter
from dataclasses import dataclass

from ragdemo.parse.local.number_closure import fold_text, numbers_in

_NON_DIGIT = re.compile(r"\D")


def _digits(text: str) -> str:
    return _NON_DIGIT.sub("", fold_text(text))


@dataclass(frozen=True)
class MissingNumbers:
    reference_total: int = 0
    hit: int = 0
    decor_stripped: int = 0
    tokenization: int = 0
    not_in_text_layer: int = 0
    unexplained: int = 0
    examples: tuple[str, ...] = ()  # tokenization 与 unexplained 的数字

    @property
    def recall(self) -> float:
        return self.hit / self.reference_total if self.reference_total else 1.0

    def plus(self, other: MissingNumbers) -> MissingNumbers:
        return MissingNumbers(
            self.reference_total + other.reference_total,
            self.hit + other.hit,
            self.decor_stripped + other.decor_stripped,
            self.tokenization + other.tokenization,
            self.not_in_text_layer + other.not_in_text_layer,
            self.unexplained + other.unexplained,
            self.examples + other.examples,
        )


def classify_missing_numbers(
    reference: str, candidate: str, *, layer_text: str, stripped_text: str
) -> MissingNumbers:
    ref, cand = numbers_in(reference), numbers_in(candidate)
    stripped = numbers_in(stripped_text)
    spare = numbers_in(layer_text) - cand  # 文字层里没被输出用掉的数字
    layer_digits = _digits(layer_text + "\n" + stripped_text)
    counts: Counter[str] = Counter()
    examples: list[str] = []
    for n, c in sorted((ref - cand).items()):
        for _ in range(c):
            if stripped[n] > 0:
                stripped[n] -= 1
                counts["decor"] += 1
            elif spare[n] > 0:
                spare[n] -= 1
                counts["unexplained"] += 1
                examples.append(n)
            elif _digits(n) not in layer_digits:
                counts["absent"] += 1
            else:
                counts["token"] += 1
                examples.append(n)
    hit = sum(min(c, cand.get(n, 0)) for n, c in ref.items())
    return MissingNumbers(
        sum(ref.values()), hit, counts["decor"], counts["token"], counts["absent"], counts["unexplained"],
        tuple(sorted(set(examples))),
    )
```

"""确定性 L0（第二版）：只接受单栏、无表格、无图表碎片、非财务报表的有文字层页。

文档级入口：正文字号、行距、标题字号层级、编号连续性都按整份文档统计（所以它不是 PageEngine——
那是"单页 PDF → markdown"的协议）。每页给出页型；只有 plain_text 进入排版与自检，其余页带着页型
原因交给上层（分级路由的 L1 / L3）。自检就是 pipeline._self_check（双向数字闭合 + 双向字符闭合），
任何不通过都说明排版器有 bug，记 closure_failed 并降级。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from typing import Final, Literal

from ragdemo.parse.local.chart import has_chart_fragments
from ragdemo.parse.local.columns import detect_columns
from ragdemo.parse.local.decor import strip_decor
from ragdemo.parse.local.layout import PageLayout, Word, extract_pages
from ragdemo.parse.local.number_closure import numbers_in
from ragdemo.parse.local.pipeline import PageResult, needs_handback, self_check
from ragdemo.parse.local.tables import cluster_rows, find_table_regions, split_segments
from ragdemo.parse.local.typeset import body_font_size, typeset_document
from ragdemo.parse.tiered.classify import is_financial_statement_page

PageKind = Literal["plain_text", "table", "multicolumn", "chart_fragments", "financial_statement", "no_text_layer"]
L0_VERSION: Final = "det-v2"
TABLELIKE_GAP_EM = 2.0
TABLELIKE_MIN_ROWS = 2
REASON_ROTATED: Final = "多栏版面：旋转文字残留"


@dataclass(frozen=True)
class PageClass:
    kind: PageKind
    reason: str = ""


@dataclass(frozen=True)
class L0Page:
    page: int
    kind: PageKind
    result: PageResult

    @property
    def accepted(self) -> bool:
        return self.kind == "plain_text" and self.result.status == "ok"


def tablelike_run(rows: Sequence[Sequence[Word]], body_size: float) -> int:
    """最长的连续"疑似表格行"行数：行内按 >= TABLELIKE_GAP_EM 字宽的空隙切成 >= 2 段，且含 >= 2 个数字。"""
    gap = TABLELIKE_GAP_EM * (body_size or 10.0)
    best = cur = 0
    for r in rows:
        if len(split_segments(r, gap)) >= 2 and sum(numbers_in(" ".join(w.text for w in r)).values()) >= 2:
            cur += 1
            best = max(best, cur)
        else:
            cur = 0
    return best


def classify_page(layout: PageLayout, *, original_text: str, body_size: float) -> PageClass:
    """layout：剥离装饰后的版面；original_text：剥离前的文字层（查 cid 乱码用）。先中先得。"""
    handback = needs_handback(layout.text)
    if handback is None and "(cid:" in original_text:
        handback = "文字层乱码（cid）"
    if handback is not None:
        return PageClass("no_text_layer", handback)
    if is_financial_statement_page(layout.text):
        return PageClass("financial_statement", "财务报表页")
    if any(not w.upright for w in layout.words):
        return PageClass("multicolumn", REASON_ROTATED)
    rows = cluster_rows([w for w in layout.words if w.upright])
    regions = find_table_regions(rows)
    in_table = {id(w) for reg in regions for r in reg for w in r}
    plain = [r for r in rows if id(r[0]) not in in_table]
    cols = detect_columns(plain, layout.width, body_size)
    if cols.multicolumn:
        return PageClass("multicolumn", cols.reason)
    if regions:
        return PageClass("table", f"坐标表格 {len(regions)} 处")
    if has_chart_fragments(plain):
        return PageClass("chart_fragments", "图表碎片")
    if tablelike_run(plain, body_size) >= TABLELIKE_MIN_ROWS:
        return PageClass("table", "疑似表格行")
    return PageClass("plain_text")


def parse_layouts_l0(pages: Sequence[PageLayout]) -> list[L0Page]:
    stripped = strip_decor(pages)
    live = [i for i, (p, s) in enumerate(zip(pages, stripped, strict=True))
            if needs_handback(s.layout.text) is None and "(cid:" not in p.text]
    body = body_font_size([stripped[i].layout for i in live])
    classes = [classify_page(s.layout, original_text=p.text, body_size=body)
               for p, s in zip(pages, stripped, strict=True)]
    typeset = dict(zip(live, typeset_document([stripped[i].layout for i in live]), strict=True))
    out: list[L0Page] = []
    for i, (s, c) in enumerate(zip(stripped, classes, strict=True)):
        lay, kept = s.layout, s.stripped_text
        kind = c.kind
        if kind == "no_text_layer":
            res = PageResult(lay.page, "no_text_layer", "", lay.text, [], c.reason, kept)
        elif kind != "plain_text":
            res = PageResult(lay.page, "layout_unsupported", "", lay.text, [], f"{kind}：{c.reason}", kept)
        else:
            t = typeset[i]
            if t.status != "ok":  # 与 classify_page 用同一个检测器，正常不会走到；防御
                kind = "multicolumn"
                res = PageResult(lay.page, "layout_unsupported", "", lay.text, [], f"multicolumn：{t.reason}", kept)
            else:
                violations, reason = self_check(t.markdown, lay.text, t.tables)
                res = (PageResult(lay.page, "closure_failed", "", lay.text, violations, reason, kept) if reason
                       else PageResult(lay.page, "ok", t.markdown, lay.text, [], "", kept))
        out.append(L0Page(lay.page, kind, res))
    return out


def parse_pdf_l0(pdf_bytes: bytes) -> list[L0Page]:
    return parse_layouts_l0(extract_pages(pdf_bytes))

def textin_page_markdowns(payload: Mapping[str, Any]) -> dict[int, str]:
    """TextIn 缓存 → 逐页 markdown（标题 `#` × (outline_level + 1)；表格为 pipe 表；不含 content == 1 的页眉页脚）。"""
    detail = (payload.get("result") or {}).get("detail") or []
    pages: dict[int, list[str]] = {}
    for b in blocks_from_detail(detail, page_dims={}):
        if b.page is None:
            continue
        text = "#" * ((b.level or 0) + 1) + " " + b.content if b.block_type == "title" else b.content
        pages.setdefault(b.page, []).append(text)
    return {p: "\n\n".join(parts) for p, parts in pages.items()}


def content_audit(markdown: str, words: Sequence[str]) -> bool:
    """独立审计：输出的内容字符多重集合 == 文字层词的内容字符多重集合。"""
    return Counter(ch for ch in markdown if ch.isalnum()) == Counter(ch for w in words for ch in w if ch.isalnum())

@dataclass(frozen=True)
class MulticolRates:
    n_multi: int
    missed: int  # 标注 multi 却被 L0 接受
    n_single: int
    false_positive: int  # 标注 single 却被判 multicolumn

    @property
    def miss_rate(self) -> float:
        return self.missed / self.n_multi if self.n_multi else 1.0

    @property
    def fp_rate(self) -> float:
        return self.false_positive / self.n_single if self.n_single else 0.0


def multicolumn_rates(
    labels: Mapping[PageKey, Label], kinds: Mapping[PageKey, str], accepted: Mapping[PageKey, bool]
) -> MulticolRates:
    n_multi = missed = n_single = fp = 0
    for key, label in labels.items():
        if key not in kinds:
            raise ValueError(f"标注页 {key} 没有运行结果：先跑 run，再算门槛")
        if label == "multi":
            n_multi += 1
            missed += int(accepted[key])
        elif label == "single":
            n_single += 1
            fp += int(kinds[key] == "multicolumn")
    return MulticolRates(n_multi, missed, n_single, fp)


@dataclass(frozen=True)
class HeadingTotals:
    matched: int = 0
    cand_total: int = 0
    ref_total: int = 0
    rel_agree: int = 0
    rel_total: int = 0

    def add(self, m: HeadingMatchV2) -> HeadingTotals:
        return HeadingTotals(self.matched + m.matched, self.cand_total + m.cand_total, self.ref_total + m.ref_total,
                             self.rel_agree + m.rel_agree, self.rel_total + m.rel_total)

    @property
    def recall(self) -> float:
        return self.matched / self.ref_total if self.ref_total else 1.0

    @property
    def precision(self) -> float:
        return self.matched / self.cand_total if self.cand_total else 1.0

    @property
    def relative_level_agreement(self) -> float:
        return self.rel_agree / self.rel_total if self.rel_total else 1.0


def cost_kind(p: L0Page) -> CostKind:
    if p.accepted:
        return "l0_accepted"
    if p.kind == "plain_text":
        return "closure_failed"
    return p.kind


@dataclass(frozen=True)
class Prices:
    c_textin: float
    c_local: float = 0.0  # 自托管 L1 引擎每页摊销（未给定按 0，见分级路由计划开放问题 3）
    l1_enabled: bool = False
    l1_pass: float = 0.0  # L1 通过率：只能取分级路由计划 T7 的实测值

    def downstream(self) -> float:
        """非 L0、非报表、非扫描页的每页期望成本（L1 失败再 L3，两笔都付）。"""
        return self.c_local + (1 - self.l1_pass) * self.c_textin if self.l1_enabled else self.c_textin


def cost_breakdown(counts: Mapping[CostKind, int], p: Prices) -> dict[CostKind, float]:
    """每类页对"每页均摊成本"的贡献。L0 在开发机 CPU 上 0.1–0.2 s / 页，计 0 元；报表页与无文字层页按 L3 计。"""
    total = sum(counts.get(k, 0) for k in COST_KINDS)
    if total == 0:
        raise ValueError("没有页，无法计算每页成本")
    unit: dict[CostKind, float] = {"l0_accepted": 0.0, "financial_statement": p.c_textin, "no_text_layer": p.c_textin}
    return {k: counts.get(k, 0) * unit.get(k, p.downstream()) / total for k in COST_KINDS}


def blended_cost_per_page(counts: Mapping[CostKind, int], p: Prices) -> float:
    return sum(cost_breakdown(counts, p).values())


def routing_cost_inputs(counts: Mapping[CostKind, int]) -> tuple[float, float, float]:
    """换算成分级路由计划 T7 CostInputs 的 (scan_share, statement_share, l0_pass)。"""
    total = sum(counts.get(k, 0) for k in COST_KINDS)
    scan, stmt = counts.get("no_text_layer", 0), counts.get("financial_statement", 0)
    text = total - scan
    non_stmt = text - stmt
    return (scan / total if total else 0.0, stmt / text if text else 0.0,
            counts.get("l0_accepted", 0) / non_stmt if non_stmt else 0.0)

@dataclass(frozen=True)
class Gate:
    gid: str
    name: str
    value: float | None
    threshold: float
    op: str
    passed: bool


@dataclass(frozen=True)
class L0Metrics:
    closure_failed: int
    audit_inconsistent: int
    num_recall: float
    unexplained_missing: int
    multicol: MulticolRates | None
    heading: HeadingTotals
    research_heading_available: int
    research_heading_judged: int
    research_heading_precision: float | None

    spot_available: int
    spot_pages: int
    spot_order_failures: int | None
    coverage_announcement: float
    coverage_research: float
    multicol_share_announcement: float
    seconds_p95: float


def _ge(gid: str, name: str, v: float | None) -> Gate:
    t = GATES[gid]
    return Gate(gid, name, v, t, ">=", v is not None and v >= t)


def _le(gid: str, name: str, v: float | None) -> Gate:
    t = GATES[gid]
    return Gate(gid, name, v, t, "<=", v is not None and v <= t)


def evaluate_gates(m: L0Metrics, *, final: bool) -> list[Gate]:
    mc = m.multicol
    enough_multi = mc is not None and mc.n_multi >= GATES["G4_min_multi"]
    gates = [
        _le("G1", "纯文字页 closure_failed 页数", float(m.closure_failed)),
        _le("G2", "独立审计不一致页数", float(m.audit_inconsistent)),
        _ge("G3", "L0 页数字召回（公告，micro）", m.num_recall),
        _le("G3b", "无法解释的缺失数字个数", float(m.unexplained_missing)),
        _le("G4", "多栏漏检率", mc.miss_rate if (mc is not None and enough_multi) else None),
        _le("G5", "多栏误检率", mc.fp_rate if mc is not None else None),
        _ge("G6a", "标题召回（公告）", m.heading.recall),
        _ge("G6b", "标题精确率（公告）", m.heading.precision),
        _ge("G6c", "标题相对层级一致率（公告）", m.heading.relative_level_agreement),
    ]
    if not final:
        gates.append(Gate("G7", "研报标题人工精确率（调参集不评）", None, GATES["G7"], ">=", True))
    elif m.research_heading_available < GATES["G7_min_available"]:
        gates.append(Gate("G7", "研报标题人工精确率（标题不足 30 个，不适用）", None, GATES["G7"], ">=", True))
    elif m.research_heading_judged < min(GATES["G7_min_judged"], m.research_heading_available):
        gates.append(Gate("G7", "研报标题人工精确率（判定数不足）", None, GATES["G7"], ">=", False))
    else:
        gates.append(_ge("G7", "研报标题人工精确率", m.research_heading_precision))
    gates.append(_le("G8", "表格泄漏页占比（公告）", m.leakage_rate))
    if not final:
        gates.append(Gate("G9", "阅读顺序人工抽查（调参集不评）", None, GATES["G9"], "<=", True))
    elif m.spot_order_failures is None or m.spot_pages < min(GATES["G9_min_pages"], m.spot_available):
        gates.append(Gate("G9", "阅读顺序人工抽查（抽查页数不足）", None, GATES["G9"], "<=", False))
    else:
        gates.append(_le("G9", "阅读顺序错误页数", float(m.spot_order_failures)))
    gates += [
        _ge("G10a", "L0 覆盖率（公告）", m.coverage_announcement),
        _ge("G10b", "L0 覆盖率（研报）", m.coverage_research),
        _le("G11", "多栏页占比（公告）", m.multicol_share_announcement),
        _le("G12", "每页耗时 p95（秒）", m.seconds_p95),
    ]
    return gates


def is_go(gates: Sequence[Gate]) -> bool:
    return all(g.passed for g in gates)


def claim_holdout(lock: Path, *, git_sha: str, today: date) -> None:
    if lock.exists():
        raise SystemExit(f"留出集已经跑过（{lock.read_text(encoding='utf-8').strip()}）：本计划规定留出集只跑一次")
    lock.parent.mkdir(parents=True, exist_ok=True)
    lock.write_text(f"{today.isoformat()} {git_sha}\n", encoding="utf-8")


def _rows(path: Path) -> list[dict[str, str]]:
    lines = path.read_text(encoding="utf-8").splitlines()
    head = lines[0].split("\t")
    return [dict(zip(head, (ln.split("\t") + [""] * len(head))[: len(head)], strict=True)) for ln in lines[1:] if ln.strip()]


def read_multicol_labels(path: Path, sample_set: str) -> dict[PageKey, Label]:
    out: dict[PageKey, Label] = {}
    for i, r in enumerate(_rows(path), start=2):
        if r["set"] != sample_set:
            continue
        if r["label"] not in ("single", "multi", "unsure"):
            raise ValueError(f"{path} 第 {i} 行未标注或标签非法：{r['label']!r}")
        if r["label"] != "unsure":
            out[(r["group"], r["key"], int(r["page"]))] = cast(Label, r["label"])
    return out


def read_judgments(path: Path) -> tuple[int, int]:
    """返回 (yes, no)；unsure 与空白不计。"""
    rows = _rows(path)
    return sum(r["judgment"] == "yes" for r in rows), sum(r["judgment"] == "no" for r in rows)


def read_spotcheck(path: Path) -> tuple[int, int]:
    """返回 (已判定页数, order_ok = no 的页数)。"""
    rows = [r for r in _rows(path) if r["order_ok"] in ("yes", "no")]
    return len(rows), sum(r["order_ok"] == "no" for r in rows)


def sample_items(items: Sequence[T], n: int, seed: int) -> list[T]:
    if n >= len(items):
        return list(items)
    return random.Random(seed).sample(list(items), n)

## 已知局限

1. **只覆盖纯文字页。** 表格页、多栏页、图表页、报表页全部降级；研报的 L0 覆盖率可能偏低（研报几乎每页都有图表），节省主要来自公告。具体数字以 T6 实测为准。
2. **阅读顺序只靠检测器 + 人工抽查兜底。** 闭合校验对阅读顺序无能为力；整页空白带检测漏掉的版式（例如侧栏与正文之间没有足够宽的空白、侧栏行数 < 3）会静默产出顺序错的 ok 页。
3. **编号标题召回有上界（约 0.80）。** TextIn 把部分整句话标成标题，规则无法复现；层级由固定的编号先后顺序决定，个别文档的非常规编号（"1." 在 "（一）" 之上）会定错级。
4. **编号连续性校验对跨页丢失敏感。** 中间某页被判为多栏 / 表格页（不排版）时，那页上的编号看不见，之后同体系的编号会因不连续而不被标为标题（宁漏勿误）。
5. **"疑似表格行"与图表碎片是启发式。** 漏判的小表会流进段落（G8 监控），漏判的图表碎片仍会被自检拦下（降级，方向安全）。
6. **短公告（< 4 页）的抬头行保留**（`strip_decor` 的保守设定），对 TextIn 的数字精确率偏低属口径差异；不影响溯源。
7. **文字层缺陷原样透传**：错误的 ToUnicode 映射（非 `(cid:` 形态）识别不出。
8. **TextIn 不是标准答案。** 标题与数字召回只表示"与 TextIn 一致"，分歧靠人工判定。
9. **留出集小**：公告留出约 8 份（其中 announcement 7 份），标题与数字召回的置信区间宽；报告里如实给出分子分母。
10. **脱敏夹具只保真几何**：文字被替换，凡依赖文字内容的规则（编号、关键词、报表识别）不能用夹具测，只能用合成用例与本机真实文件测试。
