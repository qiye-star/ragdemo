# 表格处理改进（单元格级存储与溯源 · 存量回填 · 检索修复 · 新管线衔接 · 事实引用校验）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行本计划。步骤用复选框（`- [ ]`）跟踪；每个任务结束必须有独立可测的产物并单独提交。标注 **【用户步骤】** 的事项必须由用户本人完成或明确批准，执行者不得代做、不得跳过。

**Goal:** 把"表格"从"一整块 Markdown 文本"升级为**带坐标、带页码、带校验结论的单元格网格**，使表格里的每个数字都能引用到 `[block_id | page | r{row}c{col}]` 并被代码核对；在**不重调 TextIn**的前提下把现有 104 张表回填进新存储；按审计报告的弱点排序逐条修复表格检索（每条单独评测、单独提交）；让分级路由新管线（L1 PaddleOCR / L2 双引擎 / L3 TextIn）产出的表格写进同一存储；为 Wind 来源的财务事实建立"表格单元格 → 事实"的**校验与引用**（期别列由代码识别，单位换算由 Python 计算，不由模型产生任何数值）。图表不在本计划内（图表只存图片与元数据，见 L0 v2 计划 T10）。

**Architecture:** 新增顶层业务包 `packages/ragdemo/src/ragdemo/tables/`（与 L0 v2 的 `parse/local/`、分级路由的 `parse/tiered/` 都不重叠）。`tables.grid.TableGrid` 是引擎无关的唯一表格形态：TextIn 的 `cells[]`（`tables.textin_cells`）与 L1 引擎的 HTML（`tables.html_grid`）都先转成它，Markdown / HTML 只是由它派生的视图（派生函数仍是 `parse/textin.py` 里现有的 `table_markdown` / `table_html_from_cells`，保证与库里已存内容逐字相等）。网格随 `NormalizedBlock` → `Chunk` 流到 `DocumentWriter`，写进新时点表 `core.doc_table`（迁移 030，登记 `core.bitemporal_registry`，有 `asof.doc_table` 视图与 RLS，时点列从所属 `doc_block` 复制）。逐单元格校验（`tables.verify_cells`）用 PDF 文字层在单元格 bbox 内的数字多重集核对单元格数字。引用解析（`tables.citation`）只读 `asof.doc_table`。事实校验（`tables.fact_check`）把 `core.fin_fact` 与表格单元格按"行表头=科目、列表头=期别"对上，结果写进新时点表 `core.fact_table_ref`（迁移 031），不改 `fin_fact` 任何一行。检索侧修复只动 `retrieval/lexical.py`（BM25 字段）、`embed/batch.py`（表格嵌入输入）、`retrieval/expand.py`（证据带单位），每条都有开关、先评测后翻默认值。

**Tech Stack:** Python 3.11、pdfplumber（已用，经 `parse/local/layout.py::extract_pages` 取文字层词坐标）、标准库 `html.parser`、`decimal`、ParadeDB（pg_search 0.25.9，已验证 `content ||| q OR content_desc ||| q` 会下推为单个 tantivy boolean should 查询）、psycopg 3、click、pytest、ruff、mypy --strict。不引入新第三方依赖。

## Global Constraints

- **每个数字必须可溯源（CLAUDE.md §0、§1.3）。** 单元格引用格式固定为 `[block_id | page | r{row}c{col}]`：`row`/`col` 为 **0 基**网格坐标（与 TextIn `cells[].row/col`、`core.doc_table.grid` 一致，不做 +1 换算，避免存储与引用之间出现差一）；`page` 是**该单元格自己的页码**（跨页表的尾部行指向它真正所在的页，不是表的首页）。前缀与现有 `BlockCitation.render()` 的 `[block_id | page]` 完全一致，旧格式继续有效。
- **计算与生成分离（§1.2）。** 期别列识别、单位换算、容差、校验结论全部由 Python 代码给出；本计划不新增任何让模型产出数值的 prompt。表格描述继续沿用 `parse/describe.py::validate_description` 的禁用解读规则；本计划**不改描述 prompt、不重新生成任何描述**。
- **时点（§1.1）。** `core.doc_table`、`core.fact_table_ref` 的 `known_at` 一律继承来源行（表 ← 所属 `doc_block`；事实引用 ← `GREATEST(fin_fact.known_at, doc_table.known_at)`），绝不取写入时刻；`ingested_at` 只做运维排查。读取只走 `asof.doc_table` / `asof.fact_table_ref`（回填与批量校验这两个离线批处理与现有 `stage2_crosscheck.py` 一样读 `core`，只读、不对外）。
- **研报不展示原文（ADR-0014）。** 研报表格的网格照常存储（校验需要），但 `tables.citation.resolve_cell` 在 `can_show_raw = false` 时 `display_text = None`；本计划不新增任何对外 API 端点，不把 `grid` 加进 `api/queries/` 的任何查询。
- **私有隔离（§0）。** `core.doc_table` 与 `core.doc_block` 同样 ENABLE + FORCE RLS，策略与 `block_visibility` 逐字相同；`core.fact_table_ref` 只引用公共表（`owner_user IS NULL AND owner_tenant IS NULL`），不需要 RLS。
- **不调用任何付费接口，除非标为【用户步骤】并得到用户批准。** 存量回填（T10）只读缓存 JSON 与本地 PDF；真实嵌入 / 重排评测（C2 配置）、补嵌入（T11）、表格重嵌（T13）是付费的，各自单列。
- **评测驱动（§1.4）——基线先于任何改动测量并提交（T2）。** 每个检索 / 切块 / 嵌入输入改动单独一个任务、单独一次评测、单独一次提交，PR 描述贴 `eval table-gate` 输出。门槛见"评测口径（写死）"一节，不得事后调整。`eval_extraction` 与观点评分目前没有运行器（迁移 005 只有表），PR 中如实写"N/A：无运行器"。
- **不切表格（docs/05 §3.3 不变）。** 本计划不做"按行组切子块"，理由与重开条件见 T13 的裁决 R4。表格块的 `content`、`content_desc`、`block_id`、`ordinal`、`chunking_version` 一律不变，**评测集 `gold_block_ids` 不受任何任务影响**（每个任务的"是否影响 gold_block_ids"一栏都写"否"，并有测试或查询为证）。
- **旧块永不修改。** 回填只新增 `core.doc_table` 行；`core.doc_block` 只有既有的 `embedding / embedding_version` 两列会在 T11/T13 被嵌入流程按既有机制重写（与 `embed/batch.py` 现行做法相同）。`fin_fact` 一行不改：`fin_fact.source_block` 的语义是"抽取自文档"，Wind 事实不是从表格抽出来的，表格只做佐证，佐证写进 `core.fact_table_ref`。
- **迁移只走 `db/migrations/`。** 当前最新文件是 `027_research_source_registry.sql`（本机库 `public.schema_migrations` 只执行到 `025_replay_baseline_v2`，026/027 尚未执行）；`028_parse_page_route.sql` 已被分级路由计划预留、`029_doc_block_figure_meta.sql` 已被 L0 v2 计划预留。本计划新增 **`030_doc_table_grid.sql`** 与 **`031_fact_table_ref.sql`**。编号规则：执行时若 030/031 已被占用，取"当时最新 + 1"并保持 doc_table 在 fact_table_ref 之前。独立性：030 只依赖 004/006/009/010 的对象，031 只依赖 003 与 030；`ragdemo_core/db/migrate.py` 按文件名字典序执行、允许空号，所以 030/031 可以先于 028/029 落地，028/029 之后再落地也互不影响（030 不改 `core.doc_block`，也不重建 `asof.doc_block`，与 029 的 `CREATE OR REPLACE VIEW asof.doc_block` 没有交集）。
- **TDD（§3）。** 数值计算（单位换算、容差、期别识别、覆盖率、门槛判定）与时点逻辑（known_at 继承、supersede、as_of 可见性）全部先写失败测试。
- **`ruff` + `mypy --strict` 必须通过；** Python 3.11+；`ragdemo-core` 只改 `db/invariants.py`（不 import 业务层）。
- **文件边界（避免与并行计划冲突）：** 本计划**不修改** `parse/local/**`、`parse/tiered/**`、`parse/acceptance.py`（T16 例外，且只在 W1 合入后执行）。只从 `parse/local/number_closure.py`、`parse/local/layout.py`、`parse/tiered/types.py` **导入**。`evals/runner.py` 与分级路由 T13 有交集：本计划只在其中加一个 `per_group` 字段与一次调用，分组逻辑放在新文件 `evals/grouping.py`，后落地的一方 rebase 时只需合并这几行。

## 评测口径（写死，任何任务不得调整）

**分组。** 每条用例按 gold 块类型 × 出题方式分组：gold 中任一块 `block_type = 'table'` → `table`，否则 `other`；`author` 以 `auto:` 开头 → `auto`，否则 `human`。现有 100 条合成用例 = `table/auto` 29 条 + `other/auto` 71 条（本机库实测：70 条段落 + 1 条图，gold 全部在现行块上）。人工表格题 author 记为 `human:tbl-<标注员>`，进入 `table/human`。**n < 10 的分组只报告、不判门槛。**

**配置。** C1 = BM25 主导、免费：`--models mock --no-rerank --w-vec 0`（mock 向量一路权重为 0，只在 BM25 候选不足 10 条时以 0 分按 block_id 补位，前后两次运行行为一致，可比）。C2 = 生产形态、付费：`--models siliconflow --rerank --vector-backend pg`。每次运行同时跑 `--author-prefix auto:`，人工集到位后加跑 `--author-prefix human:tbl-`。

**单步门槛（每个检索改动相对"上一步已接受状态"，C2 必过，C1 报告；R1 额外要求 C1 也过）：**

| 分组 | n | R@10 最大允许下降 | MRR@10 最大允许下降 |
|---|---|---|---|
| `table/auto` | 29 | 1 题（1/29 = 0.0345） | 0.03 |
| `other/auto` | 71 | 2 题（2/71 = 0.0282） | 0.02 |
| `table/human` | 50 | 2 题（2/50 = 0.04） | 0.03 |
| 总体 R@10 | 100 | 0.02（沿用 `evals/cli.py::TOLERANCE`） | — |

前后两次运行同一分组的 n 必须相等，否则判"不可比"并阻断（评测集或语料被动过）。

**终局目标（T19，相对 T2 的基线 B0）：** `table/human` 在 C2 下 R@10 ≥ B0 + 0.10（≥ 5 题），在 C1 下 R@10 ≥ B0 + 0.15；`table/auto` 与 `other/auto` 在 C2 下不低于 B0 减去上表单步容差。人工集未到位时，T19 报告必须写"表格检索改进未经人工集验证"，不得用 `table/auto` 的上涨宣称改进。

**"描述派生题"偏差的处理。** `table/auto` 的 29 题是 `evals/generate.py` 把 `content_desc + 正文` 一起喂给模型写出来的（审计 §6：查 `content_desc` 时 BM25 R@10 = 0.83，存在泄漏），因此：①`table/auto` 只作**回归护栏**，不作改进证据；②改进证据只认 `table/human`；③人工题导出表（T3）**不提供** `content_desc`，标注员只看表格正文与页码出题。

**回放协议（人工集晚于改动到位时）。** BM25 字段由 `RetrievalConfig.bm25_desc` 开关回放；表格嵌入输入由 `docs reembed-tables` + `docs embed --table-input/--no-table-input` 回放——旧输入与新输入的向量都在 `core.embedding_cache`，回放时全部缓存命中、不计费（只有查询嵌入计费）。

```python
"""按 gold 块类型 × 出题方式分组的检索指标（表格处理改进计划 T1）。

合成题（auto:）里表格题是看着"描述 + 正文"写出来的，对查描述的改动天然偏高，
所以 table/auto 只作回归护栏，改进证据只认 table/human（计划"评测口径"）。
"""

from __future__ import annotations

from collections.abc import Collection, Sequence
from dataclasses import dataclass
from typing import Final

MIN_GROUP_SIZE: Final = 10


def case_group(gold_types: Collection[str], *, author: str) -> str:
    kind = "table" if "table" in gold_types else "other"
    origin = "auto" if author.startswith("auto:") else "human"
    return f"{kind}/{origin}"


@dataclass(frozen=True)
class CaseOutcome:
    group: str
    hit10: float
    hit50: float
    rr10: float


@dataclass(frozen=True)
class GroupMetrics:
    n: int
    recall_at_10: float
    recall_at_50: float
    mrr_at_10: float
    gated: bool

    def as_dict(self) -> dict[str, float | int | bool]:
        return {
            "n": self.n,
            "recall_at_10": self.recall_at_10,
            "recall_at_50": self.recall_at_50,
            "mrr_at_10": self.mrr_at_10,
            "gated": self.gated,
        }


def summarize_groups(rows: Sequence[CaseOutcome]) -> dict[str, GroupMetrics]:
    buckets: dict[str, list[CaseOutcome]] = {}
    for row in rows:
        buckets.setdefault(row.group, []).append(row)
    return {
        group: GroupMetrics(
            n=len(items),
            recall_at_10=sum(i.hit10 for i in items) / len(items),
            recall_at_50=sum(i.hit50 for i in items) / len(items),
            mrr_at_10=sum(i.rr10 for i in items) / len(items),
            gated=len(items) >= MIN_GROUP_SIZE,
        )
        for group, items in sorted(buckets.items())
    }
```

```python
"""表格专项评测门槛（阈值写死在计划"评测口径"一节，改动须新开计划修订）。"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from types import MappingProxyType
from typing import Any, Final

from ragdemo.evals.grouping import MIN_GROUP_SIZE

_EPS: Final = 1e-9
OVERALL_MAX_RECALL10_DROP: Final = 0.02


@dataclass(frozen=True)
class GroupGate:
    max_recall10_drop_cases: int
    max_mrr10_drop: float


GATES: Final[Mapping[str, GroupGate]] = MappingProxyType(
    {
        "table/auto": GroupGate(max_recall10_drop_cases=1, max_mrr10_drop=0.03),
        "other/auto": GroupGate(max_recall10_drop_cases=2, max_mrr10_drop=0.02),
        "table/human": GroupGate(max_recall10_drop_cases=2, max_mrr10_drop=0.03),
        "other/human": GroupGate(max_recall10_drop_cases=2, max_mrr10_drop=0.02),
    }
)


class GateIncomparable(ValueError):
    """前后两次运行的同一分组题数不同：评测集或语料变了，指标不可比。"""


@dataclass(frozen=True)
class GateResult:
    passed: bool
    reasons: tuple[str, ...]
    report: tuple[str, ...]


def judge(
    before: Mapping[str, Mapping[str, Any]],
    after: Mapping[str, Mapping[str, Any]],
    *,
    overall_before: float,
    overall_after: float,
) -> GateResult:
    reasons: list[str] = []
    report: list[str] = []
    for group in sorted(set(before) | set(after)):
        if group not in before or group not in after:
            raise GateIncomparable(f"{group} 只出现在一次运行里")
        b, a = before[group], after[group]
        n = int(b["n"])
        if int(a["n"]) != n:
            raise GateIncomparable(f"{group} 题数 {n} → {int(a['n'])}")
        d10 = float(b["recall_at_10"]) - float(a["recall_at_10"])
        dmrr = float(b["mrr_at_10"]) - float(a["mrr_at_10"])
        line = (
            f"{group} n={n} recall@10 {float(b['recall_at_10']):.4f}→{float(a['recall_at_10']):.4f}"
            f" MRR@10 {float(b['mrr_at_10']):.4f}→{float(a['mrr_at_10']):.4f}"
        )
        if n < MIN_GROUP_SIZE or group not in GATES:
            report.append(f"{line}（n<{MIN_GROUP_SIZE} 或无门槛，不判门槛）")
            continue
        gate = GATES[group]
        report.append(line)
        if d10 > gate.max_recall10_drop_cases / n + _EPS:
            reasons.append(
                f"{group} recall@10 下降 {d10:.4f} > {gate.max_recall10_drop_cases} 题"
                f"（{gate.max_recall10_drop_cases / n:.4f}）"
            )
        if dmrr > gate.max_mrr10_drop + _EPS:
            reasons.append(f"{group} MRR@10 下降 {dmrr:.4f} > {gate.max_mrr10_drop}")
    if overall_before - overall_after > OVERALL_MAX_RECALL10_DROP + _EPS:
        reasons.append(
            f"总体 recall@10 下降 {overall_before - overall_after:.4f} > {OVERALL_MAX_RECALL10_DROP}"
        )
    return GateResult(not reasons, tuple(reasons), tuple(report))
```

@eval_group.command("table-gate")
@click.option("--before", "before_id", required=True, help="上一步已接受状态的 eval_run.run_id")
@click.option("--after", "after_id", required=True, help="本次改动的 eval_run.run_id")
def table_gate(before_id: str, after_id: str) -> None:
    """按计划写死的表格专项门槛比较两次运行（输出整段贴进 PR）。"""
    with psycopg.connect(_dsn()) as conn:
        rows = {
            str(r[0]): r[1]
            for r in conn.execute(
                "SELECT run_id, metrics FROM evals.eval_run WHERE run_id = ANY(%s)",
                ([before_id, after_id],),
            ).fetchall()
        }
    missing = {before_id, after_id} - set(rows)
    if missing:
        raise click.ClickException(f"找不到运行：{sorted(missing)}")
    b, a = rows[before_id], rows[after_id]
    try:
        res = judge(
            b.get("per_group", {}),
            a.get("per_group", {}),
            overall_before=float(b["recall_at_10"]),
            overall_after=float(a["recall_at_10"]),
        )
    except GateIncomparable as exc:
        raise click.ClickException(f"不可比：{exc}") from exc
    for line in res.report:
        click.echo(line)
    for line in res.reasons:
        click.echo(f"未过：{line}", err=True)
    click.echo("表格门槛：通过" if res.passed else "表格门槛：未过，阻断合并")
    if not res.passed:

```python
"""引擎无关的表格网格（表格处理改进计划 T4）。Markdown/HTML 都由它派生。"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass, replace
from typing import Any, Final, Literal, cast

GRID_VERSION: Final = "tablegrid:v1"
BBox = tuple[float, float, float, float]
CellCheck = Literal["not_checked", "match", "mismatch", "no_numbers", "no_text_layer"]


class GridError(ValueError):
    """网格结构不合法。"""


@dataclass(frozen=True)
class GridCell:
    row: int
    col: int
    row_span: int
    col_span: int
    text: str
    page: int | None = None
    bbox: BBox | None = None
    is_header: bool = False
    check: CellCheck = "not_checked"

    def __post_init__(self) -> None:
        if self.row < 0 or self.col < 0:
            raise GridError(f"行列必须 ≥ 0：({self.row}, {self.col})")
        if self.row_span < 1 or self.col_span < 1:
            raise GridError(f"跨度必须 ≥ 1：({self.row_span}, {self.col_span})")

    def slots(self) -> list[tuple[int, int]]:
        return [
            (r, c)
            for r in range(self.row, self.row + self.row_span)
            for c in range(self.col, self.col + self.col_span)
        ]


@dataclass(frozen=True)
class TableGrid:
    cells: tuple[GridCell, ...]
    source_engine: str
    provider_ref: str | None = None
    header_rows: int = 0
    header_cols: int = 0

    def __post_init__(self) -> None:
        if not self.cells:
            raise GridError("网格没有任何单元格")

    @property
    def n_rows(self) -> int:
        return max(c.row + c.row_span for c in self.cells)

    @property
    def n_cols(self) -> int:
        return max(c.col + c.col_span for c in self.cells)

    @property
    def pages(self) -> tuple[int, ...]:
        return tuple(sorted({c.page for c in self.cells if c.page is not None}))

    def cell_at(self, row: int, col: int) -> GridCell | None:
        found: GridCell | None = None
        for cell in self.cells:
            if (row, col) in cell.slots():
                found = cell
        return found

    def holes(self) -> list[tuple[int, int]]:
        covered = {s for c in self.cells for s in c.slots()}
        return [(r, c) for r in range(self.n_rows) for c in range(self.n_cols) if (r, c) not in covered]

    def overlaps(self) -> list[tuple[int, int]]:
        seen: set[tuple[int, int]] = set()
        dup: set[tuple[int, int]] = set()
        for cell in self.cells:
            for s in cell.slots():
                (dup if s in seen else seen).add(s)
        return sorted(dup)

    def as_cell_mappings(self) -> list[dict[str, Any]]:
        return [
            {"row": c.row, "col": c.col, "row_span": c.row_span, "col_span": c.col_span, "text": c.text}
            for c in self.cells
        ]


def grid_to_json(grid: TableGrid) -> dict[str, Any]:
    return {
        "v": 1,
        "engine": grid.source_engine,
        "ref": grid.provider_ref,
        "hr": grid.header_rows,
        "hc": grid.header_cols,
        "cells": [
            {
                "r": c.row, "c": c.col, "rs": c.row_span, "cs": c.col_span, "t": c.text,
                "p": c.page, "b": list(c.bbox) if c.bbox is not None else None,
                "h": c.is_header, "k": c.check,
            }
            for c in grid.cells
        ],
    }


def grid_from_json(data: Mapping[str, Any]) -> TableGrid:
    if int(data.get("v", 0)) != 1:
        raise GridError(f"未知网格 JSON 版本：{data.get('v')!r}")
    cells = tuple(
        GridCell(
            int(c["r"]), int(c["c"]), int(c["rs"]), int(c["cs"]), str(c["t"]),
            page=None if c.get("p") is None else int(c["p"]),
            bbox=None if c.get("b") is None else cast(BBox, tuple(float(x) for x in c["b"])),
            is_header=bool(c.get("h", False)),
            check=cast(CellCheck, str(c.get("k", "not_checked"))),
        )
        for c in data["cells"]
    )
    return TableGrid(
        cells=cells,
        source_engine=str(data["engine"]),
        provider_ref=None if data.get("ref") is None else str(data["ref"]),
        header_rows=int(data.get("hr", 0)),
        header_cols=int(data.get("hc", 0)),
    )


def remap_grid_pages(grid: TableGrid, mapping: Mapping[int, int]) -> TableGrid:
    missing = sorted({p for p in grid.pages if p not in mapping})
    if missing:
        raise GridError(f"页码映射缺少：{missing}")
    return replace(
        grid,
        cells=tuple(replace(c, page=None if c.page is None else mapping[c.page]) for c in grid.cells),
    )
```

```python
"""表头推断（结果是"推断"，不是供应商给出的事实；TextIn 的 cells 不带表头标记）。"""

from __future__ import annotations

import re
from dataclasses import replace
from typing import Final

from ragdemo.tables.grid import GridCell, TableGrid

_VALUE: Final = re.compile(r"^[(（]?[-−]?\d[\d,，]*(?:\.\d+)?%?[)）]?$")


def is_value_text(text: str) -> bool:
    return bool(_VALUE.match(re.sub(r"\s+", "", text)))


def infer_headers(grid: TableGrid) -> TableGrid:
    n_rows, n_cols = grid.n_rows, grid.n_cols
    k = 0
    if n_rows >= 2:
        k = 1
        while k < n_rows - 1:
            spanning = [c for c in grid.cells if c.row < k < c.row + c.row_span]
            if spanning:
                k = max(c.row + c.row_span for c in spanning)
                continue
            row_k = [c for c in grid.cells if c.row == k]
            if any(c.col_span > 1 for c in row_k) and not any(is_value_text(c.text) for c in row_k):
                k += 1
                continue
            break
        k = min(k, n_rows - 1)
    h = 0
    if n_cols >= 2:
        h = 1
        while h < n_cols - 1:
            spanning = [c for c in grid.cells if c.row >= k and c.col < h < c.col + c.col_span]
            if not spanning:
                break
            h = max(c.col + c.col_span for c in spanning)
        h = min(h, n_cols - 1)
    cells = tuple(replace(c, is_header=(c.row < k or c.col < h)) for c in grid.cells)
    return replace(grid, cells=cells, header_rows=k, header_cols=h)


def _distinct_texts(cells: list[GridCell | None]) -> tuple[str, ...]:
    out: list[str] = []
    seen: set[tuple[int, int]] = set()
    for cell in cells:
        if cell is None or (cell.row, cell.col) in seen:
            continue
        seen.add((cell.row, cell.col))
        text = " ".join(cell.text.split())
        if text:
            out.append(text)
    return tuple(out)


def col_header_path(grid: TableGrid, col: int) -> tuple[str, ...]:
    return _distinct_texts([grid.cell_at(r, col) for r in range(grid.header_rows)])


def row_label(grid: TableGrid, row: int) -> str:
    return " / ".join(_distinct_texts([grid.cell_at(row, c) for c in range(grid.header_cols)]))
```

"""单元格数字 → Decimal。分词复用 parse/local/number_closure.py（与 L0/L1 校验同一套口径）。"""

from __future__ import annotations

from decimal import Decimal, InvalidOperation

from ragdemo.parse.local.number_closure import ordered_numbers


def token_to_decimal(token: str) -> tuple[Decimal, bool] | None:
    t = token.strip()
    pct = "%" in t
    t = t.replace("%", "")
    neg = t.startswith("(") and t.endswith(")")
    if neg:
        t = t[1:-1].strip()
    try:
        value = Decimal(t)
    except InvalidOperation:
        return None
    return (-value if neg else value), pct


def cell_decimals(text: str) -> list[tuple[Decimal, bool]]:
    return [v for tok in ordered_numbers(text) if (v := token_to_decimal(tok)) is not None]

```python
"""TextIn detail[] 表格条目 → TableGrid（每格保留自己的 page_id 与 8 点 position）。"""

from __future__ import annotations

from collections.abc import Mapping, Sequence
from typing import Any

from ragdemo.tables.grid import BBox, GridCell, TableGrid
from ragdemo.tables.headers import infer_headers


def normalized_bbox(position: Sequence[float] | None, dims: tuple[int, int] | None) -> BBox | None:
    if not position or len(position) != 8 or dims is None:
        return None
    width, height = dims
    if not width or not height:
        return None
    xs, ys = position[0::2], position[1::2]
    return (min(xs) / width, min(ys) / height, max(xs) / width, max(ys) / height)


def textin_locator(json_ref: str | None, item: Mapping[str, Any]) -> str | None:
    if json_ref is None:
        return None
    return f"{json_ref}#page_id={item.get('page_id')}&paragraph_id={item.get('paragraph_id')}"


def grid_from_textin_item(
    item: Mapping[str, Any],
    *,
    page_offset: int,
    page_dims: Mapping[int, tuple[int, int]],
    engine: str,
    provider_ref: str | None,
) -> TableGrid | None:
    raw = item.get("cells") or []
    if not raw:
        return None
    cells: list[GridCell] = []
    for c in raw:
        pid = c.get("page_id", item.get("page_id"))
        page = int(pid) + page_offset if pid is not None else None
        cells.append(
            GridCell(
                row=int(c["row"]),
                col=int(c["col"]),
                row_span=int(c.get("row_span", 1)),
                col_span=int(c.get("col_span", 1)),
                text=str(c.get("text", "")),
                page=page,
                bbox=normalized_bbox(c.get("position"), page_dims.get(page) if page else None),
            )
        )
    return infer_headers(TableGrid(cells=tuple(cells), source_engine=engine, provider_ref=provider_ref))
```

-- db/migrations/031_fact_table_ref.sql
-- 来源：docs/10.12-plan/2026-10-13-表格处理改进计划.md T18。改动需同步 docs/02-data-model.md §4。
--
-- core.fact_table_ref：结构化事实（目前全部 source='wind'）在已解析公告表格里的单元格佐证。
-- 不是事实来源：fin_fact 一行不改，fin_fact.source_block 保持"抽取自文档"的原语义（Wind 事实不是从表格抽的）。
-- report_value 是 Python 按单元格数字 × 单位倍数换算出的元值；verdict 由数据库约束与数值关系强制一致，
-- 任何路径都不可能写入一条"差值超容差却标 match"的行。
-- known_at = GREATEST(fin_fact.known_at, doc_table.known_at)：两者都可知之后，佐证才可知。
-- 只引用公共表（写入方过滤 owner_* IS NULL），因此不需要 RLS。

CREATE TABLE core.fact_table_ref (
  ref_id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  fact_id        bigint  NOT NULL REFERENCES core.fin_fact,
  table_id       bigint  NOT NULL REFERENCES core.doc_table,
  block_id       bigint  NOT NULL REFERENCES core.doc_block,
  cell_row       int     NOT NULL CHECK (cell_row >= 0),
  cell_col       int     NOT NULL CHECK (cell_col >= 0),
  page           int,
  entity_id      text    NOT NULL REFERENCES core.entity,
  metric_id      text    NOT NULL,
  period         text    NOT NULL,
  report_value   numeric NOT NULL,
  fact_value     numeric NOT NULL,
  tolerance      numeric NOT NULL CHECK (tolerance >= 0),
  unit_scale     numeric NOT NULL CHECK (unit_scale > 0),
  period_label   text    NOT NULL,
  verdict        text    NOT NULL CHECK (verdict IN ('match', 'mismatch')),
  check_version  text    NOT NULL,
  valid_from     date    NOT NULL,
  known_at       timestamptz NOT NULL,
  superseded_at  timestamptz,
  source         text    NOT NULL,
  source_ref     text,
  ingest_run_id  text    NOT NULL,
  ingested_at    timestamptz NOT NULL DEFAULT now(),
  CONSTRAINT fact_table_ref_time_order CHECK (superseded_at IS NULL OR superseded_at > known_at),
  CONSTRAINT fact_table_ref_verdict_is_arithmetic
    CHECK ((verdict = 'match') = (abs(report_value - fact_value) <= tolerance))
);

CREATE UNIQUE INDEX fact_table_ref_live_uk
  ON core.fact_table_ref (fact_id, block_id, cell_row, cell_col) WHERE superseded_at IS NULL;
CREATE INDEX fact_table_ref_fact     ON core.fact_table_ref (fact_id) WHERE superseded_at IS NULL;
CREATE INDEX fact_table_ref_known_at ON core.fact_table_ref (known_at);

INSERT INTO core.bitemporal_registry (table_name, note) VALUES
  ('core.fact_table_ref', '事实的表格单元格佐证（表格处理改进计划 T18）');

SELECT * FROM core.fact_table_ref
 WHERE known_at <= asof.current_as_of()
   AND (superseded_at IS NULL OR superseded_at > asof.current_as_of());

## 已知局限

- **不做图表数值。** 图表只存图片与元数据（L0 v2 T10 的 `figure_meta`）；图里的数字不可溯源到单元格，生成侧引用图表数字时只能标"推断"。
- **扫描表格依赖 L1/L3 质量。** 无文字层页上的 TextIn 表格只能判 `scan_single_unverified`（单一引擎、无原文可比）；L2 的 `dual_agree` 无法发现两个引擎犯同一个错。逐格校验对它们无能为力。
- **逐格校验的边界。** 依赖单元格 bbox 与文字层坐标的换算：页面旋转（`rotation ≠ 0`）一律 `not_checked`；TextIn 的 bbox 若偏移超过 1.5pt 会误判 `mismatch`（由 G-B4 度量）；文字层本身错误（乱码、错误编码）时校验会"通过"；单元格内一个数字被拆成多个 PDF 词（如千分位处断开）时 `numbers_in` 的分词可能不一致而误判。
- **表头推断是启发式。** `is_header` 由"首行/首列 + 跨度"推断，标为推断；分节标题行（如"一、经营活动产生的现金流量"）只有带列跨度且无数值时才并入表头，否则作为普通行；行标签只取表头列，不拼接上方分节标题，所以"其中："类子项的行标签不含父项名。
- **跨页续表（非 L3）只链接不合并**，且链接规则不覆盖：两页之间夹脚注或图、续页列数因合并单元格变化、L1 与 L3 交界、续页首行是新表头而非重复表头。
- **单位绑定**只认"单位：…"与列表头括号单位两种写法；"金额单位：人民币元"之外的变体（如英文 "RMB'000"）不识别，`unit_source='none'`。
- **期别列识别**只覆盖 A 股定期报告常见表头；港股/美股报告（`hkexnews`、`edgar`）的英文期别列不识别（`no_period_column`），本计划不处理。Wind Q3 口径是假设，由 G-F3 检验。
- **既有重解析语义的副作用不修。** 21 份旧版文档在 `as_of < 2026-09-30` 时与新版同时可见（`superseded_at` 取重切块运维时刻），这是现有 `reparse_document` 的语义，不在本计划范围；网格只建在现行版上。
- **`table_looks_closed` 仍是旧口径**（审计 #7），本计划只提供 `TableGrid.holes()`；替换它会改变 `parse_confidence` 与路由 C 档触发，需在解析质量计划里单独评测。

- **规格覆盖：** ①单元格级存储与溯源——T4（类型）、T5（TextIn 每格页码/bbox）、T6（表名/单位/币种）、T7（逐格校验、版本）、T8（迁移 030 全文、RLS、asof 视图、登记、不变量、known_at 继承、ADR-0014）、T9（`[block_id | page | r{row}c{col}]` 与验证器检查项 1–3 对接）。②存量回填——T10（零成本、幂等、Markdown/HTML 逐字比对、21 份旧版与 9 份大文档的裁决、门槛 G-B1…G-B6）。③检索修复——T11（18 张缺嵌入）、T12（BM25 desc）、T13（截断 → 表格嵌入输入；R4 行组子块裁决与重开条件）、T14（单位绑定进证据）、描述版本入库（030 列 + T10 回填），每条写明改什么/改哪/测试/迁移/gold。④评测驱动——"评测口径（写死）"、T1（分组与门槛代码）、T2（基线先行）、T3+U2（人工题与描述派生偏差）、T19。⑤新管线衔接——T15（统一 `TableGrid`、HTML→网格、按页引擎、L1/L2/L3 判定、跨页规则、三大表 L3）、T16（P5/P9）。⑥结构化事实——T17（期别列）、T18（迁移 031 全文、Python 换算、不改 Wind 事实）。⑦任务拆分与并行——"并行与依赖"、"用户步骤汇总"。⑧已知局限与不做——两节。
