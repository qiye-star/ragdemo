# L0 + TextIn 分页接入与减页 实施计划（路径 4：第二版 L0 处理纯文字页 + 减少送解析的页数）

> **给执行者（agentic workers）：** 必须配合 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行。步骤用复选框（`- [ ]`）跟踪；每个任务结束时必须有独立可测的产物，并单独提交。**T0 是闸门**：T0 的结论决定 L0 开关能不能打开；其余任务的代码可以先合入（开关默认全关，关闭时线上行为与今天逐字节一致）。

**Goal：** 把研报与非定期公告的解析从"整份交给 TextIn"改为**逐页两级**：文字层完好、通过全部自检的纯文字页由 L0（`parse_layouts_l0`，本地确定性排版，零费用）产出块；其余页（表格、财务报表、多栏、无文字层、图表未解决、自检失败、被拒页）按**连续段**切成子 PDF 交给 L3（合合信息 TextIn），页码映射回原文；另用确定性规则跳过"无内容可解析"的页，**每一页的去向（L0 / L3 / skipped）、原因、P1–P8 校验结论都写进逐页台账**。目标是在不放松"每个数字可溯源"的前提下降低积压与增量的 TextIn 页数，并用实测替换本计划的成本估算。

**Architecture：** 新增 `parse/tiered/` 下的 `skip.py`（减页规则）、`textin_pages.py`（L3 连续段）、`blocks.py`（L0 页→块、跨引擎 `section_path`）、`acceptance_inputs.py`（P1–P8 输入与台账记录）、`records.py`（台账数据类，纯）、`ledger.py`（落库、汇总、告警）、`parser.py`（`TieredParser`，文档级入口）、`factory.py`（按配置装配）、`cost_model.py`（成本估算纯函数），以及 `parse/figure_blocks.py`（L0 页图块）。`TieredParser` 实现 `DocumentParser` 并新增 `parse_for(doc_type=, title=)`，由 `prepare_documents` 按 `isinstance` 分派；L3 的每次 TextIn 子调用各留一条 `provider_snapshot`（月度预算 `quality/budget.py` 自动计入）；逐页台账写新表 `core.parse_page_route`、文档结论写 `core.parse_doc_acceptance`（迁移 034）；块来源 `local` / `textin` 写 `core.doc_block.parse_source`，L0 页图片元数据写 `core.doc_block.figure_meta`（迁移 033）。旁路 JSON `parse/tiered/<sha256>/<指纹>.json` 的 `"routes"` 键沿用 `tables/page_engines.py` 已实现的读取口径。

**Tech Stack：** Python 3.11、pdfplumber（版面，已用）、pypdf 6.19.0（切子 PDF，已用；版本进指纹）、pypdfium2（图表裁图，已用）、reportlab（测试造 PDF，已用）、现有 `TextInParser` / `blocks_from_detail` / `PageBudget` / `ops.alerts.raise_alert` / `quality.budget.ensure_budget`、ParadeDB 迁移、pytest、ruff、mypy --strict。**不新增任何第三方依赖，不调用任何大模型。**

## Global Constraints

- **每个数字可溯源（CLAUDE.md §0），任何一级都不放松。** L0 只接受 `L0Page.accepted`（`kind == "plain_text"` 且自检 `status == "ok"`：双向数字闭合 + 双向字符闭合 + 顺序检查）的页；L0 页永不产出表格（防御：L0 产物里出现表格即整页降 L3）。TextIn 页沿用现状，并在入库时逐页跑 P3（不展开合并格 + 比较时重接空白，审计 §5 第 3 条）；未溯源数字记台账、文档结论落库，**不改库里存的文本**。
- **计算与生成分离（§1.2）：** 本计划不新增、不修改任何 prompt，不调用任何大模型；成本、占比、门槛全部由 Python 计算并先写测试。
- **数据境内（§0）：** 原始文档只发往 TextIn（已在用，经出网代理）；L0 全在本机。研报（ADR-0014）同样只发 TextIn。
- **用户私有材料（`owner_user` 非空）不进入分级路由**：`TieredParser.parse_for` 见到 `owner_user` 立即原样交给 `TextInParser.parse(..., owner_user=)` 的私有闸门，不跑 L0、不跳页、不写台账。
- **年报 / 半年报 / 季报整份走 L3**：`doc_type ∈ {annual_report, quarterly}` 或 `census.force_whole_document_l3(doc_type, title, None)` 为真（按标题识别的 announcement 型定期报告）→ 整份原样送 TextIn（与旧路径同一缓存键），**不跳页**；配置校验拒绝把 `annual_report` / `quarterly` 放进 `PARSE_TIERED_DOC_TYPES`。财务报表页（`classify_page` 给出 `financial_statement`）永远 L3。
- **时点（§1.1）：** 解析不改 `known_at` / `valid_from` / `publish_at`；块继承文档时点列（现有 `DocumentWriter`）；`core.parse_page_route.routed_at`、`core.parse_doc_acceptance.evaluated_at` 是运维时间，**永不进入 `as_of` 过滤**，两表不登记 `core.bitemporal_registry`（与 `core.parse_tier_policy` 同理，见迁移 015 注释）。
- **不批量重解析已入库文档**（会使 `gold_block_ids` 失效）；分级路由只对**新**文档生效；改 L0 版本 / 规则 / 指纹只影响之后的新文档。
- **跳页永不静默：** 被跳过的页在台账里 `tier = 'skipped'` + `skip_rule`，旁路 JSON 的 `"skipped"` 键也有；只命中而未强制执行的规则记 `shadow_skip_rules`。任何规则未经 T2 的事先门槛与用户批准（U3）不得进入 `PARSE_SKIP_RULES`。
- **评测驱动（§1.4）：** 任何开关打开之前，先测基线并提交（T11）；接入后按 `parse_source` 与 gold 类型分组对比；`eval_extraction` 与观点评分无运行器，PR 中如实写，范围由用户裁决（U5，T13）。
- **迁移只走 `db/migrations/`**，编号 033 / 034（见 §0 第 2 条）；迁移只加不改。
- **密钥只在环境变量 / 出网代理层**；测试夹具、日志、提交、本计划中不出现任何密钥。
- **不修改 `parse/local/`、`tables/` 下的任何文件**（它们有进行中的修复）；需要的能力只经它们的公开函数调用。
- `ruff` + `mypy --strict` 必须通过；Python 3.11+；`ragdemo-core` 不 import 业务层（本计划只改业务层与迁移）。
- 日志结构化（JSON），含 `run_id`（= `ingest_run_id`）、`as_of`（解析阶段为 `null`，与现有入库日志一致）、`entity_id`；日志不记正文。
- 用户偏好：文档与回答用中文。

```python
def parse_skip_rules(raw: str) -> frozenset[SkipRuleId]:
    """`PARSE_SKIP_RULES` 的逗号列表 → 规则集合；未知名一律报错（拼错不能变成"静默不跳"）。"""
    names = {s.strip() for s in raw.split(",") if s.strip()}

    if unknown:
        raise ValueError(f"未知的减页规则：{unknown}（可选 {list(SKIP_RULE_IDS)}）")
    return frozenset(cast(SkipRuleId, n) for n in names)
```

```python
（PARSE_SKIP_RULES，经 T2 门槛与用户批准）决定；未执行的命中记为影子跳页写进台账。"""

from __future__ import annotations

import re
from collections.abc import Sequence
from dataclasses import dataclass
from typing import Final, Literal

from ragdemo.parse.local.layout import PageLayout
from ragdemo.parse.local.number_closure import numbers_in
from ragdemo.parse.tiered.types import SKIP_RULE_IDS, SkipRuleId

SKIP_RULES_VERSION: Final = "skip-v1"
DocKind = Literal["announcement", "research_report"]
BLANK_MAX_CHARS: Final = 40
SIGNATURE_MAX_CHARS: Final = 200
DISCLAIMER_TAIL_PAGES: Final = 3
_SIGN = re.compile(r"董事会|监事会|特此公告")
_DISCLAIMER = re.compile(r"免责声明|分析师声明|法律声明|重要声明|特别声明")
_DATE = re.compile(r"(?:19|20)\d{2}\s*年\s*\d{1,2}\s*月\s*\d{1,2}\s*日")


@dataclass(frozen=True)
class PageFacts:
    page: int
    text: str  # 文字层（pdfplumber，剥离装饰之前）
    image_count: int
    curve_count: int


def page_facts(layout: PageLayout) -> PageFacts:
    return PageFacts(
        layout.page,
        layout.text,
        sum(1 for g in layout.graphics if g.kind == "image"),
        sum(1 for g in layout.graphics if g.kind == "curve"),
    )


def non_date_numbers(text: str) -> int:
    return sum(numbers_in(_DATE.sub(" ", text)).values())


def _chars(text: str) -> int:
    return sum(1 for ch in text if not ch.isspace())


@dataclass(frozen=True)
class SkipDecision:
    page: int
    matched: tuple[SkipRuleId, ...]  # 按 SKIP_RULE_IDS 的顺序


def evaluate_skip_rules(pages: Sequence[PageFacts], *, doc_kind: DocKind) -> list[SkipDecision]:
    n = len(pages)
    out: list[SkipDecision] = []
    for i, p in enumerate(pages):
        chars = _chars(p.text)
        no_numbers = non_date_numbers(p.text) == 0
        hit: set[SkipRuleId] = set()
        if chars < BLANK_MAX_CHARS and p.image_count == 0 and p.curve_count == 0 and no_numbers:
            hit.add("blank_page")
        if (
            doc_kind == "announcement"
            and n >= 2
            and i == n - 1
            and chars < SIGNATURE_MAX_CHARS
            and _SIGN.search(p.text)
            and no_numbers
        ):
            hit.add("signature_tail")
        if (
            doc_kind == "research_report"
            and i >= n - DISCLAIMER_TAIL_PAGES
            and _DISCLAIMER.search(p.text)
            and no_numbers
        ):
            hit.add("research_disclaimer_tail")
        out.append(SkipDecision(p.page, tuple(r for r in SKIP_RULE_IDS if r in hit)))
    return out


def enforced_skips(
    decisions: Sequence[SkipDecision], enforced: frozenset[SkipRuleId]
) -> dict[int, SkipRuleId]:
    chosen: dict[int, SkipRuleId] = {}
    for d in decisions:
        for rule in d.matched:
            if rule in enforced:
                chosen[d.page] = rule
                break
    if decisions and len(chosen) == len(decisions):
        return {}
    return chosen
```

```python
"""减页规则的门槛判定与节省估算（纯函数；I/O 在 scripts/skip_audit.py）。门槛在
docs/10.12-plan/验收记录/减页规则测量.md 事先登记，代码常量与之一致，不得事后调整。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from decimal import Decimal
from typing import Final, Literal

from ragdemo.parse.tiered.types import SKIP_RULE_IDS, SkipRuleId

SKIP_GATE_MIN_PAGES: Final = 5


@dataclass(frozen=True)
class SkipEvidence:
    rule: SkipRuleId
    doc_key: str
    page: int
    block_numbers: int  # 该页 TextIn 叶子块里的非日期数字个数
    referenced_blocks: int  # 该页块被事实表 / 评测引用的个数


@dataclass(frozen=True)
class RuleVerdict:
    rule: SkipRuleId
    validation_pages: int
    pages_with_numbers: int
    referenced_blocks: int
    verdict: Literal["enforceable", "shadow_only"]
    reasons: tuple[str, ...]


def judge_rule(rule: SkipRuleId, evidence: Sequence[SkipEvidence]) -> RuleVerdict:
    ev = [e for e in evidence if e.rule == rule]
    reasons: list[str] = []
    if len(ev) < SKIP_GATE_MIN_PAGES:
        reasons.append(f"验证页 {len(ev)} < {SKIP_GATE_MIN_PAGES}，证据不足")
    with_numbers = sum(1 for e in ev if e.block_numbers > 0)
    if with_numbers:
        reasons.append(f"{with_numbers} 个验证页的 TextIn 块含非日期数字")
    refs = sum(e.referenced_blocks for e in ev)
    if refs:
        reasons.append(f"{refs} 个验证页的块被事实表或评测引用")
    return RuleVerdict(
        rule, len(ev), with_numbers, refs, "shadow_only" if reasons else "enforceable", tuple(reasons)
    )


@dataclass(frozen=True)
class BacklogCandidate:
    rule: SkipRuleId  # 该页命中的第一条规则（与 enforced_skips 同序）
    doc_key: str
    page: int
    l0_accepted: bool  # L0 开启时这一页本来就不花钱


@dataclass(frozen=True)
class RuleSavings:
    candidate_pages: int
    incremental_pages: int
    incremental_cny: Decimal


def savings(candidates: Sequence[BacklogCandidate], *, price: Decimal) -> dict[SkipRuleId, RuleSavings]:
    out: dict[SkipRuleId, RuleSavings] = {}
    for rule in SKIP_RULE_IDS:
        mine = [c for c in candidates if c.rule == rule]
        if not mine:
            continue
        inc = sum(1 for c in mine if not c.l0_accepted)
        out[rule] = RuleSavings(len(mine), inc, price * inc)
    return out
```

```python
"""只读测量减页规则（L0 + TextIn 分页接入计划 T2）：积压候选页、扣除 L0 重叠后的增量、
31 份现行 TextIn 文档上的验证证据与门槛判定。不调任何付费接口、不写库；只打印计数与 doc_id:page，
不打印正文与环境变量。用法：set -a && . ./.env && set +a && uv run --no-sync python scripts/skip_audit.py"""

from __future__ import annotations

import glob
import os
from concurrent.futures import ProcessPoolExecutor
from datetime import UTC, datetime
from pathlib import Path

import psycopg

from ragdemo.config import DEFAULT_TEXTIN_COST_PER_PAGE_CNY, load_config
from ragdemo.parse.local.l0 import parse_layouts_l0
from ragdemo.parse.local.layout import extract_pages
from ragdemo.parse.tiered.census import force_whole_document_l3
from ragdemo.parse.tiered.skip import DocKind, evaluate_skip_rules, non_date_numbers, page_facts
from ragdemo.parse.tiered.skip_audit import BacklogCandidate, SkipEvidence, judge_rule, savings
from ragdemo.parse.tiered.types import SKIP_RULE_IDS, SkipRuleId
from ragdemo_core.db.session import as_of_session

Item = tuple[str, DocKind, str]  # (键, 文档口径, PDF 路径)
Hit = tuple[int, SkipRuleId, bool]  # (页码, 第一条命中规则, L0 是否接受)


def _hits(item: Item) -> tuple[str, list[Hit] | None]:
    key, kind, path = item
    try:
        layouts = extract_pages(Path(path).read_bytes())
        l0 = parse_layouts_l0(layouts)
    except Exception:  # noqa: BLE001 —— 读不了的文档计入"无法测量"
        return key, None
    decisions = evaluate_skip_rules([page_facts(x) for x in layouts], doc_kind=kind)
    return key, [(d.page, d.matched[0], l0[d.page - 1].accepted) for d in decisions if d.matched]


def main() -> None:
    blob_root = load_config().blob_root
    with psycopg.connect(os.environ["RAGDEMO_DSN"]) as conn:
        with as_of_session(conn, datetime.now(UTC)) as s:
            pending = s.execute(
                "SELECT d.doc_id, d.doc_type, d.title, d.raw_ref FROM asof.document d WHERE d.raw_ref LIKE '%%.pdf'"
                " AND NOT EXISTS (SELECT 1 FROM asof.doc_block b WHERE b.doc_id = d.doc_id)"
            ).fetchall()
            done = s.execute(
                "SELECT doc_id, doc_type, title, raw_ref FROM asof.document WHERE parse_engine LIKE 'textin%%'"
            ).fetchall()
            blocks = s.execute(
                "SELECT b.doc_id, b.page, b.block_id, b.content FROM asof.doc_block b JOIN asof.document d"
                " USING (doc_id) WHERE d.parse_engine LIKE 'textin%%' AND b.is_leaf"
            ).fetchall()
            refs = {int(r[0]) for r in s.execute("SELECT block_id FROM asof.fact_table_ref WHERE block_id IS NOT NULL")}
        refs |= {int(b) for (arr,) in conn.execute("SELECT gold_block_ids FROM evals.eval_retrieval") for b in arr}
        refs |= {int(r[0]) for r in conn.execute(
            "SELECT gold_block_id FROM evals.eval_extraction WHERE gold_block_id IS NOT NULL")}
    backlog: list[Item] = [(f"P:{r[0]}", "announcement", str(blob_root / r[3]))
                           for r in pending if not force_whole_document_l3(r[1], r[2], None)]
    backlog += [(f"R:{Path(f).name}", "research_report", f)
                for f in sorted(glob.glob("docs/rawdata/**/research/*.pdf", recursive=True))]
    validation: list[Item] = [(f"D:{r[0]}", "announcement", str(blob_root / r[3]))
                              for r in done if not force_whole_document_l3(r[1], r[2], None)]
    with ProcessPoolExecutor(4) as ex:
        back = list(ex.map(_hits, backlog, chunksize=4))
        val = list(ex.map(_hits, validation, chunksize=4))
    by_page: dict[tuple[str, int], list[tuple[int, str]]] = {}
    for doc_id, page, block_id, content in blocks:
        by_page.setdefault((f"D:{doc_id}", int(page or 0)), []).append((int(block_id), str(content)))
    candidates = [BacklogCandidate(rule, key, page, acc) for key, h in back if h for page, rule, acc in h]
    evidence = [
        SkipEvidence(rule, key, page,
                     sum(non_date_numbers(c) for _, c in by_page.get((key, page), [])),
                     sum(1 for b, _ in by_page.get((key, page), []) if b in refs))
        for key, h in val if h for page, rule, _ in h
    ]
    print("无法测量：", sorted(k for k, h in back + val if h is None))
    for rule, s in savings(candidates, price=DEFAULT_TEXTIN_COST_PER_PAGE_CNY).items():
        print(f"{rule}: 候选 {s.candidate_pages} 页，扣 L0 后增量 {s.incremental_pages} 页，{s.incremental_cny} 元")
    for rule in SKIP_RULE_IDS:
        print(judge_rule(rule, evidence))
    print("验证跳页清单：", sorted(f"{e.doc_key}:{e.page}" for e in evidence))


if __name__ == "__main__":
    main()
```

```python
@dataclass(frozen=True)
class TextInCall:
    """一次 TextIn 调用（整份或一个连续段）。每次计费调用对应一条 provider_snapshot。"""

    pages: tuple[int, ...]  # 原文档页码，升序、连续
    json_ref: str | None
    md_ref: str | None
    engine: str  # TextIn engine_version：textin:<版本>+<参数指纹>
    billed_pages: int  # 本次实际计费页数；缓存命中为 0

    def __post_init__(self) -> None:
        if not self.pages or list(self.pages) != sorted(set(self.pages)) or self.pages[0] < 1:
            raise ValueError(f"TextInCall.pages 必须是升序、无重复、从 1 起的页码：{self.pages}")
        if self.billed_pages < 0:
            raise ValueError(f"计费页数不能为负：{self.billed_pages}")


def call_to_dict(c: TextInCall) -> dict[str, object]:
    return {"pages": list(c.pages), "json_ref": c.json_ref, "md_ref": c.md_ref, "engine": c.engine,
            "billed_pages": c.billed_pages}


def call_from_dict(d: Mapping[str, Any]) -> TextInCall:
    return TextInCall(
        pages=tuple(int(p) for p in d["pages"]),
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/textin_pages.py
"""L3：需要 TextIn 的页按连续段切成子 PDF 分别送 TextIn（段内跨页表仍由 TextIn 合并），
块与表格网格的页码映射回原文档。全部页都要 L3 时直接送原 PDF（与旧路径同一缓存键）并保留原样结果。
TextIn 的异常原样抛出，由 prepare_documents 按既有规则处理。"""

from __future__ import annotations

from collections.abc import Mapping, Sequence
from dataclasses import dataclass, replace

from ragdemo.adapters.announcements import NormalizedBlock
from ragdemo.parse.textin import DocumentParser, ParseResult
from ragdemo.parse.tiered.pdfpages import sub_pdf
from ragdemo.parse.tiered.types import TextInCall
from ragdemo.tables.grid import GridError, remap_grid_pages


def contiguous_runs(pages: Sequence[int]) -> list[list[int]]:
    runs: list[list[int]] = []
    for p in sorted(set(pages)):
        if runs and p == runs[-1][-1] + 1:
            runs[-1].append(p)
        else:
            runs.append([p])
    return runs


@dataclass(frozen=True)
class TextInPages:
    blocks_by_page: Mapping[int, tuple[NormalizedBlock, ...]]
    calls: tuple[TextInCall, ...]
    warnings: tuple[str, ...]
    whole_document: ParseResult | None  # 全部页 L3 时的原样结果（已标 source=textin）

    @property
    def billed_pages(self) -> int:
        return sum(c.billed_pages for c in self.calls)


def _billed(r: ParseResult, sent: int) -> int:
    return 0 if r.from_cache else (r.page_count or sent)


def _remap(b: NormalizedBlock, run: Sequence[int], warnings: list[str]) -> NormalizedBlock:
    if b.page is None:
        original = run[0]
        warnings.append(f"TextIn 块缺页码，归入段首页 {original}")
    elif not 1 <= b.page <= len(run):
        raise ValueError(f"TextIn 块页码 {b.page} 超出子文档 1..{len(run)}")
    else:
        original = run[b.page - 1]
    table = b.table
    if table is not None:
        try:
            table = replace(table, grid=remap_grid_pages(table.grid, {i + 1: p for i, p in enumerate(run)}))
        except GridError:
            warnings.append(f"第 {original} 页表格网格页码无法映射，网格丢弃")
            table = None
    return replace(b, page=original, table=table, source="textin")


def _group(blocks: Sequence[NormalizedBlock]) -> dict[int, tuple[NormalizedBlock, ...]]:
    by_page: dict[int, list[NormalizedBlock]] = {}
    for b in blocks:
        if b.page is not None:
            by_page.setdefault(b.page, []).append(b)
    return {p: tuple(bs) for p, bs in by_page.items()}


def parse_pages_with_textin(
    textin: DocumentParser, pdf_bytes: bytes, pages: Sequence[int], *, total_pages: int
) -> TextInPages:
    wanted = sorted(set(pages))
    if not wanted:
        return TextInPages({}, (), (), None)
    if wanted == list(range(1, total_pages + 1)):
        r = textin.parse(pdf_bytes, owner_user=None)
        marked = [replace(b, source="textin") for b in r.blocks]
        whole = replace(r, blocks=marked)
        call = TextInCall(tuple(wanted), r.json_ref, r.md_ref, r.engine_version, _billed(r, len(wanted)))
        return TextInPages(_group(marked), (call,), tuple(r.warnings), whole)
    remapped: list[NormalizedBlock] = []
    calls: list[TextInCall] = []
    warnings: list[str] = []
    for run in contiguous_runs(wanted):
        r = textin.parse(sub_pdf(pdf_bytes, run), owner_user=None)
        calls.append(TextInCall(tuple(run), r.json_ref, r.md_ref, r.engine_version, _billed(r, len(run))))
        warnings.extend(r.warnings)
        remapped.extend(_remap(b, run, warnings) for b in r.blocks)
    return TextInPages(_group(remapped), tuple(calls), tuple(warnings), None)
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/blocks.py
"""L0 页 markdown → NormalizedBlock；整份文档按页拼接、跨引擎统一标题层级、重建 section_path。

L0 页只可能有标题与段落（parse/local/l0.py：表格页永不在 L0 排版），出现表格行说明上游
有 bug，抛 L0TableInOutput，由调用方把该页降到 L3。"""

from __future__ import annotations

import re
from collections.abc import Sequence
from dataclasses import replace

from ragdemo.adapters.announcements import NormalizedBlock
from ragdemo.parse.local.headings import SYSTEM_ORDER, numbering_of

_HEADING = re.compile(r"^(#{1,6})\s+(.*\S)\s*$")
_TABLE_LINE = re.compile(r"^\s*\||<table\b", re.IGNORECASE)


class L0TableInOutput(ValueError):
    """L0 产物里出现了表格。"""


def blocks_from_l0_page(page: int, markdown: str) -> list[NormalizedBlock]:
    out: list[NormalizedBlock] = []
    para: list[str] = []

    def flush() -> None:
        text = "\n".join(para).strip()
        if text:
            out.append(NormalizedBlock(len(out), "paragraph", "", text, page=page, source="local"))
        para.clear()

    for line in markdown.splitlines():
        if _TABLE_LINE.search(line):
            raise L0TableInOutput(f"第 {page} 页 L0 产物含表格行")
        s = line.strip()
        heading = _HEADING.match(s)
        if heading:
            flush()
            out.append(
                NormalizedBlock(len(out), "title", "", heading.group(2), page=page,
                                level=len(heading.group(1)) - 1, source="local")
            )
        elif not s:
            flush()
        else:
            para.append(s)
    flush()
    return out


def harmonize_title_levels(blocks: Sequence[NormalizedBlock]) -> list[NormalizedBlock]:
    titles = [b for b in blocks if b.block_type == "title"]
    if {"local", "textin"} - {b.source for b in titles}:
        return list(blocks)
    numbering = {i: numbering_of(b.content) for i, b in enumerate(blocks) if b.block_type == "title"}
    present = sorted(
        {n.system for n in numbering.values() if n is not None and n.system != "keyword"},
        key=SYSTEM_ORDER.index,
    )
    rank = {s: i for i, s in enumerate(present)}
    out: list[NormalizedBlock] = []
    for i, b in enumerate(blocks):
        if b.block_type != "title":
            out.append(b)
            continue
        n = numbering[i]
        out.append(replace(b, level=0 if n is None or n.system == "keyword" else rank[n.system]))
    return out


def assemble_blocks(pages: Sequence[tuple[int, Sequence[NormalizedBlock]]]) -> list[NormalizedBlock]:
    flat = [b for _page, bs in sorted(pages, key=lambda item: item[0]) for b in bs]
    stack: list[str] = []
    out: list[NormalizedBlock] = []
    for b in harmonize_title_levels(flat):
        if b.block_type == "title":
            level = b.level if b.level is not None else 0
            del stack[level:]
            stack.append(b.content)
            section = " > ".join(stack[:-1])
        else:
            section = " > ".join(stack)
        out.append(replace(b, ordinal=len(out), section_path=section))
    return out
```

```python
# packages/ragdemo/src/ragdemo/parse/figure_blocks.py
"""L0 页图表 → figure 块（只存图与元数据，非叶子、不检索、不解读）。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import replace
from typing import Final

from ragdemo.adapters.announcements import NormalizedBlock
from ragdemo.parse.figures import FigureRef, figure_to_dict

FIGURE_PLACEHOLDER: Final = "[图]"


def figure_block(ref: FigureRef, *, ordinal: int, section_path: str) -> NormalizedBlock:
    return NormalizedBlock(
        ordinal=ordinal,
        block_type="figure",
        section_path=section_path,
        content=ref.caption.strip() or FIGURE_PLACEHOLDER,
        page=ref.page,
        bbox=ref.bbox_norm,
        source="local",
        figure_meta=figure_to_dict(ref),
    )


def _path_after(b: NormalizedBlock) -> str:
    if b.block_type == "title":
        return f"{b.section_path} > {b.content}" if b.section_path else b.content
    return b.section_path


def interleave_figures(blocks: Sequence[NormalizedBlock], refs: Sequence[FigureRef]) -> list[NormalizedBlock]:
    out = list(blocks)
    for ref in sorted(refs, key=lambda r: (r.page, r.bbox_norm[1])):
        idx = 0
        for i, b in enumerate(out):
            if b.page is not None and b.page <= ref.page:
                idx = i + 1
        if idx > 0:
            section = _path_after(out[idx - 1])
        elif idx < len(out):
            section = out[idx].section_path
        else:
            section = ""
        out.insert(idx, figure_block(ref, ordinal=0, section_path=section))
    return [replace(b, ordinal=i) for i, b in enumerate(out)]
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/records.py
"""逐页台账的数据类（纯，无 I/O）。parse/textin.py 的 ParseResult 引用 ParseLedger，
所以本模块除 tiered.types 外不得 import parse 包内的任何模块。校验与迁移 034 的 CHECK 一一对应。"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Final, Literal

from ragdemo.parse.tiered.types import SkipRuleId

LedgerTier = Literal["L0", "L3", "skipped"]
LEDGER_TIERS: Final[tuple[LedgerTier, ...]] = ("L0", "L3", "skipped")
TierVerdictValue = Literal["passed", "failed", "not_run"]
P3StateValue = Literal["pass", "fail", "unverifiable_scan"]
DocStateValue = Literal[
    "accepted", "accepted_with_scan", "partially_accepted", "textin_unverified", "rejected", "empty_document"
]


@dataclass(frozen=True)
class PageRecord:
    page: int
    tier: LedgerTier
    engine: str
    page_kind: str
    reasons: tuple[str, ...] = ()
    skip_rule: SkipRuleId | None = None
    shadow_skip_rules: tuple[SkipRuleId, ...] = ()
    textin_billed: bool = False
    textin_json_ref: str | None = None
    tier_verdict: TierVerdictValue = "not_run"
    p3_state: P3StateValue | None = None
    unverified_numbers: int = 0
    output_numbers: int = 0
    image_ocr_numbers: int = 0
    coverage_ratio: float | None = None
    table_blocks: int = 0
    figure_count: int = 0
    chart_regions: int = 0
    checks: tuple[tuple[str, bool, str, str], ...] = ()  # (检查号, 通过, 状态, 说明)

    def __post_init__(self) -> None:
        problems: list[str] = []
        if self.page < 1:
            problems.append(f"页码 {self.page}")
        if self.tier not in LEDGER_TIERS:
            problems.append(f"层级 {self.tier!r}")
        if not self.engine or not self.page_kind:
            problems.append("engine / page_kind 为空")
        if (self.tier == "skipped") != (self.skip_rule is not None):
            problems.append("skip_rule 必须且只能出现在跳页上")
        if self.textin_billed and self.tier != "L3":
            problems.append("只有 L3 页可以计费")
        if self.textin_json_ref is not None and self.tier != "L3":
            problems.append("只有 L3 页有 TextIn JSON")
        if (self.tier == "skipped") != (self.p3_state is None):
            problems.append("跳页没有 P3，其余页必须有")
        counts = (self.unverified_numbers, self.output_numbers, self.image_ocr_numbers, self.table_blocks,
                  self.figure_count, self.chart_regions)
        if any(c < 0 for c in counts):
            problems.append("计数为负")
        if self.unverified_numbers > self.output_numbers:
            problems.append("未溯源数字多于产出数字")
        if problems:
            raise ValueError(f"PageRecord p{self.page} 不一致：{'；'.join(problems)}")


@dataclass(frozen=True)
class DocRecord:
    state: DocStateValue
    reasons: tuple[str, ...]
    warnings: tuple[str, ...]
    unverified_numbers: int
    scan_pages: int
    page_count: int
    l0_pages: int
    l3_pages: int
    skipped_pages: int
    billed_pages: int
    fallback_reason: str | None
    acceptance_version: str

    def __post_init__(self) -> None:
        counts = (self.unverified_numbers, self.scan_pages, self.page_count, self.l0_pages, self.l3_pages,
                  self.skipped_pages, self.billed_pages)
        if any(c < 0 for c in counts):
            raise ValueError("DocRecord 计数为负")
        if self.l0_pages + self.l3_pages + self.skipped_pages != self.page_count:
            raise ValueError(
                f"页数不守恒：L0 {self.l0_pages} + L3 {self.l3_pages} + 跳页 {self.skipped_pages}"
                f" ≠ {self.page_count}"
            )


@dataclass(frozen=True)
class ParseLedger:
    routes_ref: str
    pages: tuple[PageRecord, ...]
    doc: DocRecord

    def __post_init__(self) -> None:
        nums = [p.page for p in self.pages]
        if nums != sorted(set(nums)):
            raise ValueError(f"台账页码必须严格递增：{nums[:20]}")
        by_tier = {t: sum(1 for p in self.pages if p.tier == t) for t in LEDGER_TIERS}
        if (by_tier["L0"], by_tier["L3"], by_tier["skipped"]) != (
            self.doc.l0_pages, self.doc.l3_pages, self.doc.skipped_pages
        ):
            raise ValueError(f"逐页层级计数 {by_tier} 与文档结论不一致")
```

```python
@dataclass(frozen=True)
class TierRow:
    tier: LedgerTier
    pages: int
    billed_pages: int
    cost_cny: Decimal
    pages_unpriced: int


def tier_summary(
    conn: psycopg.Connection,
    *,
    start: datetime,
    end: datetime,
    textin_per_page: Decimal | None,
    doc_type: str | None = None,
) -> list[TierRow]:
    rows = conn.execute(
        "SELECT tier, count(*), count(*) FILTER (WHERE textin_billed), coalesce(sum(cost_cny), 0),"
        "       count(*) FILTER (WHERE textin_billed AND cost_cny IS NULL)"
        "  FROM core.parse_page_route"
        " WHERE routed_at >= %s AND routed_at < %s AND (%s::text IS NULL OR doc_type = %s)"
        " GROUP BY tier",
        (start, end, doc_type, doc_type),
    ).fetchall()
    got = {str(r[0]): r for r in rows}
    out: list[TierRow] = []
    for t in LEDGER_TIERS:
        r = got.get(t)
        if r is None:
            out.append(TierRow(t, 0, 0, Decimal(0), 0))
            continue
        cost, unpriced = Decimal(r[3]), int(r[4])
        if unpriced and textin_per_page is not None:
            cost, unpriced = cost + textin_per_page * unpriced, 0
        out.append(TierRow(t, int(r[1]), int(r[2]), cost, unpriced))
    return out


def format_tier_summary(rows: Sequence[TierRow]) -> str:
    lines = ["| 去向 | 页数 | 计费页 | 估算费用（元） | 未定价页 |", "|---|---|---|---|---|"]
    lines += [f"| {r.tier} | {r.pages} | {r.billed_pages} | {r.cost_cny:.4f} | {r.pages_unpriced} |" for r in rows]
    lines.append(
        f"| 合计 | {sum(r.pages for r in rows)} | {sum(r.billed_pages for r in rows)}"
        f" | {sum((r.cost_cny for r in rows), Decimal(0)):.4f} | {sum(r.pages_unpriced for r in rows)} |"
    )
    return "\n".join(lines)


def evaluate_ledger_alerts(
    day_rows: Sequence[TierRow],
    *,
    fallback_docs: int,
    l0_unverified_pages: int,
    month_textin_cny: Decimal,
    monthly_budget_cny: Decimal,
) -> list[Alert]:
    alerts: list[Alert] = []
    if l0_unverified_pages > 0:
        alerts.append(Alert("parse_ledger", "critical", "parse_ledger:l0_unverified",
                            f"近 24 小时有 {l0_unverified_pages} 个 L0 页数字未能溯源",
                            "停止条件 S-A：立即设 PARSE_TIER_L0_ENABLED=false，排查排版器"))
    if fallback_docs > 0:
        alerts.append(Alert("parse_ledger", "warning", "parse_ledger:fallback",
                            f"近 24 小时有 {fallback_docs} 份文档整份退回 TextIn",
                            "查 core.parse_doc_acceptance.fallback_reason"))
    by = {r.tier: r.pages for r in day_rows}
    routed = by.get("L0", 0) + by.get("L3", 0)
    if routed >= L3_SHARE_MIN_PAGES and by.get("L3", 0) / routed > L3_SHARE_ALERT:
        alerts.append(Alert("parse_ledger", "warning", "parse_ledger:l3_share",
                            f"近 24 小时 L3 占比 {by.get('L3', 0) / routed:.0%} 超过 {L3_SHARE_ALERT:.0%}",
                            f"L3 {by.get('L3', 0)} 页 / 路由 {routed} 页；L0 可能没在工作，成本不降"))
    if month_textin_cny >= monthly_budget_cny * PARSE_SPEND_ALERT_SHARE:
        severity = "critical" if month_textin_cny >= monthly_budget_cny else "warning"
        alerts.append(Alert("parse_ledger", severity, "parse_ledger:budget",
                            f"本月 TextIn 花费 {month_textin_cny:.2f} 元，达总预算的"
                            f" {month_textin_cny / monthly_budget_cny:.0%}",
                            "ADR-0008 推翻条件：解析支出超过总预算 30%"))
    return alerts


def collect_ledger_alerts(
    conn: psycopg.Connection, *, now: datetime, textin_per_page: Decimal | None, monthly_budget_cny: Decimal
) -> list[Alert]:
    since = now - timedelta(hours=24)
    day = tier_summary(conn, start=since, end=now, textin_per_page=textin_per_page)
    fb = conn.execute(
        "SELECT count(*) FROM core.parse_doc_acceptance"
        " WHERE evaluated_at >= %s AND evaluated_at < %s AND fallback_reason IS NOT NULL",
        (since, now),
    ).fetchone()
    bad = conn.execute(
        "SELECT count(*) FROM core.parse_page_route"
        " WHERE routed_at >= %s AND routed_at < %s AND tier = 'L0' AND p3_state <> 'pass'",
        (since, now),
    ).fetchone()
    month_start = now.astimezone(SHANGHAI).replace(day=1, hour=0, minute=0, second=0, microsecond=0)
    spent = conn.execute(
        "SELECT coalesce(sum(cost_cents), 0) / 100 FROM core.provider_snapshot"
        " WHERE provider = 'textin' AND fetched_at >= %s AND fetched_at < %s",
        (month_start, now),
    ).fetchone()
    return evaluate_ledger_alerts(
        day,
        fallback_docs=int(fb[0]) if fb else 0,
        l0_unverified_pages=int(bad[0]) if bad else 0,
        month_textin_cny=Decimal(spent[0]) if spent else Decimal(0),
        monthly_budget_cny=monthly_budget_cny,
    )


def emit_ledger_alerts(
    conn: psycopg.Connection, *, now: datetime, textin_per_page: Decimal | None, monthly_budget_cny: Decimal
) -> list[dict[str, str]]:
    alerts = collect_ledger_alerts(conn, now=now, textin_per_page=textin_per_page,
                                   monthly_budget_cny=monthly_budget_cny)
    return [raise_alert(conn, a, now=now) for a in alerts]
```

```python
def coverage_ratio(p: PageInput) -> float | None:
    """P4 的比值本身（不依赖阈值）；无文字层或文字层内容字符不足 MIN_COVERAGE_CHARS 返回 None。"""
    if not _has_text_layer(p) or p.text_layer_text is None:

    need = _content_len(p.text_layer_text)
```

```python
def _structure_problems(pages: Sequence[PageInput], meta: DocumentMeta | None) -> list[str]:
    out: list[str] = []
    nums = [p.page for p in pages]
    dup = sorted(n for n, c in Counter(nums).items() if c > 1)
    if dup:
        out.append(f"页码重复 {dup}")
    skipped = meta.skipped_pages if meta is not None else frozenset()
    both = sorted(set(nums) & skipped)
    if both:
        out.append(f"页既入库又被跳过 {both[:20]}")
    if meta is not None and meta.page_count is not None:
        missing = sorted(set(range(1, meta.page_count + 1)) - set(nums) - skipped)
        extra = sorted(n for n in set(nums) | skipped if n < 1 or n > meta.page_count)
        if missing:
            out.append(f"缺页 {missing[:20]}")
        if extra:
            out.append(f"页码越界 {extra[:20]}")
    if meta is not None and meta.forced_l3:
        bad = sorted(p.page for p in pages if p.tier != "L3")
        if bad:
            out.append(f"定期报告须整份 L3，非 L3 页 {bad[:20]}")
        if skipped:
            out.append(f"定期报告不得跳页 {sorted(skipped)[:20]}")
```

```python
    *,
    routes_ref: str,
    meta: DocumentMeta,
    billed_pages: int,
    fallback_reason: str | None,
) -> ParseLedger:
    records: list[PageRecord] = []
    inputs: list[PageInput] = []
    for r in sorted(routed, key=lambda x: x.page):
        if r.tier == "skipped":
            records.append(PageRecord(r.page, "skipped", f"skip:{r.skip_rule}", r.page_kind,

                                      shadow_skip_rules=r.shadow_skip_rules))

            raise ValueError(f"p{r.page} 是 {r.tier} 页却没有验收输入")

                coverage_ratio=ratio, table_blocks=r.input.table_blocks, figure_count=r.figure_count,
                chart_regions=r.input.chart_regions,

            )

        billed_pages=billed_pages, fallback_reason=fallback_reason, acceptance_version=ACCEPTANCE_VERSION,
    )
    return ParseLedger(routes_ref, tuple(records), doc)
```

```python
TIERED_ALGORITHM_VERSION: Final = "v1"
REASON_L0_OFF: Final = "L0 关闭"
REASON_PERIODIC: Final = "定期报告整份 L3"
REASON_L0_TABLE_OUTPUT: Final = "L0 产物含表格（防御）"

def tiered_fingerprint(*, l0_enabled: bool, enforced: frozenset[SkipRuleId], textin_fp: str) -> str:
    return param_fingerprint(
        {
            "algo": TIERED_ALGORITHM_VERSION,
            "l0": f"det:{L0_VERSION}" if l0_enabled else "off",
            "chart": CHART_DETECTOR_VERSION,
            "skip": f"{SKIP_RULES_VERSION}:{','.join(sorted(enforced))}",
            "acceptance": ACCEPTANCE_VERSION,
            "pypdf": pypdf.__version__,
            "textin": textin_fp,
        }
    )


@dataclass(frozen=True)
class _Plan:
    layouts: tuple[PageLayout, ...]
    l0_pages: Mapping[int, L0Page]
    local_blocks: Mapping[int, list[NormalizedBlock]]
    l3_pages: tuple[int, ...]
    l3_reasons: Mapping[int, tuple[str, ...]]
    skips: Mapping[int, SkipRuleId]
    shadow: Mapping[int, tuple[SkipRuleId, ...]]

    @property
    def total(self) -> int:
        return len(self.layouts)


def _doc_kind(doc_type: str) -> DocKind:
    return "research_report" if doc_type == "research_report" else "announcement"


def _l0_reason(p: L0Page) -> str:
    base = f"L0 {p.kind}/{p.result.status}"
    return f"{base}：{p.result.reason}" if p.result.reason else base


def _stores(blob: BlobStore, calls: Sequence[TextInCall], warnings: list[str]) -> dict[int, PageStore]:
    """每个 TextIn 调用的 JSON → 原文页码 → PageStore（P3 用不展开合并格的文本）。"""
    out: dict[int, PageStore] = {}
    for call in calls:
        if call.json_ref is None:
            warnings.append(f"TextIn 段 {list(call.pages)} 没有 JSON，P3 只能对空文本核对")
            continue
        try:
            payload = json.loads(blob.get(call.json_ref).decode("utf-8"))
        except (BlobNotFound, ValueError):
            warnings.append(f"TextIn JSON 读取失败：{call.json_ref}")
            continue
        detail = (payload.get("result") or {}).get("detail") or []
        stores, _unpaged = split_detail_by_page(detail)
        for local, store in stores.items():
            if 1 <= local <= len(call.pages):
                out[call.pages[local - 1]] = store
    return out


class TieredParser:
    """实现 DocumentParser 与 DocTypeAwareParser。parse() 不知道文档类型，等价于 TextIn。"""

    def __init__(
        self,
        textin: DocumentParser,
        blob: BlobStore,
        *,
        l0_enabled: bool,
        doc_types: frozenset[str],
        enforced_skips: frozenset[SkipRuleId],
        textin_fp: str,
        extract: Callable[[bytes], list[PageLayout]] = extract_pages,
        l0: Callable[[Sequence[PageLayout]], list[L0Page]] = parse_layouts_l0,
    ) -> None:
        periodic = sorted(doc_types & ALWAYS_L3_DOC_TYPES)
        if periodic:
            raise ValueError(f"{periodic} 永远整份走 L3，不能进入分页路由")
        self._textin, self._blob = textin, blob
        self._l0_enabled, self._doc_types, self._enforced = l0_enabled, doc_types, enforced_skips
        self._extract, self._l0 = extract, l0
        self._fp = tiered_fingerprint(l0_enabled=l0_enabled, enforced=enforced_skips, textin_fp=textin_fp)

    @property
    def engine(self) -> str:
        return f"tiered:{TIERED_ALGORITHM_VERSION}+{self._fp}"

    def _sidecar_key(self, sha: str) -> str:
        return f"{SIDECAR_PREFIX}/{sha}/{self._fp}.json"

    def parse(self, file_bytes: bytes, *, owner_user: str | None = None) -> ParseResult:
        return self._textin.parse(file_bytes, owner_user=owner_user)

    def parse_for(
        self, file_bytes: bytes, *, doc_type: str, title: str | None, owner_user: str | None = None
    ) -> ParseResult:
        if owner_user is not None or doc_type not in self._doc_types:
            return self._textin.parse(file_bytes, owner_user=owner_user)
        if force_whole_document_l3(doc_type, title, None):
            return self._whole(file_bytes, reason=REASON_PERIODIC, kind=KIND_PERIODIC, forced=True, fallback=None)
        try:
            plan = self._plan(file_bytes, doc_type)
        except Exception as exc:  # noqa: BLE001 —— L0 / 版面 / 规则的任何异常都不得丢文档
            reason = f"{FALLBACK_L0}：{type(exc).__name__}"
            _LOG.warning("tiered parse fell back", extra={"stage": "plan", "error": type(exc).__name__})
            return self._whole(file_bytes, reason=reason, kind=KIND_FALLBACK, forced=False, fallback=reason)
        tp = parse_pages_with_textin(self._textin, file_bytes, plan.l3_pages, total_pages=plan.total)
        try:
            return self._finish(file_bytes, plan, tp)
        except Exception as exc:  # noqa: BLE001
            reason = f"{FALLBACK_ASSEMBLY}：{type(exc).__name__}"
            _LOG.warning("tiered parse fell back", extra={"stage": "assemble", "error": type(exc).__name__})
            whole = self._whole(file_bytes, reason=reason, kind=KIND_FALLBACK, forced=False, fallback=reason)
            return replace(
                whole,
                textin_calls=tp.calls + whole.textin_calls,
                billable_pages=tp.billed_pages + (whole.billable_pages or 0),
            )

    def _plan(self, file_bytes: bytes, doc_type: str) -> _Plan:
        layouts = tuple(self._extract(file_bytes))
        if not layouts:
            raise ValueError("PDF 没有可提取的页")
        l0_list = self._l0(layouts)
        if [p.page for p in l0_list] != [lay.page for lay in layouts]:
            raise ValueError("L0 页序与版面不一致")
        decisions = evaluate_skip_rules([page_facts(x) for x in layouts], doc_kind=_doc_kind(doc_type))
        skips = enforced_skips(decisions, self._enforced)
        shadow = {d.page: tuple(r for r in d.matched if r != skips.get(d.page)) for d in decisions}
        local: dict[int, list[NormalizedBlock]] = {}
        l3: list[int] = []
        reasons: dict[int, tuple[str, ...]] = {}
        for p in l0_list:
            if p.page in skips:
                continue
            if not self._l0_enabled:
                reasons[p.page] = (REASON_L0_OFF,)
            elif not p.accepted:
                reasons[p.page] = (_l0_reason(p),)
            else:
                try:
                    local[p.page] = blocks_from_l0_page(p.page, p.result.markdown)
                    continue
                except L0TableInOutput:
                    reasons[p.page] = (REASON_L0_TABLE_OUTPUT,)
            l3.append(p.page)
        return _Plan(layouts, {p.page: p for p in l0_list}, local, tuple(l3), reasons, skips, shadow)

    def _crop(self, file_bytes: bytes, sha: str, plan: _Plan, warnings: list[str]) -> list[FigureRef]:
        regions = [f for page in sorted(plan.local_blocks) for f in plan.l0_pages[page].figures]
        if not regions:
            return []
        try:
            refs, skipped = crop_figures(
                file_bytes, regions, doc_sha256=sha, blob=self._blob, source="local",
                detector_version=CHART_DETECTOR_VERSION,
                page_sizes={lay.page: (lay.width, lay.height) for lay in plan.layouts},
            )
        except Exception as exc:  # noqa: BLE001 —— 图是附加品，裁图失败不影响正文
            warnings.append(f"裁图失败：{type(exc).__name__}")
            return []
        warnings.extend(f"第 {s.page} 页图未裁：{s.reason}" for s in skipped)
        return refs

    def _routed(self, plan: _Plan, tp: TextInPages, stores: Mapping[int, PageStore],
                figures: Sequence[FigureRef]) -> list[RoutedPage]:
        call_of = {p: c for c in tp.calls for p in c.pages}
        text = {lay.page: lay.text for lay in plan.layouts}
        out: list[RoutedPage] = []
        for page in range(1, plan.total + 1):
            kind = plan.l0_pages[page].kind
            shadow = plan.shadow.get(page, ())
            if page in plan.skips:
                out.append(RoutedPage(page, "skipped", kind, None, skip_rule=plan.skips[page],
                                      shadow_skip_rules=shadow))
            elif page in plan.local_blocks:
                figs = [f for f in figures if f.page == page]
                inp = l0_page_input(plan.l0_pages[page], text_layer=text[page], blocks=plan.local_blocks[page],
                                    figures=figs)
                out.append(RoutedPage(page, "L0", kind, inp, shadow_skip_rules=shadow, figure_count=len(figs)))
            else:
                call = call_of[page]
                store = stores.get(page)
                tables = sum(1 for b in tp.blocks_by_page.get(page, ()) if b.block_type == "table")
                inp = l3_page_input(page, engine=call.engine, page_kind=kind, reasons=plan.l3_reasons[page],
                                    text_layer=text[page], store=store, table_blocks=tables)
                out.append(RoutedPage(page, "L3", kind, inp, shadow_skip_rules=shadow,
                                      textin_billed=call.billed_pages > 0, textin_json_ref=call.json_ref,
                                      image_ocr_numbers=image_ocr_numbers(store)))
        return out

    def _finish(self, file_bytes: bytes, plan: _Plan, tp: TextInPages) -> ParseResult:
        sha = hashlib.sha256(file_bytes).hexdigest()
        warnings = list(tp.warnings)
        stores = _stores(self._blob, tp.calls, warnings)
        figures = self._crop(file_bytes, sha, plan, warnings)
        routed = self._routed(plan, tp, stores, figures)
        if tp.whole_document is not None:
            whole = tp.whole_document
            ref = whole.json_ref or self._sidecar_key(sha)
            meta = DocumentMeta(True, whole.engine_version, True, page_count=plan.total)
            ledger = build_ledger(routed, routes_ref=ref, meta=meta, billed_pages=tp.billed_pages,
                                  fallback_reason=None)
            if whole.json_ref is None:
                self._blob.put(ref, json.dumps({"ledger": asdict(ledger)}, ensure_ascii=False).encode("utf-8"))
            return replace(whole, warnings=warnings, billable_pages=tp.billed_pages, textin_calls=tp.calls,
                           ledger=ledger)
        assembled = assemble_blocks(
            [(p, bs) for p, bs in plan.local_blocks.items()] + [(p, list(bs)) for p, bs in tp.blocks_by_page.items()]
        )
        blocks = interleave_figures(assembled, figures)
        key = self._sidecar_key(sha)
        meta = DocumentMeta(True, self.engine, True, page_count=plan.total, skipped_pages=frozenset(plan.skips))
        ledger = build_ledger(routed, routes_ref=key, meta=meta, billed_pages=tp.billed_pages, fallback_reason=None)
        md_key, markdown = self._write_sidecar(key, plan, tp, figures, ledger, blocks)
        return ParseResult(
            blocks=blocks, page_count=plan.total, engine_version=self.engine, markdown=markdown, json_ref=key,
            md_ref=md_key, warnings=warnings, from_cache=tp.billed_pages == 0, billable_pages=tp.billed_pages,
            textin_calls=tp.calls, ledger=ledger,
        )

    def _write_sidecar(
        self, key: str, plan: _Plan, tp: TextInPages, figures: Sequence[FigureRef], ledger: ParseLedger,
        blocks: Sequence[NormalizedBlock],
    ) -> tuple[str, str]:
        text = {lay.page: lay.text for lay in plan.layouts}
        routes = [
            route_to_dict(PageRoute(page=r.page, tier=cast(Tier, r.tier), engine=r.engine,
                                    text_layer=bool(text[r.page].strip()), reasons=r.reasons,
                                    textin_billed=r.textin_billed))
            for r in ledger.pages
            if r.tier != "skipped"
        ]
        body = {
            "version": 1,
            "engine": self.engine,
            "routes": routes,  # tables/page_engines.py::routes_from_sidecar 读这个键
            "skipped": [{"page": r.page, "rule": r.skip_rule} for r in ledger.pages if r.tier == "skipped"],
            "shadow_skips": [{"page": r.page, "rules": list(r.shadow_skip_rules)}
                             for r in ledger.pages if r.shadow_skip_rules],
            "textin_calls": [call_to_dict(c) for c in tp.calls],
            "l0_markdown": {str(p): plan.l0_pages[p].result.markdown for p in sorted(plan.local_blocks)},
            "figures": [figure_to_dict(f) for f in figures],
            "ledger": asdict(ledger),
        }
        self._blob.put(key, json.dumps(body, ensure_ascii=False).encode("utf-8"))
        markdown = "\n\n".join(
            f"<!-- p{r.page} {r.tier} -->\n" + "\n\n".join(b.content for b in blocks if b.page == r.page)
            for r in ledger.pages
        )
        md_key = key.removesuffix(".json") + ".md"
        self._blob.put(md_key, markdown.encode("utf-8"))
        return md_key, markdown

    def _whole(self, file_bytes: bytes, *, reason: str, kind: str, forced: bool, fallback: str | None) -> ParseResult:
        r = self._textin.parse(file_bytes, owner_user=None)
        marked = [replace(b, source="textin") for b in r.blocks]
        warnings = list(r.warnings)
        try:
            text = {lay.page: lay.text for lay in self._extract(file_bytes)}
        except Exception as exc:  # noqa: BLE001 —— 文字层取不到时 P3 记 unverifiable，不阻断入库
            text = {}
            warnings.append(f"文字层提取失败：{type(exc).__name__}，P3 无法核对")
        total = r.page_count or len(text)
        if total < 1:
            return replace(r, blocks=marked, warnings=warnings)
        call = TextInCall(tuple(range(1, total + 1)), r.json_ref, r.md_ref, r.engine_version,
                          0 if r.from_cache else total)
        stores = _stores(self._blob, (call,), warnings)
        tables = Counter(b.page for b in marked if b.block_type == "table")
        routed = [
            RoutedPage(
                p, "L3", kind,
                l3_page_input(p, engine=r.engine_version, page_kind=kind, reasons=(reason,),
                              text_layer=text.get(p), store=stores.get(p), table_blocks=tables.get(p, 0)),
                textin_billed=call.billed_pages > 0, textin_json_ref=r.json_ref,
                image_ocr_numbers=image_ocr_numbers(stores.get(p)),
            )
            for p in range(1, total + 1)
        ]
        ref = r.json_ref or self._sidecar_key(hashlib.sha256(file_bytes).hexdigest())
        meta = DocumentMeta(True, r.engine_version, True, page_count=total, forced_l3=forced)
        ledger = build_ledger(routed, routes_ref=ref, meta=meta, billed_pages=call.billed_pages,
                              fallback_reason=fallback)
        if r.json_ref is None:
            self._blob.put(ref, json.dumps({"ledger": asdict(ledger)}, ensure_ascii=False).encode("utf-8"))
        return replace(r, blocks=marked, warnings=warnings, billable_pages=call.billed_pages,
                       textin_calls=(call,), ledger=ledger)
```

```python
def with_tiered_routing(textin: DocumentParser, blob: BlobStore, cfg: RagdemoConfig) -> DocumentParser:

        doc_types=cfg.parse_tiered_doc_types,
        enforced_skips=cfg.parse_skip_rules,

    )
```

```python
# packages/ragdemo/src/ragdemo/parse/tiered/cost_model.py
"""积压 / 增量成本估算与启用前后每页成本（纯函数，Decimal，不让模型产出任何数值）。"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from decimal import ROUND_HALF_UP, Decimal
from typing import Final

from ragdemo.parse.tiered.ledger import TierRow

_Q4: Final = Decimal("0.0001")


@dataclass(frozen=True)
class GroupEstimate:
    name: str
    pages: int
    l0_share: Decimal  # 按页路由时 L0 接手的页占比；整份 L3 的组为 0
    skipped_pages: int = 0

    def __post_init__(self) -> None:
        if self.pages < 0 or not Decimal(0) <= self.l0_share <= Decimal(1):
            raise ValueError(f"{self.name}：页数 {self.pages} 或 L0 份额 {self.l0_share} 非法")
        if self.skipped_pages < 0 or self.skipped_pages > self.pages - l0_pages(self):
            raise ValueError(f"{self.name}：跳页 {self.skipped_pages} 超过非 L0 页")


def l0_pages(g: GroupEstimate) -> int:
    return int((Decimal(g.pages) * g.l0_share).to_integral_value(rounding=ROUND_HALF_UP))


@dataclass(frozen=True)
class CostEstimate:
    pages: int
    textin_pages: int
    cny: Decimal
    per_page: Decimal


def estimate(groups: Sequence[GroupEstimate], *, price: Decimal) -> CostEstimate:
    pages = sum(g.pages for g in groups)
    textin = sum(g.pages - l0_pages(g) - g.skipped_pages for g in groups)
    cny = price * textin
    per_page = (cny / pages).quantize(_Q4, rounding=ROUND_HALF_UP) if pages else Decimal(0)
    return CostEstimate(pages, textin, cny, per_page)


@dataclass(frozen=True)
class CostComparison:
    pages: int
    billed_pages: int
    unbilled_l3_pages: int
    actual_cny: Decimal
    counterfactual_cny: Decimal
    actual_per_page: Decimal
    saving_share: Decimal


def compare_costs(rows: Sequence[TierRow], *, price: Decimal) -> CostComparison:
    pages = sum(r.pages for r in rows)
    if pages == 0:
        raise ValueError("台账里没有页，无从比较")
    l3 = next((r for r in rows if r.tier == "L3"), None)
    billed = l3.billed_pages if l3 is not None else 0
    unbilled = (l3.pages - l3.billed_pages) if l3 is not None else 0
    actual = (sum((r.cost_cny for r in rows), Decimal(0)) + price * unbilled).quantize(_Q4)
    counterfactual = (price * pages).quantize(_Q4)
    return CostComparison(
        pages=pages, billed_pages=billed, unbilled_l3_pages=unbilled, actual_cny=actual,
        counterfactual_cny=counterfactual,
        actual_per_page=(actual / pages).quantize(_Q4, rounding=ROUND_HALF_UP),
        saving_share=(1 - actual / counterfactual).quantize(_Q4, rounding=ROUND_HALF_UP),
    )


def unverified_rate(unverified: int, total: int) -> Decimal | None:
    if total <= 0:
        return None
    return (Decimal(unverified) / Decimal(total)).quantize(_Q4, rounding=ROUND_HALF_UP)
```

```python
"""最小 eval_extraction：解析数字保真度（仓库里还没有抽取 Agent，这里不评模型）。
value_recall：人工读出的数值是否在 gold 块里（比较前 heal_spacing）。
hallucination_rate：逐页台账里入库数字不在文字层的比例（P3 口径），按 L0 / L3 分开。全部由代码计算。"""

from __future__ import annotations

import csv
import uuid
from dataclasses import asdict, dataclass
from datetime import UTC, datetime
from pathlib import Path
from typing import Final

import psycopg

from ragdemo.evals.runner import record_eval_run
from ragdemo.parse.local.number_closure import numbers_in
from ragdemo.parse.textin_audit import heal_spacing

EXTRACTION_COLUMNS: Final = ("doc_id", "block_id", "field", "gold_value", "unit")


def value_found(gold_value: str, content: str) -> bool:
    want = numbers_in(gold_value)
    have = numbers_in(heal_spacing(content))
    return bool(want) and all(have.get(k, 0) >= v for k, v in want.items())


def import_extraction_cases(conn: psycopg.Connection, path: Path, *, annotator: str) -> int:
    with path.open(encoding="utf-8-sig", newline="") as fh:
        rows = [{k: (v or "").strip() for k, v in r.items() if k} for r in csv.DictReader(fh)]
    problems: list[str] = []
    for i, r in enumerate(rows, start=2):
        hit = conn.execute(
            "SELECT 1 FROM core.doc_block WHERE block_id = %s AND doc_id = %s AND is_leaf AND superseded_at IS NULL",
            (int(r["block_id"]), int(r["doc_id"])),
        ).fetchone()
        if hit is None:
            problems.append(f"第 {i} 行：块 {r['block_id']} 不属于文档 {r['doc_id']} 或不是现行叶子")
        if not r["gold_value"]:
            problems.append(f"第 {i} 行：gold_value 为空")
    if problems:
        raise ValueError("；".join(problems))
    for r in rows:
        conn.execute(
            "INSERT INTO evals.eval_extraction (doc_id, field, gold_value, unit, gold_block_id, author)"
            " VALUES (%s, %s, %s, %s, %s, %s)",
            (int(r["doc_id"]), r["field"], r["gold_value"], r["unit"] or None, int(r["block_id"]),
             f"human:{annotator}"),
        )
    conn.commit()
    return len(rows)


@dataclass(frozen=True)
class ExtractionResult:
    n: int
    value_recall: float
    per_source: dict[str, dict[str, float | int]]
    hallucination_rate: dict[str, float | None]


def run_extraction_eval(
    conn: psycopg.Connection, *, git_sha: str, author_prefix: str | None = None
) -> ExtractionResult:
    started = datetime.now(UTC)
    cases = conn.execute(
        "SELECT e.gold_value, coalesce(b.content, ''), b.parse_source FROM evals.eval_extraction e"
        "  LEFT JOIN core.doc_block b ON b.block_id = e.gold_block_id"
        " WHERE (%s::text IS NULL OR e.author LIKE %s) ORDER BY e.case_id",
        (author_prefix, f"{author_prefix}%" if author_prefix else None),
    ).fetchall()
    if not cases:
        raise ValueError("评测集为空；空集会算出满分")
    hits = [(value_found(str(g), str(c)), s or "legacy") for g, c, s in cases]
    per: dict[str, dict[str, float | int]] = {}
    for src in sorted({s for _, s in hits}):
        mine = [h for h, s in hits if s == src]
        per[src] = {"n": len(mine), "value_recall": sum(mine) / len(mine)}
    hall: dict[str, float | None] = {}
    for tier in ("L0", "L3"):
        u = conn.execute(
            "SELECT coalesce(sum(unverified_numbers), 0), coalesce(sum(output_numbers), 0)"
            "  FROM core.parse_page_route WHERE tier = %s",
            (tier,),
        ).fetchone()
        hall[tier] = (int(u[0]) / int(u[1])) if u and int(u[1]) else None
    result = ExtractionResult(len(hits), sum(h for h, _ in hits) / len(hits), per, hall)
    record_eval_run(conn, run_id=f"eval-{uuid.uuid4().hex[:12]}", suite="extraction", git_sha=git_sha,
                    config={"author_prefix": author_prefix}, metrics=asdict(result), started_at=started,
                    ended_at=datetime.now(UTC))
    return result
```

`evals/cli.py`：`@eval_group.command("extraction-import")`（`--csv`、`--annotator`，调用 `import_extraction_cases`）与 `@eval_group.command("extraction-run")`（`--author-prefix`，调用 `run_extraction_eval(conn, git_sha=_git_sha(), ...)` 并打印 `n`、`value_recall`、`per_source`、`hallucination_rate`）。

4. **跨页表只在 L3 连续段内合并。** 一张表跨过被 L0 接手或被跳过的页时不会被合并（L0 页按定义不含表格，实际极少出现）。
5. **阅读顺序只靠检测器 + 人工抽查兜底。** 数字闭合对顺序无能为力（L0v2 已知局限 2）。
6. **图表只存图。** L0 页的图块非叶子、不检索、不解读；TextIn 页的图片 OCR 文字原样入库，其数字只在台账计数（`image_ocr_numbers`），是否在引用链路里标"推断"待 U7。
7. **扫描页全部 L3。** 整份扫描文档的数字无法用文字层核对（台账 `unverifiable_scan`）；是否不可引用待 U7。
8. **子 PDF 字节依赖 pypdf 版本。** 版本进指纹；升级 pypdf 会让新文档的子 PDF 缓存失效、重新计费（已入库文档不受影响）。
9. **减页节省很小。** 构造上安全的两条公告规则预计 ≤ 81 页（约 11 元）；真正的大头是 U4 的文档级选择，不是页级规则。
10. **P6 的 `can_show_raw` 在解析阶段按最严值记。** 实际块权限由 `DocumentWriter` 按来源写入。
11. **`tables/backfill.py` 的单文档入口不识别分页文档**（它把 `parse_json_ref` 当 TextIn JSON 读）；批量入口只选 `textin%` 引擎，不受影响。本计划不改 `tables/`，由表格计划维护者决定是否加守卫。
12. **TextIn 页码归属偏移不放宽。** P3 按单页核对，审计里的 adjacent_page 类（数字在相邻页）会让文档记为 `textin_unverified`；审计 §5 第 4 条（`page_end` / ±1 页取证）不在本计划内。
13. **评测的 gold 只在新文档上产生。** 存量 100 条只能做回归（E1）；L0 质量（E2）依赖用户在灰度文档上新出的人工题。

## 明确不做

- L1（自托管引擎）与 L2（双引擎一致）——用户裁决；扫描页全部 L3。
- 财务三大表页、年报 / 半年报 / 季报的分页路由——永远 L3。
- 图表数据提取、图片送模型或 OCR。
- 批量重解析已入库文档（含回滚后的 L0 文档）。
- 用户私有材料进入分级路由（P4 再议）。
- 修改 `parse/local/`、`tables/` 的任何文件；修改任何 prompt；新增大模型调用。
- TextIn 页的图片回填与 TextIn 图块改造（L0v2 计划开放问题 9）。
- 改写库里已存的 TextIn 文本（空白重接只用于比较）。
