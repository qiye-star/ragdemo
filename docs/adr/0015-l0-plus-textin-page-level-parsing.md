# ADR-0015 · 逐页解析路由：接入框架与逐页台账，当前只有 TextIn（L3）一条生产路径

- 状态：已接受
- 日期：2026-10-13
- 决策者：数据底座负责人（用户）
- 影响：修订 ADR-0008 的适用范围（"整份文档走 TextIn"变为"可按页路由，现实仍是整份 L3"）；ADR-0008 的年报 / 半年报 / 季报条款与推翻条件不变。不改变其他已锁定决策。

## 背景

- 目标曾是把单页解析成本从约 0.14 元降到 0.05 元以下：纯文字页走本地确定性排版（L0），表格页走自托管引擎（L1），扫描页走双引擎一致（L2），其余走 TextIn（L3）。
- 实测结果（记录见 `docs/10.12-plan/验收记录/`）：
  - L1：表格页 0/37 通过校验，结构性原因是引擎输出无单元格坐标、无法逐格校验；不再投入。
  - L2：未建。
  - L0 v2：调参集 G6a 标题召回 0.5517 未达 0.60；用户放宽后留出集 G3 = 0.9891 < 0.99（缺 3 个数字）；用户事后放宽 G3，改以 G9 阅读顺序抽查为最后条件，G9 未过（6 页被判错；缺陷：单行间隔表格被当纯文字、并排图注交错）。**L0 不启用。**
  - 减页规则：三条（空白页、签章尾页、研报免责声明尾页）按事先门槛全部只做影子记录，总节省不超过约 55 页、约 7.5 元；成本主要由"解析哪些文档"决定，而非页级规则。
  - TextIn 单价 0.1356 元/页（257 页、34.84 元实测估算，待发票复核）。积压全送 TextIn 约 869 元。
- 用户裁决：L0 v2 不启用；生产只有 L3；图表只存裁剪图与元数据，不提取图内数据；表格继续逐格解析；测试阶段付费解析只做一部分（已解析 288 页），不付费的工作可以全部做完。

## 备选方案

1. 维持旧路径，不引入路由框架：放弃逐页台账与将来接 L0 的位置。
2. 强行启用 L0 v2（放宽 G9）：违反"每个数字可溯源"，被否决。
3. 接入路由框架，L0 与跳页保持关闭（本决定）。

## 决策

1. 新增分页解析框架（`parse/tiered/`，开关 `PARSE_TIERED_*`，默认全关，关闭时与旧路径逐字节一致）。**当前生产形态只有 L3**：整份送 TextIn（跳页规则启用时才拆成连续段子 PDF，目前不启用）。
2. `PARSE_TIER_L0_ENABLED=true` 在配置加载时被硬拒绝（`L0 v2 not validated (G9)`）；L0 的代码（排版器、编号标题规则）保留但不接入入库链路。重开 L0 须新写计划（第三版），并使用新的留出样本。
3. 减页规则 `blank_page`、`signature_tail`、`research_disclaimer_tail` 均为 `shadow_only`；`PARSE_SKIP_RULES` 默认为空，只有过门槛且用户批准的规则才可填入。
4. 年报 / 半年报 / 季报整份 L3；用户私有材料不进分级路由；研报先灰度，`can_show_raw=false` 继承 ADR-0014。
5. 逐页台账（迁移 034：`core.parse_page_route` / `core.parse_doc_acceptance`）记录每页去向、P1–P8 验收、计费页与影子跳页；每个计费的 TextIn 子调用对应一条 `provider_snapshot`；块来源列 `parse_source` 与图表元数据列 `figure_meta`（迁移 033，`asof.doc_block` 已重建）。
6. 图表：只存裁剪图与元数据，不检索、不解读、不提取数据；表格：由 TextIn 逐格解析入库。
7. 每批入库后重测与当前语料匹配的检索基线（CLAUDE.md §1.4），指标下降按该条处理。

## 后果（已知局限）

1. **没有降本。** 当前形态下成本等于全送 TextIn；本决定买到的是逐页可审计与将来接 L0 的位置，不是节省。
2. 迁移 034 尚未应用到开发库，应用前须备份。
3. 每日汇总告警函数（`emit_ledger_alerts`）代码已有但未接定时任务；已接线的只有入库时的 `l3_no_output` 告警。灰度期间靠手动查询（见 `docs/10.12-plan/验收记录/L0加TextIn-接入评测与灰度.md`）。
4. P5 对跨页表格只在首页计表，续页可能使整份文档被记为 `rejected`；真实文档上未测，付费灰度前须先只读预检。
5. 跨页表只在 L3 连续段内合并；标题合并是规则化近似。
6. TextIn 页码归属偏移不放宽，相邻页数字使部分文档停在 `textin_unverified`（审计复现为 10/31）。
7. 图片 OCR 文字中的数字不静默放行：文档记为 `textin_unverified` 并带 `unverifiable_image` 原因；扫描页无文字层可核对，记为 `unverifiable_scan`、文档至多 `accepted_with_scan`。这些数字在引用链路里是否标"推断"、扫描文档数字是否不可引用，尚未裁决（产品改动另立项）。
8. 子 PDF 字节依赖 pypdf 版本，版本进指纹；升级会使新文档缓存失效（已入库不受影响）。
9. 单文档入口 `tables/backfill.py` 不识别分页文档（批量入口只选 `textin%` 引擎，不受影响）。
10. 评测的 gold 只在新文档上产生，存量只能做回归；`eval_extraction` 运行器未补；付费评测 C2 未跑。
11. L0 若将来重开：混合成本约 0.0957 元/页，0.05 元/页单靠 L0 也达不到。

## 推翻条件

- 有通过验证的 L0 第三版（新留出样本、G9 0 错）且用户批准启用：另立 ADR 或修订本文；
- 有可用于表格页的自托管引擎且输出含单元格坐标、可做逐格校验：另立 ADR；
- 逐页台账长期不被用于审计或回滚决策、且维护成本高于价值：关闭总开关回退为旧路径（台账表保留）。
