# ADR-0007 · 观点评分双轨制，分开存不合并

- 状态：已接受
- 日期：2026-09-21
- 决策者：创始团队

## 背景

简报 §12 第 6 问：观点评分的自动化规则，如何定义「事后走向」。

这是整个回测闭环的地基。定错了，`opinion_score` 表里积累三个月的数字毫无意义，
P5 的「观点准确率公开页」也没有可信内容可展示。

## 备选方案

**A. 只用相对超额收益**：个股相对其 L3 环节等权组合的超额收益，分档打分。
全自动、零人工成本。

**B. 只用论据验证**：不看股价，只看后续披露的事实是否印证原论据。
合规上最安全（完全不涉及投资收益），但需要持续人工标注，且没有可对外展示的
「准确率」数字。

**C. 绝对涨跌幅**：直接用个股绝对收益分档。最简单。

**D. A + B 双轨，分开存不合并。**

## 决策

**选 D。**

### 为什么不是 A

方案 A 会把「论据对、市场没反应」判为错误。这在研究场景中恰恰是常见且有价值的情形：
引擎判断某公司 AI 收入占比将提升，三个月后财报证实了，但股价因为大盘或行业
情绪没动。按方案 A 这是 0 分甚至负分，但引擎的**判断是对的**。
持续用这个信号去调优，会把系统训练成追逐短期价格动量而不是识别基本面变化。

### 为什么不是 C

牛熊市会系统性抬高或压低所有观点的得分。三个月后拿到一个「命中率 78%」，
如果那三个月大盘涨了 20%，这个数字没有任何参考价值。相对基准是必须的。

### 为什么不是 B

论据验证无法给出对外可展示的量化结论，而 P5 需要一个公开页。
更重要的是，它完全依赖人工标注，规模上不去。

### 为什么两轨不加权合并

一旦合并成单一分数，就必须选一个权重，而这个权重没有任何客观依据。
更糟的是**合并会掩盖最有价值的信息**：价格分高而论据分低 = 蒙对了；
论据分高而价格分低 = 判断对但市场未反应（可能是机会，也可能是逻辑不被认可）。
这两种情况需要完全不同的改进动作，合并后都变成「中等分数」，无法区分。

因此 `opinion_score` 上有 `UNIQUE (opinion_id, track, horizon)`
（`02-data-model.md` §6），结构上就不允许合并。

## 决策内容

完整计算口径见 `08-evaluation.md` §2。核心要点：

**价格分（自动）**

- `t0` = 观点生成后第一个可获得收盘价的交易日；`t1` = `t0` 后第 21（1M）/ 63（3M）个交易日
- 收益用复权价；`price_daily` 走 `asof` 视图，`as_of = scored_at`
- 基准 = 目标实体在 `opinion.as_of` 时点所属 L3 环节的等权组合，
  剔除停牌、上市不足 60 交易日、缺价者
- 成分不足 3 家时按 `l2_segment` → universe 逐级回退，回退级别记入 `benchmark_def`
- α = 个股收益 − 基准收益，按 ±3% / ±8% 分五档（−2 到 +2）
- **全部由代码计算，模型不参与打分**

**论据分（人工）**

- 复盘 Agent 检索区间内新文档，产出**预标注**与候选证据块
- **创始人复核后才入库**，`scorer = 'human'`
- −2（明确证伪）到 +2（明确印证），0 表示区间内无相关新信息

**不评分的情形**（不是记 0 分）：停牌超过 1/3 区间、退市、未经人工确认的观点。
「没法评」和「评了是中性」是两回事，记 0 分会污染平均分。

## 后果

1. **需要 `entity_node_membership` 时点表**（`02-data-model.md` §2.4）。
   基准是环节等权组合，如果环节成分只存当前值，回溯调整某公司的环节归属
   会静默改变全部历史观点的基准收益。这张表是本决策的直接产物。
2. **`benchmark_def` 必须快照成分清单**。即使日后环节调整，历史分数可复现。
3. **论据分有持续人工成本**。按每周 10–20 条观点估算，每周约 1–2 小时。
   这是可接受的，但要在排期里显式留出。
4. **报告必须分组**（`08-evaluation.md` §3.1）。尤其是
   「依赖手工关系 vs 仅依赖自动抽取」这一组——它检验结论是否主要来自
   创始人的事后知识而非引擎能力。
5. **样本量下限 30**（§3.2）。P5 公开页在分组样本不足时显示计数而非百分比。
6. **合规边界**：价格分是事后统计，不是收益预测，不违反「不输出投资建议」。
   但公开展示时的措辞必须是「历史观点的事后统计」，
   不得暗示未来表现。文案需合规审核。

## 推翻条件

- 积累三个月后发现价格分与论据分的相关性极高（如 Spearman > 0.8），
  说明双轨冗余，可简化为单轨；
- 价格分的分档阈值（±3% / ±8%）被证明不合理——例如绝大多数观点都落在
  中间档，分档失去区分度。这是**参数调整**，改阈值不需要新 ADR，
  但要在 `08-evaluation.md` 中记录变更日期，且**不得回溯重算历史分数**；
- 论据分的人工成本超出承受，且 Agent 预标注与人工的一致率足够高
  （> 90%）→ 部分情形自动化，但「明确证伪」等高风险判定仍须人工；
- 出现更合适的基准（如可交易的 AI 产业链指数），可替换等权组合——
  届时新旧基准并行计算一段时间对比后再切换。
